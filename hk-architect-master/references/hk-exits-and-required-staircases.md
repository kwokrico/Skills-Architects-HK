# Exit doors, exit routes and required staircases

Use the [BD Fire Safety Code 2011 (2024 Edition), Part B](https://www.bd.gov.hk/doc/en/resources/codes-and-references/code-and-design-manuals/fs_code2011.pdf), especially B7–B8/Table B2 (printed pp. 32–34), B12 (pp. 40–42) and B14 (p. 44). Sources checked 23 November 2026. Establish use classification, occupant capacity under B4, actual exit layout and the stair's escape function before applying these provisions. An ordinary circulation stair is not automatically a required escape stair.

## Exit doors and storey exit routes

- **B7:** assess exit doors from the room/fire compartment. Table B2 column 2 gives the count, column 3 the total door width and column 5 each door's width.
- **B8.1:** assess storey exit routes separately. Use column 2 for count, column 4 for total route width and column 6 for each route. At least two routes are required unless the B6.1 single-stair provisions apply; a low occupant count alone does not establish that exception.

The first two Table B2 rows illustrate the change at **31 occupants**; this is not a replacement for the full table and its notes:

| Occupants | Table count | Total doors (mm) | Total routes (mm) | Each door (mm) | Each route (mm) |
|---|---|---|---|---|---|
| 4–30 | 1 | Not specified in this row | Not specified in this row | 750 | 1050 |
| 31–200 | 2 | 1750 | 2100 | 850 | 1050 |

Thus two 850 mm doors do not meet the 1750 mm total-door requirement. Check both individual and total widths, the B7.2 route arrangement, and the limits on credit for unequal widths in B7.3/B8.1(b). Use the full applicable row for larger populations and the special provisions for Use 5a. Do not infer a blanket 750 mm door/route allowance for up to 50 occupants.

Measure doors and routes using Table B2 notes 2–3: door clear width is between frame members; route width is between finished walls or inner balustrade faces, subject to the stated handrail projection allowance. Corridor and stair widths are not selected by a blanket residential/non-domestic split.

## Required-staircase checks

| Separate check | Governing provisions |
|---|---|
| Geometry | B14.2 requires straight flights without winders. Check its riser/tread dimensions and use-specific exceptions; B14.3 governs landings. A **900 mm spiral stair proposed as a required exit fails the standard B14.2 geometry test**, regardless of its width |
| Clear width | B14.4 refers to B8.1 and Table B2, not the exit-door column. Check occupant capacity, route count and width measurement. A 900 mm width also falls below Table B2's 1050 mm minimum route width; widening a spiral stair does not cure its geometry |
| Discharge capacity | B12 assesses the population served across storeys, separately from each storey's B8 width check. Select Table B3 or B4 using B12.3–B12.5; partial sprinkler coverage does not automatically qualify. Apply the B12.6/B12.7 reductions where relevant |

Also check B14.4 headroom, B14.5 division of wide stairs and B14.6 handrails. B14.1 routes construction/fire resistance to Part C. Check B10 access/lobby provisions and the applicable FSI requirements for smoke protection; do not use a blanket height-based fire-resistance or pressurisation rule from an abbreviated stair table. Scissors stairs still require the relevant layout, protection and discharge checks, not assumed acceptance.

Travel distance remains a separate check: use [the existing B11 reference](hk-travel-distance.md).

## Existing buildings and A&A

Read [PNAP APP-153, paragraphs 2–3](https://www.bd.gov.hk/doc/en/resources/codes-and-references/practice-notes-and-circular-letters/pnap/APP/APP153.pdf). Establish the applicable code edition/basis, approved escape layout, proposed use and areas/exit routes affected by the works before a project conclusion. Paragraph 3(a) generally applies the FS Code to areas affected by A&A, including affected exit routes; it does not automatically require unaffected parts to follow the Code. Check paragraph 2's transitional provisions and separate statutory fire-safety improvement regimes where relevant. Neither existing status nor a nominal stair width establishes acceptability.
