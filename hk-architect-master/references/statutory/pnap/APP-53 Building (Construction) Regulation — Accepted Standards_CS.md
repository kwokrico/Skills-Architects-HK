# APP-53 Building (Construction) Regulation — Accepted Standards
**Architect critical summary for schematic design**
This revision April 2024 | Buildings Department (previously PNAP 140; first issue December 1990)

> Scope note: Standards the Building Authority accepts as meeting the performance requirements of the Building (Construction) Regulation. Another version or standard may be approved if it achieves those requirements and its fit with local conditions is explained. Agree an alternative in principle with the Buildings Department before it is used. Appendix A is the list. Later parts of the appendix give material and test standards for concrete, steel, aluminium, and other materials; the design standards below are the ones that fix schematic choices.

## Regulatory Overview
Concrete, fire safety, foundations, precast concrete, steel, wind, dead and imposed loads, and structural glass are designed to the Hong Kong codes named in Appendix A. Structural aluminium may still use BS 8118: Part 1: 1991, but from 1 January 2017 the partial load factor for wind is 1.4 instead of the factor of 1.2 in Table 3.1 of that standard, unless an amendment continues a design already approved at 1.2.

## Critical main topics and subtopics

### 1. Design standards accepted for performance compliance (Appendix A, part 1)
| Subject | Accepted standard |
| --- | --- |
| Concrete | Code of Practice for Structural Use of Concrete 2013 (2020 Edition) |
| Fire safety | Code of Practice for Fire Safety in Buildings 2011 (June 2023 Edition) |
| Foundations | Code of Practice for Foundations 2017 |
| Precast concrete | Code of Practice for Precast Concrete Construction 2016 |
| Steel | Code of Practice for the Structural Use of Steel 2011 (2023 Edition), with its Explanatory Materials |
| Wind | Code of Practice on Wind Effects in Hong Kong 2019, with its Explanatory Notes |
| Dead and imposed loads | Code of Practice for Dead and Imposed Loads 2011 (2021 Edition) |
| Aluminium | BS 8118: Part 1: 1991, with the wind partial factor of 1.4 from 1 January 2017 |
| Glass | Code of Practice for Structural Use of Glass 2018 |
| Stainless steel | SCI Publication P291, Structural Design of Stainless Steel |
| Timber | BS 5268: Part 2: 2002 (permissible stress), Part 3: 2006 (trussed rafters), Part 4: 1990 (fire resistance) |
| Glass-fibre reinforced concrete | Practical Design Guide published by the Technical Committee of the Glassfibre Reinforced Concrete Association |
| Elastomeric or mechanical bearings | General Specification for Civil Engineering Works 2020 |
| Masonry | BS 5628: Part 1: 2005, unreinforced masonry |
| Earthworks | BS 6031: 2009 |
| Natural stone cladding and lining | BS 8298: Parts 1 to 4: 2010 |
| Reinforcing bars, concrete materials, and testing | The 2013 concrete code (2020 Edition) |
| Structural steel materials, bolts, welding, and protective treatment | The 2011 steel code (2023 Edition) |

**SD takeaway:** Design to the Hong Kong codes listed above, and if structural aluminium still follows BS 8118 use a wind partial factor of 1.4 unless the original approval was at 1.2.
