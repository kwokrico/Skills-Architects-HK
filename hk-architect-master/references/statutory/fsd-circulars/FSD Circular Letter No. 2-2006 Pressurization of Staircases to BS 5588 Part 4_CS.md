# FSD Circular Letter No. 2/2006 — Pressurization of Staircases to British Standard 5588: Part 4
**Architect critical summary for schematic design**  
31 July 2006 | Fire Services Department — Licensing and Certification Command

> Implements **BS 5588-4:1998 (+ Amd 1 + Corrig 1)** for staircase pressurization with Lists One–Four local schedule + inspection checklist. Read with **FSI CoP §5.21** and **CL 8/2021** (notice plates).

---

## Regulatory Overview

This circular formalizes local application of BS 5588-4:1998 for **staircase pressurization systems (SPS)**, replacing direct wholesale adoption with four modification lists. Only **Class A (means of escape)** and **Class B (firefighting)** systems are used locally — **Class C, D and E systems are not applied**.

---

## Critical main topics and subtopics

### 1. System classes in Hong Kong

| BS class | HK application |
|---|---|
| **Class A** | **Means of escape** pressurization (MOE mode) |
| **Class B** | **Firefighting** pressurization |
| Class C, D, E | **Not applied locally** |

### 2. Class A — key acceptance criteria (design + testing)

| Parameter | Requirement |
|---|---|
| Door air velocity (fire zone floor) | **≥ 0.75 m/s** at door of measurement |
| Door configuration at test | Open stair/lobby doors on **3 consecutive levels**; air release open on fire zone; other stair doors closed; **final exit open** |
| Air release checking | BS 5588 air-release provisions checked on **fire zone floor only**, but tests run **throughout entire staircase** |
| Pressure differentials | Refer **Clauses 5.2 and 5.3 only** (not 5.4–5.6) |

### 3. Definitions aligned to BD Codes

| Term | Local replacement |
|---|---|
| Basement | Storey below lowest ground storey with **upward exit route** |
| Fire compartment | BD-style enclosed fire-separated space |
| Protected lobby | Intercepted approach to staircase/exit route acting as fire/smoke check |

### 4. Other SD-relevant local changes

| Topic | Modification |
|---|---|
| Operational modes | Class A **MOE mode** + Class B **firefighting mode** only |
| Simple lobby door force | Max **100 N** opening force from accommodation |
| Ductwork standard | **DW/144** (not DW/142) |
| Indicator lights | Show **true SPS status** — power, duty/standby fans, air release, etc. (per List Two item 2.9) |
| Interaction with normal ventilation | Clause **9.2.3.3 not applied** |

**SD takeaway:** Pressurization design is **Class A/B only** with **0.75 m/s** door velocity criterion — size **air release paths, relief openings and plant** accordingly; do not design to Class C–E tables in BS 5588-4.
