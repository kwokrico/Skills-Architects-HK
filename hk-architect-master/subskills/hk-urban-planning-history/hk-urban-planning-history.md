# HK Urban Planning History

Dates and the instrument each decision left behind. This file does not state a width, a plot ratio, or a compliance result. For the live test, open the subskill in the last column.

For **why a Hong Kong planning control exists**, use `hk-urban-planning-history`. For other topics, see the routing table below.

## When to Use This Skill

| Question type | Use this skill | Use instead |
|---|---|---|
| Why this was planned this way, or which plan introduced the control | `hk-urban-planning-history` | `—` |
| The rule to draw or to test | `—` | The subskill named in the table |
| A planning idea with no date | `—` | `hk-urban-planning-theory` |

Do not cite this file as compliance.

## Chronology

| Period | What was decided | Instrument still used | Where the live rule sits |
|---|---|---|---|
| 1948 | The Abercrombie Report answered post-war development needs. Planning Department treats it as the start of strategic planning in Hong Kong | The report is not a current site control | This file only |
| 1973 | The New Town Development Programme started. The first three new towns are Tsuen Wan, Sha Tin and Tuen Mun. The stated concept is a balanced and self-contained community as far as possible | The new towns, and later new development areas | `hk-spatial-planning` for the zone; `hk-building-programming` for community facilities |
| Late 1980s, endorsed 1991 | The Metroplan study set out to reduce urban population density, improve landscape and the living environment, and increase mass-transit capacity. The Metroplan Selected Strategy was endorsed in 1991 as the framework for restructuring the metro area | Metroplan is not the outline zoning plan. Chapter 11 still cites its ridgeline starting point | `hk-urban-space-statutory` for the ridgeline test; `hk-spatial-planning` for the zone |
| 1997 | The Protection of the Harbour Ordinance, Cap. 531, established a presumption against reclamation in Victoria Harbour | Cap. 531 | `hk-coastal-wetland-controls` |
| 2007 | Hong Kong 2030: Planning Vision and Strategy was promulgated | Superseded as the latest strategy by Hong Kong 2030+ | This file only |
| 2021 | The final recommendations of Hong Kong 2030+: Towards a Planning Vision and Strategy Transcending 2030 were promulgated, as a strategic spatial framework beyond 2030 | Hong Kong 2030+. Chapter 11 assimilates its liveability directions. The strategy is not a site plot ratio | `hk-urban-space-statutory` for Chapter 11; `hk-urban-planning-theory` for the ideas |
