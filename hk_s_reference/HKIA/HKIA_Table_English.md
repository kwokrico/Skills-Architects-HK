# Hong Kong Institute of Architects Index (English)

**Issued by:** The Hong Kong Institute of Architects
**Scope:** The Code of Professional Conduct and the Rules of the Institute in this library (2 instruments). Rule 3.1 of the code refers to a Standard Form of Agreement between Client and Architect. There is no agreement PDF in this library, and none is indexed here. The HKIA Rules for the Conduct of Architectural Competitions and the Standard Form of Building Contract private-edition forms are not in this library. This library was not checked against the live Institute website after these two PDFs were saved.
**How to use:** The short title links to the critical summary in `summaries/` when one exists. The PDF link in the same cell opens the file in `source_reference/`.
**Titles:** The official title is the summary heading, or the PDF title when no summary is filed.
**Caveat:** Desk reference only. Before relying on it, check the current text on the Institute's website.
