# Joint Practice Note No. 2 — Second Package of Incentives for Green and Innovative Buildings
**Architect critical summary for schematic design**  
First issue February 2002 | Last revision September 2019 | This revision July 2022 | BD / LandsD / PlanD  
Ref: BD GP/ENV/8 · LD BP/7-4/5/2 · TPB/C/TPB/35

> Scope note: Second GFA/SC exemption package. **MiC removed** (July 2022) → use **JPN 8**. Hotels = non-residential → **no** utility-platform concessions. Residential incentives do not apply to non-domestic portion of composite buildings or residential accommodation for commercial use. Subject to **PNAP APP-151**. Cross-check JPN 1, APP-19, APP-123, CoP Access for External Maintenance App. B, B(C)R s.27.

---

## Regulatory Overview

JPN 2 adds four green/innovative features eligible for GFA and/or SC exemption under BO (with lease and planning follow-through): non-structural prefabricated external walls; utility platforms for residential buildings; noise barriers; and communal sky gardens for non-residential buildings.

At schematic design, lock prefab wall thickness and GFA line, UP vs balcony separation, noise-barrier form, and non-res sky-garden count (storeys÷20) before plate and BH freeze. Objective, application window, and submission conditions follow JPN 1.

### 3. Non-structural prefabricated external walls

#### 3.1 Structural and thickness

| Rule | Constraint |
|---|---|
| Load path | **Non-load-bearing**; satisfies external-wall design under B(C)R **s.27** |
| Fixings allowed | (a) in-situ RC joints; (b) cast-in anchorage in structural concrete; (c) welded to structural steel |
| Max thickness exempted | **150 mm** |
| Finishes disregarded from the 150 mm | Nominal-thickness finishes **or** dry-fixed stone panels with overall thickness ≤ **75 mm** — disregarded for thickness measurement **and** for GFA/SC |
| Lot boundary | Wall **including external finishes** must not project beyond |
| Door openings | Portion of wall formed with door opening → **GFA and SC accountable** |
| Prefab projecting window | Allowed if wall exempt thickness still ≤ 150 mm **and** projecting window meets **PNAP APP-19** |
| Submission | Blow-up sections for various wall profiles at building-plan stage |

#### 3.2 GFA measurement concept (App. B diagrams)

| Condition | Effect |
|---|---|
| Prefab skin ≤ 150 mm outside in-situ structure | Projection may be exempt from GFA/SC → usable floor gained vs measuring to external face of thick in-situ wall |
| Thickened part of wall | Premium may be chargeable on existing leases without curtain-wall exemption clause (diagram note) |
| Projecting window | Typically ≤ 100 mm under APP-19 (diagram reference) |

**SD:** Coordinate prefab 150 mm strategy with curtain wall (JPN 4 Group II — premium on many existing leases) and MiC double walls (JPN 8).

### 4. Utility platforms (residential) — full checklist

#### 4.1 Area maths

| Item | Value |
|---|---|
| Max portion exemptible | ≤ **50%** of UP area |
| Max exempt area per unit | **0.75 m²** (including portion of platform) |
| Minimum UP size (incl. exempted part) | ≥ **1.5 m²** |

**Worked implication:** To claim full 0.75 m² exemption, UP must be ≥ 1.5 m² (50% rule). Typical design UP ≈ 1.5–2.0 m².

#### 4.2 Location and conflicts

| Rule | Constraint |
|---|---|
| Occupancy | Residential buildings only |
| Balcony separation | ≥ **1.5 m** (unless CoP External Maintenance App. B combined balcony/UP/AC) |
| Projecting window | **None** in the room leading to the UP |
| Re-entrant | Not in re-entrant < **1,500 mm** unobstructed width (note: stricter/different from balcony’s 2,300 mm) |
| Light well | Not permitted |
| Lot boundary | Must not project beyond |
| Daylight / ventilation | Must not adversely affect other habitable space, kitchens, bathrooms, lavatories |

#### 4.3 Openness, level, parapet, exhaust

| Rule | Constraint |
|---|---|
| Open perimeter (standalone) | ≥ **40%** of UP perimeter faces open air, unenclosed above safe parapet |
| Laterally attached UPs | If separation is parapet height only → **longer side** must face open air and be unenclosed above safe parapet |
| Level drop | ≥ **150 mm** from adjacent interior leading to UP |
| Parapet design | Open (railing / perforated sheet / mesh) so natural ventilation not blocked |
| Solid base allowed | Lowermost **400 mm** of parapet may be solid |
| Fire | Overall design per fire codes; acceptance similar to balcony under **PNAP APP-123** |
| Combined UP+balcony+AC | Open-parapet criterion **not** applicable if CoP Ext. Maint. App. B complied with |
| Exhaust | If B(P)R 36 mod → exhaust must not open into UP or covered area underneath |
| Fixtures | Door access OK; water supply point and sink OK |

#### 4.4 Covered area under lowest UP

| Rule | Detail |
|---|---|
| Full GFA/SC exemption | Covered area under **lowest** UP |
| Openness | ≥ 40% perimeter open to open air; **or** if laterally attached covered areas with parapet-only separation → longer side open to open air |

#### 4.5 Enforcement / DMC

| Item | Detail |
|---|---|
| Enclosure above parapet | Misuse → enforcement |
| Exhaust into UP | Misuse → enforcement |
| Undertaking | Must be registered before OP |
| DMC | UPs + covered areas = **non-enclosed areas**; AC platforms on UPs (CoP App. B) = **areas for air-conditioning**; no individual AC on external walls |
| Sky gardens | Common areas; exclusive use of owners/tenants/visitors |

### 5. Noise barriers

| Rule | Constraint |
|---|---|
| Form A | Stand-alone wall, with or without projection, located **away from main tower** |
| Form B | Cantilevered acoustic panel from **podium** external walls |
| Beyond lot boundary | Approvals from relevant government departments required |
| Use | Not for other purposes including commercial |
| Justification | Quantitative assessment — effective and reasonable |
| Exclusion | GFA exemption **not** accorded to a non-noise-sensitive building used as a noise buffer |
| Policy note | Exemption does **not** replace controlling noise at source (EPD / HyD guidelines) |
| APP-151 | Pre-requisites apply |

**SD:** Place barriers as podium cantilevers or freestanding walls — not as a fake “buffer building” claiming exemption.

### 6. Communal sky gardens for non-residential buildings

#### 6.1 Count and use

| Parameter | Requirement |
|---|---|
| Max number | In addition to any podium garden: ≤ (number of **storeys**) ÷ **20** |
| Recreation | **Active recreational use permissible** except in **industrial** buildings |
| Microclimate | Wind tunnel / CFD recommended |

#### 6.2 Geometry (largely mirrors JPN 1 residential sky gardens)

| Parameter | Requirement |
|---|---|
| Cross-vent | ≥ two opposite sides open above safe parapet |
| Net garden | ≥ **50%** of floor plate; multi-parcels connected by communal circulation |
| Greenery | ≥ **15%** of floor plate in “L” zone (same L, 1.5 m lateral, 1.5×1.5 indentation rules) |
| Parapet for assessment | Solid ≤ 1,250 mm; opening top ≥ 3,000 mm above solid parapet; planter-backed → ≥ 2/3 permeable above 1,250 mm |
| First garden (multi, no podium) | ≤ **10 storeys** above lowest ground storey |
| Spacing | ≥ **10 storeys** above lower sky / podium garden (exceptions need strong env. justification) |
| Clear height | ≥ **4.5 m** |
| Access | Common area only |
| Service lifts | Garden **not** served by service lifts (where provided) |
| Exhaust | Must not face garden |
| Fixed elements | Planters, furniture, equipment fixed; typhoon-resistant |
| Refuge | Roof or coupled with sky garden(s) per fire codes |
| Notice / commercial ban | Communal use; no café/shops |
| Maintenance manual | Required |
| PlanD BH | No concern |
| APP-151 | Pre-requisites apply |

#### 6.3 vs JPN 1 residential sky garden

| Item | JPN 1 (res) | JPN 2 (non-res) |
|---|---|---|
| Count formula | Storeys ÷ **15** | Storeys ÷ **20** |
| Active recreation | Sitting-out + limited elderly kit (RRF package separate) | Active OK except industrial |
| Service lifts | Not specially barred in JPN 1 text | Explicitly **not** served by service lifts |
| RRF / elderly package | Detailed §1(c)(xvi) | Not in JPN 2 |

### 7. Triple-regime and process (design-critical)

| Regime | Key points |
|---|---|
| BO | Modification + supporting docs + undertaking; may precede lease mod if TPO OK |
| Lease — new tender | May include nil-premium clause mirroring BA exemptions if design/disposition OK to Lands |
| Lease — existing | BA exemptions generally follow; storey/height breach → lease mod |
| Lease — process | BA grant is pre-requisite; submit lease mod to DLO in parallel; BD alerts DLO; send approved plans + fee receipt to finalise BT |
| Enquiry | DLO ~30 days; or 8/10 weeks via centralised processing |
| PlanD | Same criteria; OZP BH/SC must not be contravened; sky garden may trigger minor relaxation; Class A/B amendments for approved schemes |
| OP | Undertaking registered; enforcement on UP enclosure, exhaust into UP, sky-garden misuse |

**SD takeaway:** UP re-entrant limit is **1,500 mm** (not balcony’s 2,300 mm). Prefab 150 mm + UP 0.75 m² both sit under APP-151 **overall cap** — budget with JPN 1 balconies. For MiC, switch to JPN 8.
