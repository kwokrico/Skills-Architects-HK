# LAO Practice Note No. 1/2026 — Certificate of Compliance applications
**Architect critical summary for schematic design**  
January 2026 | Lands Administration Office — Lands Department  
Supersedes LAO PN Nos. **1/1987** and **8/2000**; varies **PN 4/2008**

> Scope note: **Mandatory compliance checklist** for CC after completing a lease development. **Does not apply** to Cap. 121 NTEHs (use PN 1/2025). Phased lots with LandsD-approved Master Plans may get a **section** CC.

---

## Regulatory Overview

The optional checklist used since December 2000 is now **mandatory**, AP-confirmed, against a LandsD sample (App I, not exhaustive). Target: **CC within 10 weeks** or departmental comments within **8 weeks** of a valid application; unresolved conflicts may escalate under **DEVB General Circular No. 1/2026**.

---

## Critical main topics and subtopics

### 1. Documents that must accompany the CC application (para 4)

| Item | Who / what |
|---|---|
| (a) Completed **Checklist** + 4th-column proofs | AP confirms correctness |
| (b) AP letter (App II) | Development built to the **full set of latest building plans approved by LandsD** |
| (c) ALS letter + final survey report + Survey Record Plan (App III) | Certify **no encroachment** onto Government land (except BD+LandsD-approved projections/works over GL) |
| (d) | **Occupation Permit** and Certificate of Completion (where applicable) |
| (e) | LandsD **approval letter(s)** for that latest GBP set |
| (f) | Government rent paid to application date or last quarter |

Fn 6: because AP + ALS now certify as-built vs LandsD plans and no GL encroachment, **PN 4/2008 para 5 no longer applies** to CC applications on or after this PN.

**SD takeaway:** CC is blocked until LandsD-approved GBPs, OP, ALS no-encroachment survey, and AP as-built letter exist — freeze the LandsD plan set as the as-built datum from GBP stage.

### 2. Sample checklist — lease obligations LandsD will tick (App I)

Architect-facing rows (authority in brackets):

| Obligation | Typical authority |
|---|---|
| Premium; rent; no GL encroachment; building covenant | D of Lands / R&V |
| Green Area formation | HyD, TD, FSD, DSD, WSD, LCSD, CEDD |
| Brown Area | LandsD / BD / HAD |
| BO compliance | BD — submit **full latest BA-approved GBPs** |
| TPO / planning conditions | PlanD — **PlanD written confirmation** of approval-condition compliance |
| Tree preservation | LandsD — **PN 6/2023** |
| LMP / LP | PlanD or LandsD — **PN 1/2020 and 1/2020A** |
| Design and disposition | LandsD |
| SBD (setback, separation, greenery) | BD |
| Parking / L/UL / lay-bys; night-time CV parking; parking information; car-park layout deposit | TD / LandsD |
| Automatic meter reading (fresh water) | WSD |
| Babycare room (commercial accommodation) | DH |
| Footbridge / subway / pedestrian link | TD, HyD, CEDD, PlanD |
| **Government Accommodation** + assignment | GPA, ArchSD, plus TD/HyD for PTI; SWD for elderly centre; etc. |
| Public open space; public-facility layout; public vehicle park | Initiating B/D / TD |
| Green hatched black; natural terrain | GEO, CEDD |
| Drains/channels; drainage reserve; waterworks reserve; DIAs | DSD / WSD |
| TIA/traffic review; NIA; noise barrier; SIA; AQIA | TD / EPD / DSD |
| Restriction on alienation before compliance; DMC & MA | LandsD |

**SD takeaway:** Build a CC matrix at SD covering **GA, coloured areas, LMP/trees, SBD greenery, parking, POS/PVP, and planning conditions** — each needs a named department’s proof before the 10-week clock works.

---

### 3. Processing target and escalation (paras 6–7)

| Target | Clock |
|---|---|
| CC issued | **10 weeks** from valid application |
| Or comments relayed | **8 weeks** |
| Deadlock | LandsD coordinates; may escalate per **DEVB GC 1/2026** (large-scale private developments) |
| Effect | Paras 4–6 from **16 January 2026** |

**SD takeaway:** Programme CC (and thus DMC/sales) on a 10-week LandsD clock **after** a complete AP/ALS pack, with DEVB escalation only for remaining B/D deadlocks.
