# Lands Administration Office Practice Notes Index (English)

**Issued by:** Lands Department, Lands Administration Office
**Scope:** Issue Nos. 3/2026, 4/2026 and 9/2026 in this library (standard premium rates). Earlier practice notes that already have a critical summary in `summaries/` are not repeated here. This library was not checked against the live departmental website.
**How to use:** The number links to the critical summary in `summaries/`. The PDF link in the same cell opens the main note in `source_reference/`. Appendices and the `_text` copies are covered by the same summary.
**Titles:** The official title is the practice-note heading.
**Caveat:** Desk reference only. Before a submission, check the current practice note, the joint practice note it varies, and the lease.
