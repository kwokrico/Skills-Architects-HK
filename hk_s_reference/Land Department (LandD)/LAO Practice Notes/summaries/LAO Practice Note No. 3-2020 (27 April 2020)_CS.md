# LAO Practice Note No. 3/2020 — Design, Disposition and Height (DDH / DD) under Lease
**Architect critical summary for schematic design**  
27 April 2020 | Lands Administration Office — Lands Department  
Supersedes LAO PN 3/2014 | Read with **JPN 5** (building height) and LAO PN **4/2018** (streamlined GBP)

> Scope note: When **DDH or DD** is imposed, when it can be **omitted or stripped**, and **what LandsD actually checks** (site coverage, height, stilts, soil fill, parking headroom, transfer plates, walls, projections). **Pure aesthetics are generally not controlled.** It is **not** the BO SC/height code — BA is followed where stated. PN **3/2020A** later streamlines **SC** under this PN.

## Regulatory Overview

New/modified leases generally **omit building-height restriction** except special cases (**JPN 5**). A **DD** clause is also **generally not imposed** for the site types in para. 3 if the lease already controls essential parameters (GFA/PR). Existing DDH/DD can be **removed on modification** (new max GFA if missing, SBD, parking, user, landscape/trees, BC, premium). Where DDH/DD remains, approval is given **with GBP Stage 1** under PN 4/2018 — **no separate DDH application**.

## Critical main topics and subtopics

### 1. When DD is generally **not** imposed (paras. 2–4)

DD generally **not** imposed (any site size) if the site is:

- **commercial**; or
- **private residential or composite C/R in Density Zone I (urban)**; or
- **R(A)** high-density / composite in the **NT**; or
- **industrial and/or godown**; or
- requires **TPB MLP/LP**, or planning condition for MLP/LP to PlanD, or **lease MLP/LP** per OZP ES;

**and** the lease has specific GFA/PR (etc.) control.

Urban-design / **flat-size or unit-number** controls → **specific SCs**, not a vague DD clause.

**SD takeaway:** On a new grant in those categories, do **not** design around a DDH negotiation — height lives in **JPN 5 / the OZP**, bulk in the **GFA SC**.

### 2. Stripping DDH/DD from an existing lease (para. 5)

On redevelopment modification, owner may apply to **remove** DDH/DD if the lot falls in para. 3(a)–(e). Approval typically adds **max GFA** (if none), SBD, parking, user, landscape/trees, BC, other bureau requirements, **admin fee + premium**.

**SD takeaway:** Budget a **GFA cap + SBD + parking** package as the price of deleting DDH — not a free deletion.

### 3. Site coverage under DDH (para. 7(a)) — later varied by 3/2020A

| Rule | Detail |
|---|---|
| Accountable | **All** building components on the lot, including **projections** and **underground structures outside footprint** (water tanks, plant rooms), unless **expressly exempted** under lease |
| Disregarded | Architectural features, cladding, minor features from the building face with **no significant bulk impact**, if BA disregards them **without** s.42 modification |
| Modern SC clause “at or above ground” | Does **not** catch **underground** buildings/structures |
| JPN 1/2 features | Balconies, UP, NSPE walls **SC-accountable** unless BA-exempt **and** lease exemption (those JPNs) applies |
| Curtain wall | SC-accountable unless BA-exempt **and** lease has the curtain-wall GFA/SC definition clause; if no exemption SC → **modification** after BA exemption |

**SD takeaway:** Assume **basements, tanks and plant outside the tower** count for lease SC unless the SC clause is ground-up only or an express exemption exists.

### 4. Building height (para. 7(b)) — follow JPN 5

| Scenario | How height is read |
|---|---|
| Default | **JPN 5** (from 15 May 2019) |
| JPN 5 does not apply (lease has different specs, or **no** development-intensity provisions) | Height from **lowest formation level** of any part of the building (**including basement and stilts**) to **top of highest main-roof slab** |
| Not counted as lowest level | Localised sunken slabs: lift pits, sump pits, manholes, sunken planters, sunken trenches for toilets/utilities |
| Counted as basement | **Underground tanks or plant rooms** |
| “Mean formation level” leases | Average of **highest + lowest** formation levels of the land on which any part stands, **same lowest floor** (incl. lowest basement) |
| Existing approved form | LandsD may recognise previously approved/no-objection height on the facts + legal advice |
| Rooftop features | If height is **not** an absolute cap, follow **JPN 5** size/height for rooftop ancillary / architectural features / signboards (if lease-permitted) |
| No explicit height SC | Pure aesthetic height **not** normally a DDH refusal |

**SD takeaway:** On old leases with no PR/GFA, height is **lowest basement/stilts to main-roof slab** — hide tanks in the basement storey count.

### 5. Stilts, fill, parking, plates, walls, projections (para. 7(c)–(j))

| Topic | Lock |
|---|---|
| **Stilts** | Discouraged even without anti-stilt SC. If no alternative: **minimise**; **guide max 8 m**; **not automatic**; architectural + landscape screening (App.); justifications + treatment with GBP |
| **Soil fill** under houses/gardens/flats on **flat** land | Generally **not** acceptable. Sloping/undulating: **≤2 m** normally OK; deeper on merits |
| **Parking** | Extra spaces / L/UL / undesignated areas → LAO PN **4/2014**. **Stacked** parking with **excessive headroom** not acceptable (avoids extra spaces) |
| **Transfer plate** | Allowed under DDH if **BA** accepts it as non-accountable GFA under BO (JPN 5 streamlining) |
| **Walls** | Follow **BA** on boundary / party / parapet / dividing walls |
| **External finish / shape** | LandsD would **not normally** restrict; existing-lease enforcement of this **normally waived** |
| **Encroachment** | Still LAO PN **4/2008** — no Government-land encroachment regardless of DDH |
| Canopies / architectural features over streets | Generally OK if no planning/aesthetic/env/road-safety objection; **BA usually followed** |
| Pipes/gutters over streets | Generally OK if projection **≤30 mm** at **≥2.5 m** above ground (**B(P)R 7(2)**) and no TD/HyD objection |
| Noise barriers over streets | If lease has NIA / noise-barrier SCs; design agreed by EPD, PlanD, HyD, TD, BD and matches approved NIA |
| Cladding/CW beyond lot | Entire IB conversion: PN **1/2010B**. Partial conversion/other buildings: normally if BA + TD/HyD etc.; **modification** + fee/premium |

**SD takeaway:** Cap stilts at **well under 8 m with screening**, keep garden fill **≤2 m**, and do **not** buy extra parking with tall stacks.

### 6. Process (paras. 6, 8–10)

- DDH/DD approval **bundled with GBP Stage 1** (PN 4/2018); in-principle approval is **not** proof of other lease compliance (area still Stages 2–3).
- List of aspects is **not exhaustive**; Director may add case-specific items.
- DLO **refusal** under DDH/DD after para. 7 (and extra aspects) needs **Building Committee III** (DD LandsD chair).
- Appeal to the Director; decision **final**.

**SD takeaway:** Fix DDH issues in the **Stage 1** GBP pack — there is no later separate DDH meeting unless BCIII on a refusal.
