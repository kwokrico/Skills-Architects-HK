# Guidelines Index (English)

**Issued by:** Buildings Department
**Scope:** The guidelines, booklets, and extracts in `source_reference/` (24 files). Codes of practice that sit in other Buildings Department folders are not in this index. This library was not checked against the live departmental website.
**How to use:** The number links to the critical summary in `summaries/`. The official title links to the source file in `source_reference/`. Where one summary covers more than one file, the companion files are linked in that row.
**Titles:** The official title is the heading printed in the file. Where the text layer has no cover heading, the row says so and uses the title printed in the PDF document properties or the document’s own description.
**Caveat:** Desk reference only. Before a submission, check the current guideline, the Buildings Ordinance, and the practice notes named in the summary.
