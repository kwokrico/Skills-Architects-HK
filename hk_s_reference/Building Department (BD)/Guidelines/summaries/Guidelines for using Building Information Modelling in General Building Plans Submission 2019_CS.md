# Guidelines for using Building Information Modelling in General Building Plans Submission 2019
**Architect critical summary for schematic design**
2019. The PDF document title is Guidelines for using Building Information Modelling in General Building Plans Submission 2019 | Buildings Department

> Scope note: How to prepare a native building information model that accompanies general building plans. The prescribed plans remain the statutory submission. A later guideline covers statutory plans other than general building plans.

## Regulatory Overview
The Building Authority accepts native building information files for general building plans only from Revit 2017 or later, saved as .rvt, or from ArchiCAD 21 or later, saved as .pla, unless another application has been accepted in advance by a tested sample. Each file is limited to 500 MB, is stored on a non-rewritable DVD-ROM, and must match the prescribed plans.

## Critical main topics and subtopics

### 1. File format and media (section 4.3)
| Rule | Lock |
| --- | --- |
| Media | Non-rewritable DVD-ROM in ISO/IEC 13346:1995 format. Other electronic media are not acceptable unless the Building Authority agrees |
| Size | Each file not more than 500 MB |
| Contents of the file | 3D model, views, schedules, and pre-set sheets (plans, area diagrams, calculations) from which the hard copy of the prescribed plans is produced |
| Hierarchy | A text file on the DVD describes the linked-file structure |
| Rejected formats | .dwf, .dwfx, .bimx, and other lightweight, compressed, or zipped formats |
| Other software | Prior acceptance. Submit at least one test sample and the enabling software. Web-based building information software is not accepted |
| Add-ins | The file must serve its purpose in the Department’s standard Revit or ArchiCAD without add-ins or in-house scripts |
| Self-contained | Opens on a standalone computer. External references such as spreadsheets and PDF files sit in sub-folders on the same DVD, with links connected |
| Identity of information | Information in the model shall be identical to the information on the prescribed general building plans |
| Stripped content | Lighting, reflected ceiling plans, building services, and similar data that are irrelevant to the statutory submission shall be removed |
| Title block | Drawing number, revision, legends, site or project title, and drawing title on every drawing |

**SD takeaway:** Export a self-contained Revit 2017-or-later .rvt or ArchiCAD 21-or-later .pla, at or under 500 MB, on a DVD, with no dependence on an add-in.

### 2. Level of development and plan content (sections 4.4 and 5.2)
The guidelines refer to Level of Development (LOD) 100, 200, 300, 350, 400, and 500. Authorized persons are advised to adopt LOD 300. LOD below 300 may be used for an indication such as mechanical plant or exhaust ducts, and LOD above 300 for special design details.

The block or key plan is at a scale not less than 1:500 and includes the site boundary, the site area coloured pink (recommended RGB 255, 218, 236), and the lot number. Existing and proposed works are coloured. The preferred colour code is Appendix A of PNAP ADM-9. Gross floor area diagrams use the colour code in section 5.2.10. Views required to check the model against the codes, practice notes, and circular letters shall be included in the file.

**SD takeaway:** Model to LOD 300, colour the site pink on a 1:500 key plan, and generate the gross floor area diagrams from the same file as the plans.
