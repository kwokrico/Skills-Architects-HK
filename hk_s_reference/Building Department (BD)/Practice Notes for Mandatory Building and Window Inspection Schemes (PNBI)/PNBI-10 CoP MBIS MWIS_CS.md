## Regulatory Overview

BD’s Technical Committee feedback produced five amendment packages to the 2012 CoP, consolidated in the **2023 Edition** (textual refinement + numbering cleanup per May 2023 footnote). Packages: **App. A Sep 2014**, **App. B Mar 2017**, **App. C Apr 2018**, **App. D Jul 2020**, **App. E Jan 2022**. Applies wherever MBIS/MWIS inspection and repair are carried out under Cap. 123 ss.30B–30C / Cap. 123P.

### 2. Hard split — windows vs curtain walls (App. A)

| Element | Scheme |
|---|---|
| Windows, glass louvers, **window walls** (private + common) | **MWIS** |
| **Curtain walls** | **MBIS only** |
| Internal glass partitions | **Out of MWIS** |
| G/F shopfront **show windows** | **Out of MWIS** |

**SD takeaway:** Mixed CW + punched windows + window wall = two regimes, two professionals, two repair tracks.

### 3. Window inspection & repair specs that belong in SD details (App. A §§10–11)

#### Who inspects
- Natural-person QP → inspects **personally**  
- Company RGBC/RMWC QP → **AS** inspects personally (see PNBI-5)  
- Cover **all** elements of openable sash **and** fixed panel; inspect from **interior** as far as practicable  
- Emergency window risk → advise immediate remedial action + notify BA  
- Prevent fall during inspection; temporarily secure (e.g. safety rope) if needed (2017 add-on)

#### Safety vs non-safety
- **Mandatory:** repair/replace all defective components **affecting window safety** (screws, rivets, broken/cracked glass called out expressly in 2017)  
- Renewed components ≥ original material/size; whole-window replacement **not** required if suitable repair restores safety  
- Maintain specified **FR** capability; if Cap. 502 / Cap. 572 applies, meet those window FR requirements  
- **Not** MWIS-mandatory: weather sealant, weather gasket/strip, etc. — advise as optional concurrent repair; clearly label safety vs recommended items  

#### Best-practice replacement (lock into window specs)
| Component | Best practice |
|---|---|
| Hinge replacement | Prefer **4-bar** hinge; stainless steel; adjustable friction shoes; bars preferably ≥ **2.5 mm** thick |
| Rivets | Stainless, **4.8 mm** Ø |
| Screws | Stainless, **5 mm** Ø |
| Anchorage for new 4-bar | Insert SS or HDG plate/bar/angle ≥ **3 mm** for screw threads; **or** locally thicken section to ≥ **5 mm**; else QP must prove existing thickness gives sufficient anchorage |
| Enlarged corroded holes | Add extra SS rivets/screws at proper positions |
| Other aluminium window install rules | PNAP **APP-116** |
| After repair | Advise owners: lubricate hinges; clean dust/dirt from hinges & tracks |

Component defect tables cover aluminium, steel/iron, timber framed windows **and window walls** (glass/fins, mullions/transoms, brackets/spider fixings, anchors, glazing beads, **structural sealant** — specialist may be engaged).

### 4. Cantilevered slab canopy over street — investigation density (App. B, 2017)

For CSC projecting over street, RI **must** investigate and assess per CoP §§4.3.3–4.3.4:

| Action | Requirement |
|---|---|
| Open-up at root adjoining parent | Assess main-bar corrosion |
| Coring | Actual slab thickness, compressive strength, carbonation |
| At open-ups measure | Bar diameter/spacing, cover, screed + waterproofing thickness |
| Geometry | Span; parapet / downturn / architectural features |
| Minimum locations | **≥ 2** per discrete canopy **or 1 per 6 m** along canopy length — **whichever greater** |

Also watch: ponding, defective drains, seepage, UBW on/attached to soffit.  
**SD:** Do not bury cantilever roots behind irremovable cladding; design access for future open-up/coring.

### 5. Concealed external walls & signboards — 30% rule (App. D, 2020)

New CoP §3.3.2**(J)**:

| Condition | Minimum exposure |
|---|---|
| Any EW with concealed elements | Inspect **≥ 30%** of that wall area |
| Wall concealed by wall signboard with display area **> 40 m²** | Enable inspection of **≥ 30%** of concealed area (temporary display removal or other feasible method); expand if defects found |

**SD:** Large wall signs and closed rainscreens without inspection panels = statutory opening-up cost and programme risk.

### 6. Other MBIS deltas that affect design / documentation

| Topic | Rule |
|---|---|
| Cladding anchors | Open only if external inspection shows obvious defects / corrosion signs |
| Common drains in private premises | Exposed **or** in ducts — access from premises **≥ every 3 floors** + at duct outlet |
| Drainage defects | Include **misconnected common drains** affecting sanitary condition / public health; must be rectified |
| Drainage scope (2022) | Explicitly includes **anti-syphonage** and **ventilating** pipes |
| Pre-inspection (2022) | Check outstanding BO **repair / investigation orders** that MBIS will cover, plus Cap. 502/572 FS Direction status |
| Finishes after repair (2018) | Reinstate EW rendering finish (e.g. paint) to **match existing appearance**; same idea for common corridor/lobby finishes |
| False ceilings | Defective common corridor/lobby false ceilings → remove and/or replace |
| Daily inspection records | Must keep and submit to BD on completion |
| Emergency building safety / UBW | Notify BA + alert owners/occupants immediately; advise removal of all identified UBW |

### 7. RI supervision team (App. B / E — App. VI)

| Rule | Detail |
|---|---|
| Minimum | Supervise ≥ frequency/extent in App. VI |
| Team | Optional Level 1 + Level 2 representatives; RI retains overall responsibility |
| Level 1 quals | ≈ TCP **T1** (Building Works / Class I MW) per CoP for Site Supervision |
| Level 2 quals | ≈ TCP **T3**, **or** passed specified top-up + ≥ **5 years** relevant experience |
| RI personal duty | First inspection of works/proof tests specified for **Level 2** |
| Frequency | Level 1 & Level 2: **fortnightly** (cannot combine frequencies if L2 also does L1 duties) |
| Notify BA of team | ≥ **7 days** before appointment / within **7 days** of change |
| Class I MW | Also Technical Memorandum + CoP for Site Supervision |
| Proof tests (examples) | Pull-off = Level **2**; hammer-tapping = Level **1** |

Key Level 2 hold points for SD/tender: first trial bedding mortar; pull-off tests; examine rebar + substrate before bond coat / concreting; structural member replacement with temporary supports; NDT of welds.
