# PNBI-7 Building Inspection Report
**Architect critical summary for schematic design**  
First issue April 2016 | Last revision April 2018 | This revision August 2020 | Buildings Department

> Scope note: Content and evidence standard for the MBIS **inspection report** under Cap. 123P B(I&R)R **s.12(2)** / **s.30(1)(a)**. Checklists are for RI QA — **not** submitted to BA. At SD, use the checklists as a **defect / inspectability / UBW risk map** for common parts, EW, CW, canopies and balconies.

---

## Regulatory Overview

Within **7 days** after completing a prescribed building inspection, the RI must submit an inspection report to the BA and deliver a copy to the person for whom the inspection was carried out. Report content follows the CoP for MBIS/MWIS; PNBI-7 supplies checklists (App. A) and samples (App. B projections; App. C common parts/EW). Submit **hard copy + non-rewritable DVD-ROM** PDF at **200 dpi**. BA runs random audits; blatant/repeated breaches risk prosecution and/or discipline.

## Critical main topics and subtopics

### 1. Report spine (Master Checklist SC1) — what must be evidenced

| Block | Must include |
|---|---|
| Building data | OP date; original/current use; storeys/units; approved plans; materials; prior inspection/repair; IO / management |
| Reference docs | Approved building/structural/drainage/A&A plans; MWCS plans; **s.39C** validation (signboard, AC frames, drying racks, window canopies); **FS Directions** status; prior large repair records |
| Method | Visual + any NDT; particulars of RI’s representative if used |
| Results | Element checklists SC2–SC9 as applicable; MBIS inspection forms; elevation photos; defect summary table + annotated photos / mark-ups |
| Assessment | Concise whole-building assessment; detailed investigation if serious defects / unknown cause; interim maintenance advice to next cycle |
| Repair proposal | Mark-ups splitting **MWCS** (class/type/item) vs **full approval+consent**; method/materials/specs/precautions; **proof-test** proposal; supervision-team particulars if same RI continues |
| Upgrading (optional) | Cap. 502 / Cap. 572 FS Works recommendations — **distinguish** from mandatory MBIS repair |

### 2. Element checklists — SD risk map

#### SC2 External wall
- Close-distance visual + hammer-tapping at representative areas (cross-ref PNBI-6)  
- If access insufficient: re-inspect at repair stage / IR thermography / recent condition records  
- Hunt: cracks, spalling, loose/missing tiles/rendering; fins/grilles/cladding/appendages — dilapidation, corrosion, distress, loose fixings, displacement  

#### SC3 Structural elements
- Close visual + hammer-tapping  
- **Cantilevered slab-type → fully exposed**; **other structure → ≥ 30% exposed**  
- Defects: dampness, rust stains, cracks, spalling, delamination, exposed rebar, voids/honeycomb, deformation, abnormal separation from adjoining buildings  
- Flag canopies / balconies / fins / AC platforms / drying racks / planters → SC8 / SC9  

#### SC4 Fire safety provisions
- FS Direction status (FS(CP)O / FS(B)O) and whether upgrading completed  
- MOE: exit signs, lighting, balustrades/handrails, door swing, blocked routes, defective treads  
- MA: blocked access (esp. rear lane), fireman’s lift lobby, EVA, lobby integrity  
- FRC: defective FR materials; services through compartments; fire doors (hinges, glass, self-closers, FR rating); non-emergency services in stairs/lobbies; fire dampers/shutters; staircase top vents  

#### SC5 Drainage
- Close visual at representative areas; **common drains inside private premises ≥ every 3 floors**  
- Underground: CCTV or other methods / recent records  
- Defects: leakage, rusty supports, joint dislocation, blockage/overflow, untreated trade effluent, **misconnection** to public systems, bracket failure, manhole/channel damage, missing mica flaps / vent gratings  

#### SC6 UBW / change in use
- Structures on common parts / roofs / yards / lanes; projecting UBW & signboards  
- FS-affecting UBW (escape obstruction, unprotected openings, refuge-floor structures, cockloft doors to single stairs, deficient FRC/MOE, fireman’s lift changes, removed FR doors/shutters)  
- Structural / drainage / EW / parapet / BFA alterations; balcony/canopy additions; **suspected subdivided flats** (extra doors, bells, meters, drain tees)  
- Unauthorised change in use (hazardous storage; exceed MOE / imposed load)  
- Assess: obvious hazard; parent overload/distress; health nuisance; UBW under construction  

#### SC7 Curtain wall (**MBIS, not MWIS**)
- Close visual externally; if external defects → inspect from **inside**  
- Defects: glass, fixings, sealants, **fire stop**, locking devices/hinges, water behind CW  

#### SC8 Cantilevered projecting structures (canopy / fins / features / AC / drying / planter)
- Cantilever slab → **fully exposed**; other → **≥ 30%**  
- Street-overhang **cantilevered slab canopy**: open-up at root for screed thickness, cover, bar size; verify span & slab thickness vs records  
- Check support cracks; soffit/surface defects; metal corrosion/fixings; surface drainage; UBW (thickened finishes / change in use); overload & need for detailed investigation (CoP §4.3.1)  

#### SC9 Balcony / verandah
- Same exposure rules as SC8  
- RC: support cracks; floor/ceiling/parapet (internal) defects  
- Metal railing / glass balustrade: corrosion, loose fixings, broken glass, sealants  
- Drainage; UBW (parapet change, enclosure, thickened finishes); overload / detailed investigation

### 3. Sample report hooks (App. B / C) that matter at SD

- State whether building/premises is **dangerous / liable to become dangerous** or safe  
- Record UBWs even if “no obvious hazard” and advise voluntary removal  
- Demarcate repair items to **MWCS item numbers** (e.g. 2.34 tiles, 2.17 patch concrete, 2.30 AG drainage, 1.25 UG drainage, 3.30 drying racks, 2.5 protective barrier)  
- Call out defects extending from common parts/EW **into flats**; flat entrance doors; incomplete FSDn works; suspected subdivision  
- Cantilevered slab canopy: investigation per CoP §3.4.2 / §§4.3.3–4.3.4; may conclude “no remedial work before next cycle” **with** maintenance advice
