# PNBI-9 Window Inspection Report
**Architect critical summary for schematic design**  
First issue August 2019 | Buildings Department

> Scope note: When and what a MWIS **window inspection report** must contain (Cap. 123P B(I&R)R). At SD, use the component list as the **safety-critical fenestration checklist** for punched windows and window walls (curtain walls stay on MBIS — see PNBI-10 / CoP).

---

## Regulatory Overview

If a **different QP** is appointed to supervise prescribed window repair, the inspection QP must, within **7 days** after completing the prescribed inspection, submit an inspection report to the BA (hard copy + **non-rewritable DVD-ROM** PDF **200 dpi**), and deliver copies to the repair-supervising QP and the person for whom the inspection was carried out (B(I&R)R **s.14(4)(a)** / **s.30(3)(b)**). If the repair QP is not also the RC, that QP must pass the BA-submitted documents and any revised proposal (s.23(2)) to the RC (s.30(4)(a)). Where the same QP does inspection and repair, a full report to BA is not forced by para. 1 — but delivering a copy to the client is **strongly recommended**. BA audits; blatant/repeated breaches risk prosecution and/or discipline.

## Critical main topics and subtopics

### 1. Trigger matrix

| Appointment pattern | Report to BA? | Deadline | Also deliver to |
|---|---|---|---|
| Different QP for repair supervision | **Yes** | 7 days after inspection | Repair QP + client |
| Same QP for inspection + repair | Not required by para. 1 | — | Strongly recommend copy to client |
| Repair QP ≠ RC | Pass BA docs + revised proposal to RC | Per s.30(4)(a) | RC |

---

### 2. Sample report content (Appendix) — minimum evidence set

| Field | Requirement |
|---|---|
| Header | Statutory notice no.; BD file ref.; address; inspection & report dates; QP name, registration no., expiry, signature |
| Per window | Location; window number; components & quantities |
| Safety components tracked | Hinge; screw/rivet (per hinge); dual lock; cam lock; glass pane; others (frame, sash, gasket securing glass, aluminium glazing bead) |
| Non-mandatory | e.g. waterproof gasket — optional advise-only (aligns with PNBI-10 / CoP: weather seals not MWIS-mandatory) |
| Result | Defects / repair proposal per window |
| Annexes | Location plan with window numbers + defect call-outs; photo record per window |

---

### 3. Defect types that drive mandatory repair (from sample + CoP)

Treat as safety-related unless QP justifies otherwise:

- Hinge jerky / deformed / seriously corroded / missing parts  
- Loosened or oxidised rivets/screws  
- Broken or loosened lock sets (dual lock, cam lock)  
- Cracked / broken glass  
- Missing/defective glazing bead or gasket **securing** the pane  

**SD takeaway:** Spec windows so hinges, fixings and locks remain **inspectable and replaceable from inside** (CoP: inspect from interior as far as practicable). Prefer details that accept **4-bar stainless hinges** and stainless rivets/screws on future MWIS repairs (PNBI-10 best practice).

---

### 4. Out of MWIS (do not put on the window report track)

- **Curtain walls** → MBIS  
- **Internal glass partitions**  
- **G/F shopfront show windows**  

(See PNBI-10 App. A / CoP §§8 & 10.)
