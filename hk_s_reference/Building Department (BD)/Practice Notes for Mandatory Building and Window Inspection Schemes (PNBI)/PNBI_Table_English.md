# PNBI Series Index (English)

**Scope:** 10 practice notes in this library (PNBI-1 to PNBI-10).
**How to use:** Jump from the contents to a topic. Each number opens `summaries/[code] [title]_CS.md`. The PDF is in `source_reference/`.
**Titles:** Official titles are the PDF cover lines.
**Caveat:** Desk reference only. Check the current Buildings Department PNBI before use. This library's 1–10 run was not checked against the live Buildings Department list.

## Inspection and completion reports

| No. | Official title | In one sentence |
| --- | --- | --- |
| [PNBI-7](<./summaries/PNBI-7 Building Inspection Report_CS.md>) | Building Inspection Report | Within 7 days of a prescribed building inspection, submit the inspection report to the Building Authority and a copy to the client; the preparation checklists are for the inspector’s own check and are not submitted. |
| [PNBI-8](<./summaries/PNBI-8 Building Completion Report_CS.md>) | Building Completion Report | Within 14 days of prescribed building repair, submit the completion report to the Building Authority and a copy to the client as the close-out record of the repair. |
| [PNBI-9](<./summaries/PNBI-9 Window Inspection Report_CS.md>) | Window Inspection Report | When a different qualified person will supervise window repair, submit the inspection report to the Building Authority within 7 days and copy the repair supervisor and the client; if the same person does both, still give the client a copy. |
