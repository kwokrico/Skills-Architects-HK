# PNBI-1 Practice Notes for Mandatory Building and Window Inspection Schemes
**Architect critical summary for schematic design**  
First issue December 2012 | Buildings Department

> Scope note: Gateway PN for the whole PNBI series. It does **not** add dimensional rules. At SD it tells you which **rule stack** governs future MBIS/MWIS cycles on the building you are designing or altering — CoP for MBIS/MWIS, Cap. 123N MWCS, and the PNAP/PNRC list in Appendix I.

---

## Regulatory Overview

PNBI-1 defines the PNBIs as BD’s practice-note channel for Registered Inspectors (RI), Qualified Persons (QP), Registered Contractors (RC) and stakeholders implementing **MBIS** (Cap. 123 s.30B) and **MWIS** (Cap. 123 s.30C). Technical standards and procedures live in the **Code of Practice for MBIS and MWIS**; most prescribed repairs are expected to run as **minor works** under the Buildings Ordinance.

---

## Critical main topics and subtopics

### 1. Lock the reference stack before façade / fenestration SD

| Layer | What it controls | SD use |
|---|---|---|
| **CoP for MBIS & MWIS** | Inspection scope, repair standards, proof tests, RI/QP duties | Design envelopes, projections, windows for inspectability + durability through next cycle |
| **PNBI series** | Forms, appointment rules, projections scope, report formats, CoP amendments | Programme, who inspects what, documentation |
| **PNAP / PNRC** (App. I) | Material, cladding, windows, site safety, MWCS, FS Cap. 572, etc. | Specs and detailing cross-checks |
| **Technical Guidelines on MWCS** | Simplified requirements for most MBIS/MWIS repairs | Avoid full s.14 consent path where MWCS applies |

**SD takeaway:** Treat MBIS/MWIS as a **lifecycle constraint** on common parts, external walls, projections, signboards and windows — not only as an existing-building notice regime.

### 3. Design implications that follow from “majority = minor works”

- Spec and detail so future MBIS repairs can stay on the **MWCS** track (class / type / item clear on mark-up plans).
- Non-minor / non-exempt work still needs **full BA approval + consent** (Cap. 123 s.14) — flag early for large structural, CW, or FRC packages.
- Coordinate with **CoP on Access for External Maintenance** and ADV-14 so façades remain inspectable without relying only on private-premises access.
