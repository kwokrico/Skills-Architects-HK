# Code of Practice for Building Works for Lifts and Escalators 2011
**Architect critical summary for schematic design**  
2020 Edition (September 2020 revision) | Buildings Department / Building Authority

> Scope note: This CoP covers **building works** that accommodate lifts and escalators — shaft, pit, headroom, machine/pulley rooms, escalator landings — deemed to satisfy **Building (Construction) Regulations reg. 9A**. Fire resisting construction → **FS Code Part C**. E&M / lift safety → Cap. 618 CoPs (EMSD). Firemen’s lifts → **B(P)R 41B + FS Code Part D**. Do not size shafts from this summary alone without checking Table 1 against selected load/speed and coordinating with the lift supplier / RSE.

---

## Regulatory Overview

This Code applies to **building works for lifts and escalators** in general. **Sections 2–3** cover passenger/goods lifts under B(C)R 9A (except service lifts); **Section 4** covers **service lifts** (rated load ≤250 kg; car floor ≤1 m²; car height ≤1.2 m); **Section 5** covers **escalators** (including passenger conveyors). Machine-room-less (MRL) lifts are allowed only where the **lift model is EMSD-approved**, with model particulars and approval shown on the GBP.

## Critical main topics and subtopics

### 1. Lock lift type and shaft package first (SD killer checklist)

| Decision | SD takeaway |
|---|---|
| **Passenger / goods lift** | Size well, pit, headroom, entrance, machine room from **Table 1** (by rated load + speed) |
| **Service lift** | Use **Section 4** — not Table 1; pit often not required |
| **MRL** | Table 1 **machine-room area / overall headroom do not apply**; must be EMSD-approved model; control-panel access from **common areas** only |
| **Firemen’s lift** | This CoP + **B(P)R 41B + FS Code Part D** (lobby, size, power, etc.) — coordinate early |
| **Deviation from Table 1** | Allowed only with written confirmation from registered lift engineer / authorised person of registered lift contractor (fit, safe maintainability, Cap. 618 compliance) |

**SD takeaway:** Fix load (kg / persons), speed (m/s), and conventional vs MRL **before** locking floor-to-floor, roof plant, and core width.

### 2. Table 1 — minimum installation dimensions (architect’s core)

Use Table 1 for: **car (Cw × Cd)**, **well (Ww × Wd)**, **clear entrance (Ew × Eh)**, **pit depth (Ph)**, **headroom (Sh)**, **machine room (Ra / Rw × Rd / Rh)**, **overall headroom (Uh)**. See CoP Figure 1 for annotation of Cw, Cd, Ww, Wd, etc.

#### 2.1 Quick reference — common loads (extract; verify full Table 1 for exact speed row)

| Rated load | Persons | Typical car Cw×Cd | Well Ww×Wd (typical) | Entrance Ew | Pit Ph (by speed) | Headroom Sh (by speed) | MR area Ra (typ.) | Overall Uh (by speed) |
|---|---|---|---|---|---|---|---|---|
| **630 kg** | 8 | 1100×1400 | 1800×2100 | 800 | 1700–1800 | 4450–4850 | 15 m² | 7250–7650 |
| **800 kg\*** | 10 | 1400×1350 | 1900×2300 | 800 | 1700–2800 | 4450–5650 | 15–15+ | 7250–8450 |
| **900 kg** | 12 | 1600×1350 | 2100×2100 | 900 | 1700–2800 | 4450–5650 | 15 | 7250–8450 |
| **1000 kg** | 13 | 1600×1400 | 2400×2300 | 1100 | 1800–3650 | 4300–6300 | 20 | 7200–10400 |
| **1250 kg** | 16 | 1950×1400 | 2600×2300 | 1100 | 1900–3650 | 4400–6300 | 22 | 7250–10400 |
| **1350 kg** | 18 | 2000×1500 | 2600×2300 | 1100 | 1900–3650 | 4800–6300 | 22 | 7800–10400 |
| **1600 kg** | 21 | 2000×1750 | 2600×2600 | 1100 | 1900–3650 | 4800–6300 | 25 | 7800–10600 |

\*750 kg: Ca (max.) = **1.9 m²** (Table 1 Note 4).

**Speed effect (SD critical):** At ~**≥2.0 m/s**, pit and headroom jump sharply (often Ph ≈ **2800** mm; Sh ≈ **5650–6150** mm). At **3.5 m/s**, Ph ≈ **3650** mm; Uh can exceed **10 m**. Do not assume low-rise pit/headroom for high-speed cores.

#### 2.2 Table 1 design rules (Notes)

| Rule | Requirement |
|---|---|
| Intermediate load/speed | **Linear interpolation** from Table 1 |
| Cw × Cd | Product must **not exceed** Ca (max. car area) |
| Machine room Rw × Rd | Each ≥ tabulated; product ≥ Ra |
| Load **>1600 kg** | Ca +**0.16 m²** per extra 100 kg; Ra +**0.6 m²** per extra 100 kg; other dims ≥ 1600 kg same-speed values |
| Alt. to MR floor area | **Machine-room clearances** approach accepted (GBP general note — Appendix sample); verify on site at completion |
| Lower/higher speeds than listed | Table dimensions still apply (extrapolate per Note 2) |

**SD takeaway:** Core depth = well depth + landing lobby + structure. High-speed lifts can force **extra storey-equivalent** headroom at roof and deep pits at basement — flag early in massing.

### 3. Liftwell enclosure, doors, and emergency access

#### 3.1 Enclosure

| Item | Rule |
|---|---|
| Enclosure | **Totally enclosed** imperforate walls, floor, ceiling (FRC per FS Code Part C) |
| Materials | Non-combustible, durable, non-dust-creating; adequate structural strength |
| Inner wall face | Continuous smooth hard vertical surface (unless inaccessible from car top / via CW & supports) |
| Exclusive use | Well **for lift only** — no other cables/devices; **no fire sprinklers** |

#### 3.2 Inspection / emergency doors & traps

| Opening | Size | Key design rules |
|---|---|---|
| **Inspection door** | ≥ **1.4 m** H × **600 mm** W | Safety/servicing only; imperforate; **must not open into well** |
| **Emergency door** | ≥ **1.8 m** H × **500 mm** W | Readily accessible to rescuers; bilingual danger notice (≥25 mm characters) |
| **Inspection trap** | ≤ **500 × 500 mm** | Key lock; reclose/relock without key |
| **Landing sill spacing** | If consecutive landing sills **>11 m** | Provide intermediate emergency doors so sill spacing ≤**11 m** |

**Locks (3.2.8):** Dual key-operated locks (two keys simultaneously from outside); openable from inside without key; warning figure ≥100 mm at keyholes — **except** where inadvertent entry is unlikely (landing doors used as emergency doors, or door sill ≥**1 m** above adjoining floor → single designated key OK).

#### 3.3 Walls facing car entrance (350 mm band below each landing sill)

| Item | Rule |
|---|---|
| Surface | Continuous smooth hard vertical face; extend ≥**25 mm** beyond full car entrance width each side |
| Forbidden | **Plaster-faced** and **glass** walls in this band |
| Projections >5 mm | Connect to lintel below **or** splay underside ≥**75°** from horizontal for ≥**20 mm** (metal/concrete/similar) |

### 4. Liftwell ventilation (SD plant / roof coordination)

| Item | Rule |
|---|---|
| Principle | Well suitably ventilated; **must not** ventilate other rooms (except rooms serving the lifts) |
| Opening location | **Top of well** → open air (direct, ducted, or via machine/pulley room) |
| Area | ≥ **1%** of well horizontal cross-section; **never < 0.3 m²** net free area per well |
| Shared well (4 / 5 / 6 lifts) | Min vent **0.4 / 0.5 / 0.6 m²** respectively |
| Fall protection | Ferrules projecting ≥**50 mm** above slab/FFL at openings over the well |
| Partitioned multi-lift well | If solid walls separate each lift → **each** well needs its own 3.3.2 vents |

**SD takeaway:** Reserve roof/machine-room vent path early; do not “borrow” lift-shaft vents for toilets, corridors, or other rooms.

### 5. Space below lift / multi-lift wells / pit

#### 5.1 Space below car or counterweight

| Preference | Do **not** place liftwell above space accessible to persons |
|---|---|
| If accessible space below | Pit base designed for ≥**5 kPa** imposed load **and** either solid pier under CW buffer to solid ground **or** CW fitted with safety gear |

#### 5.2 Several lifts in one well

Full-height partition of adequate strength (solid wall, wire mesh, etc.) between moving parts of different lifts — from pit floor through full well height and across full well depth. Solid-wall separation → separate ventilation per well.

#### 5.3 Lift pit

| Item | Rule |
|---|---|
| Bottom | Smooth, approximately level (except buffer/guide/jack bases and drains); **impervious** to water after equipment built-in |
| Access door if Ph **>2 m** | Mandatory — to stair meeting 3.12.4; imperforate; not into well; key lock; openable from inside; ≥**1.4 m** H × **600 mm** W; danger notice |
| Ph **>1.6 m and ≤2 m** | Access door also required **if layout permits** |
| No other access | Permanent means of access + handholds inside well from landing door; must not project into clear running space; handhold ~**1.3 m** above sill and ≤**0.9 m** from landing opening |
| Fall-arrest anchorage | ≥1 point adjacent to **lowest** landing door, **1.5–1.8 m** above FFL, readily accessible — **not required** if compliant pit access door provided |

---

### 6. Outside the well (landing interface)

| Item | Rule |
|---|---|
| Landing sill | Sufficient strength for loads entering the car |
| Water control | **Slight counter-slope** in front of each landing sill — no washing/sprinkling/drainage into well |
| Fire notice | At each landing (or every other door if paired lifts): bilingual “IN CASE OF FIRE DO NOT USE THE LIFT” — characters ≥**15 mm** |

### 7. Machine and pulley rooms (conventional lifts)

#### 7.1 Location, use, and access (high SD impact)

| Item | Rule |
|---|---|
| Enclosure | Special room — solid walls, ceiling, door and/or trap |
| Preferred location | **Above** the well |
| Use | Lift equipment only; allowed extras: service-lift/escalator machines; A/C or ventilation for the room; FSI as required by DFS for the room |
| Sprinklers | **Not normally** fitted in machine/pulley rooms |
| Access route | From **common areas only** — never through private premises; clear & safe at all times |
| Access height | Ways and entrances ≥**2 m** high (door sills/edges ≤**400 mm** OK) |
| Level change **>0.6 m** | **Stairs** required (see 7.2); ≤0.6 m → fixed ladder + top platform with railings + handholds |
| Heavy equipment | Provide means of access for hoisting so plant need not be manhandled on stairs |
| MRL exception | No machine room if EMSD-approved; still need clear/safe access to control panels/cabinets from common areas |

#### 7.2 Stair standard for machine-room access (3.12.4)

| Item | Rule |
|---|---|
| Width | ≥ **900 mm** |
| Tread / riser | Tread ≥**225 mm** (anti-slip); riser ≤**175 mm** |
| Flight | ≤ **16** steps without landing |
| Handrails | Both sides |
| Outer edge barrier | ≥ **1.1 m** high |

#### 7.3 Machine / pulley room dimensions & openings

| Item | Rule |
|---|---|
| Clear height (machine room) | ≥ **2.1 m** to underside of structural roof beams (access & working areas) |
| Pulley room height | ≥ **1.5 m** under roof |
| Multi-level floor | Level difference >**500 mm** → stairs/steps + guard rails |
| Recesses / channels | Recess >500 mm deep and <500 mm wide, or channels → cover with ≥**4 mm** chequer plate (or equiv.) |
| Access door | Machine room ≥**600 mm** W × **1.8 m** H; pulley room height ≥**1.4 m**; **must not open inward** |
| Person trap door | Clear ≥**800 × 800 mm**; counter-balanced; support 2 persons (**2000 N**); not open downward |
| Notices | Bilingual danger notice on doors/traps (≥25 mm) |
| Holes above well | Minimise; ferrules ≥**50 mm** above slab/FFL |
| Hoisting | Metal supports/hooks with SWL notice in MR ceiling/beams **and** at liftwell ceiling soffit (car / rope replacement) |

#### 7.4 Appendix — alternative machine-room clearances (GBP note)

If using clearances instead of Table 1 Ra footprint, show on GBP:

| Clearance | Minimum |
|---|---|
| In front of control panels/cabinets | Depth ≥**0.7 m**; width ≥**0.5 m** or full panel width (whichever greater) |
| Moving parts / manual emergency operation | ≥ **0.5 × 0.6 m** |
| Access ways to working space | ≥ **0.5 m** (or **0.4 m** if no moving parts / hot surfaces) |

### 8. Service lifts (Section 4) — compact rules

| Topic | Rule |
|---|---|
| Definition | ≤**250 kg**; car floor ≤**1 m²**; car height ≤**1.2 m** |
| Enclosure / FRC / exclusive use / multi-lift partition / entrance wall band | Align with passenger-lift principles (cross-refs to §3) |
| Pit | **Not required** unless lowest serving level at/near floor level; if provided, drain; if depth >**1 m**, permanent access + handholds |
| Below accessible space | Safety gear on car and/or CW per Cap. 618 CoP; well bottom sized for safety-gear / buffer forces |
| Landing notice | “SERVICE LIFT — PERSONS FORBIDDEN…” (≥**25 mm**) |
| Machinery ≥150 kg | Floor ≥**1.5 × 1.5 m**; clear height ≥**1.2 m**; door ≥**1.0 m** H × **1.2 m** W |
| Machinery <150 kg | Depth ≤**600 mm**; clear height ≥**800 mm**; door ≥**800 mm** H × width = lesser of **900 mm** or full machinery width; **or** reach-all-from-outside + mesh/partition to stop fall into well |
| Access | Per 3.12.2 (stairs/ladder rules); lockable door with danger notice; space for lift only |

### 9. Escalators (Section 5) — SD space killers

#### 9.1 Separate machine / driving / return stations

| Item | Rule |
|---|---|
| Enclosure | Solid walls, ceilings, door/traps if separate rooms provided |
| Use | Escalator equipment only (+ lift/service-lift machines, room A/C, required FSI); **no sprinklers** normally |
| Clear height | ≥ **2.1 m** |
| Access | Prefer stairs; if ladder unavoidable: permanently fixed; if >**2 m** high → safety hoops / fall arrest; top platform + railings + handholds |
| Notices | Danger notice on access doors/traps |

#### 9.2 Landings — unrestricted passenger area (must lock early)

| Item | Rule |
|---|---|
| Width | ≥ distance between escalator **handrail centrelines** |
| Depth (from end of balustrade) | ≥ **2.5 m** — **or** ≥ **2.0 m** if unrestricted width ≥ **2×** handrail-centreline distance |
| Clear height | ≥ **2.3 m** above **all steps** and above the unrestricted landing area |

#### 9.3 Obstructions

| Item | Rule |
|---|---|
| Building parts that may hit riders | Obstruction guards per Cap. 618 Design & Construction CoP (e.g. floor intersections, criss-cross escalators) |
| Handrail to wall / obstruction | Horizontal clearance **never < 80 mm** |

**SD takeaway:** Escalator planning is driven by the **2.5 m (or 2.0 m widened) clear landing** and **2.3 m headroom** — these routinely break atrium and mall sectional schemes if ignored.

### 11. SD checklist (print / pin)

- [ ] Load, speed, conventional vs **MRL** fixed with supplier
- [ ] Well Ww×Wd, pit Ph, headroom Sh / Uh from **Table 1** (watch ≥2.0 m/s jump)
- [ ] Machine room above shaft **or** MRL + common-area cabinet access
- [ ] Roof **vent** ≥1% well area (min 0.3 m²; shared wells higher)
- [ ] Landing sill spacing ≤**11 m** or intermediate emergency doors
- [ ] No programme/habitable space under shaft without 5 kPa + pier/CW gear
- [ ] Multi-lift well: full-height partition (+ per-well vents if solid walls)
- [ ] Pit access strategy if Ph >1.6–2.0 m; anchorage if no pit door
- [ ] Landing **counter-slope** + fire notices
- [ ] MR access from common area; stair ≥900 if rise >0.6 m
- [ ] Escalator: **2.5 m / 2.0 m** unrestricted landing + **2.3 m** clear height + **80 mm** handrail clearance
- [ ] Firemen’s lift / FRC / BFA coordinated in parallel
