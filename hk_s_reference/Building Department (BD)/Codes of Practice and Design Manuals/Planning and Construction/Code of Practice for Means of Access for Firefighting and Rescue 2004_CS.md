# Code of Practice for Means of Access for Firefighting and Rescue 2004
**Architect critical summary for schematic design**  
December 2004 revision (first issue October 1989) | Building Authority / Buildings Department

> Scope note: Guidance on compliance with **B(P)R 41A, 41B, 41C and 41D** — fireman’s access into the building (access staircases, fireman’s lifts, firefighting & rescue stairways) and emergency vehicular access (EVA) to the site. Means of escape, fire-resisting construction, and active FSI are in other Codes. **Superseded for new work by FS Code 2011 Part D** (unified MOE + FRC + MOA); keep this summary for legacy A&A, historic approvals, and understanding the Table 1 / EVA logic that Part D inherited. Read with PNAP APP-75 / APP-136 and contemporaneous MOE 1996 + FRC 1996 (or FS Code 2011 for new work).

---

## Regulatory Overview

This Code sets the **firefighting access envelope**: how many access staircases, fireman’s lifts and firefighting & rescue stairways (FRS) a building needs by use / height / cubical extent (Table 1), how those cores are designed and reached from street level, and how EVA must serve the building façade under B(P)R 41D.

It applies wherever B(P)R 41A–41D must be demonstrated to the Building Authority. Compliance is by **prescriptive provisions** (deemed reliable) or a **fire engineering / alternative approach** for special size, height, use, design, construction or location — assessed against MOE, MOA, FSI, FRC, size, height, use, location and management as a package.

## Critical main topics and subtopics

### 1. Design-critical definitions (§4) — get these right before measuring

| Term | Meaning that drives SD |
|---|---|
| **Access staircase** | Stair designed/constructed so firemen have safe, unobstructed access to **all floors** in a fire |
| **Fireman’s lift** | Lift designed/installed for firemen in a fire |
| **Firefighting & rescue stairway (FRS)** | Stairway that **accommodates both** an access staircase **and** a fireman’s lift |
| **Required staircase** | Access staircase (whether in FRS or not) **or** a staircase required for MOE |
| **Basement** | Any storey below the ground storey from which any required exit route is in an **upward** direction |
| **Ground storey** | Storey containing an entrance from a street; if building fronts multiple streets at different levels with entrances in different storeys → **each** such storey is a ground storey |
| **Cubical extent** | Space within external surfaces of walls + roof + upper surface of lowest-storey floor; **exclude** roof enclosures used only for water tank / lift gear / services; unenclosed side deemed enclosed by wall from outer roof edge downward |
| **Emergency vehicular access (EVA)** | Vehicular access for FSD appliances in fire/emergency |
| **Refuge floor** | Protected floor for occupants to assemble in a fire |
| **FRP** | Fire resistance period per BS 476 Pts 20–24 : 1987 or FRC Code schedule |
| **Element of construction** | Floor, beam, column, hanger; load-bearing wall/member (**not** roof or part of roof) |

**SD takeaways:**
- **Cubical extent includes basements** wherever Table 1 says so — do not measure tower volume alone.
- Multi-level street frontages create **multiple ground storeys** → FS access point / EVA / entrance logic can attach to more than one level.
- FRS is not “a stair next to a fireman’s lift” — it is a **single protected package** with shared lobby rules (§18–22).

### 2. Objectives & what this Code does **not** cover (§2)

| Covered here | Not covered (use other Codes) |
|---|---|
| Access for firefighting personnel into / onto floors | Preventing outbreak of fire |
| Number / design of access stairs, fireman’s lifts, FRS | Limiting fire/smoke spread; fire suppression |
| EVA geometry and signs | Means of escape geometry (except dual-counting rules) |
| | Fire-resisting construction & structural integrity (except FRP cross-refs) |
| | Active FSI equipment schedules (FSD CoP) |

### 3. Alternative / fire engineering path (§3) — when Table 1 / EVA cannot be met

BA accepts non-prescriptive solutions especially for special hazard (size, height, use, design, construction, location). Assessment criteria package:

- Means of escape, means of access, FSI, fire-resisting construction
- Size, height, use, location, **management** of the building

Factors to quantify / argue:
- Anticipated risk of fire occurring; anticipated fire severity
- Ability of structure to resist fire/smoke spread; consequential danger to people in/around building

Measures that may be traded (illustrative): prevention; early detection/warning; MOE standard; smoke control; growth-rate control; structural fire resistance; containment / separation; active extinguishment; facilities for fire service; property management; trained personnel; continuing maintenance control.

**SD takeaway:** Do not invent ad-hoc waivers on GBP day — if you need setback >18 m, buried FRS without air, or deficient EVA, budget a **fire-safety report** + FSD consultation early (§27–28 for EVA).

### 4. Lock Table 1 first — what triggers fireman’s lift vs FRS (§5)

Every core strategy hinges on **building type + height above mean level of lowest street + cubical extent (incl. basements where stated) + storey count**. Set this before fixing towers, basements, and industrial volumes.

#### 4.1 Full Table 1 matrix

| Ref | Building type | Threshold | Access staircases | Fireman’s lift | FRS |
|---|---|---|---|---|---|
| **(1)** | All buildings & basements | ≤ **1 storey** | — | — | — |
| **(2)** | Single-household domestic | ≤ **3** main storeys | — | — | — |
| **(3a)** | Domestic / office with G/F shop or carport | >1 ≤**6** storeys; uppermost ≤**13 m**; UFA ≤**250 m²**/floor | **1** | — | — |
| **(3b)** | Same | >1 ≤**6** storeys; uppermost >**13–17 m**; UFA ≤**150 m²**/floor | **1** | — | — |
| **(4a)** | Domestic / domestic part of composite *(not 2–3)* | >1 storey, height ≤**30 m** | ≥**2** (as many as escape stairs) | — | — |
| **(4b)** | Same | >**2** storeys **and** height >**30 m** | ≥**2** | **1** within **60 m** of any part of floor | — |
| **(5a)** | Non-domestic / non-domestic part of composite *(excl. industrial, bulk storage, warehouse, PPE, hotel, hospital, and (3))* | >1 storey, height ≤**15 m** | ≥**2** | — | — |
| **(5b)** | Same | >1 storey; height >**15–30 m**; cubical extent ≤**7 000 m³** | ≥**2** | — | — |
| **(5c)** | Same | >**2** storeys; height >**15–30 m**; cubical extent >**7 000 m³** | ≥**2** | **1** within **60 m** | — |
| **(5d)** | Same | >**2** storeys; height >**30 m** | ≥**2** | **1** within **60 m** | — |
| **(6a)** | Places of public entertainment, hotels or hospitals | >1 ≤**2** storeys | ≥**2** | — | — |
| **(6b)** | Same | >**2** storeys (any height / volume) | ≥**2** | **1** within **60 m** | — |
| **(7a)** | Industrial, bulk storage or warehouse | >**2** storeys; ≤**30 m**; ≤**7 000 m³** | ≥**2** | **1** within **60 m** | — |
| **(7b)** | Same | >1 storey; ≤**30 m**; >**7 000 m³** | ≥**2** | **1** within **60 m** | **1** within **60 m** |
| **(7c)** | Same | >1 storey; >**30 m**; ≤**7 000 m³** | ≥**2** | **1** within **60 m** | **1** within **60 m** |
| **(7d)** | Same | >1 storey; >**30 m** **and** >**7 000 m³** | ≥**2** | **1** within **60 m** | **1** within **60 m** |
| **(8a)** | All basements | >**2** basement storeys **and** >**7 000 m³** | ≥**2** | **1** within **60 m** | **1** within **60 m** |
| **(8b)** | All basements | Depth >**9 m** (G/F floor level → lowest basement floor level) **and** >**7 000 m³** | ≥**2** | **1** within **60 m** | **1** within **60 m** |

#### 4.2 Quick decision tree (SD)

```
Single household ≤3 main storeys?                    → nothing (2)
≤1 storey anything?                                  → nothing (1)
Small domestic/office+shop/carport (3a/3b limits)?   → 1 access stair only
Domestic / domestic composite:
  height ≤30 m                                        → ≥2 access stairs (4a)
  >2 storeys AND >30 m                                → + fireman’s lift ≤60 m (4b)
Hotel / hospital / PPE:
  ≤2 storeys                                          → ≥2 access stairs (6a)
  >2 storeys                                          → + fireman’s lift ≤60 m (6b)  ← early trigger
Ordinary non-domestic (not industrial/PPE/hotel/hosp):
  ≤15 m                                               → ≥2 stairs (5a)
  >15–30 m AND ≤7000 m³                               → ≥2 stairs (5b)
  >2 storeys AND (>15–30 m & >7000 m³, OR >30 m)      → + fireman’s lift (5c/5d)
Industrial / warehouse / bulk storage:
  >2 storeys, ≤30 m, ≤7000 m³                         → fireman’s lift only (7a)
  (>7000 m³) OR (>30 m) [per 7b–7d]                   → fireman’s lift + FRS (both ≤60 m)
Basement:
  (>2 storeys AND >7000 m³) OR (depth >9 m AND >7000) → fireman’s lift + FRS
```

#### 4.3 Counting credits & extras (Table 1 Note + §5.2)

| Rule | Effect |
|---|---|
| FRS access staircase | Counts as **1** access staircase for B(P)R **41A** |
| FRS fireman’s lift | Counts as **1** fireman’s lift for B(P)R **41B** |
| Special hazard (BA view) | High fire/life risk (entertainment, exhibition, etc.) → BA may require **additional** fireman’s lifts and/or FRS beyond Table 1 |

**SD takeaways:**
- **FRS is the industrial / deep-basement killer** — domestic and ordinary commercial get fireman’s lifts at height/volume triggers, but **not** FRS.
- Hotel / hospital / PPE flip to fireman’s lift at only **>2 storeys** — lock before podium hotel / hospital stacking.
- Row **(7a)** is the only industrial band with fireman’s lift **without** FRS — stay ≤30 m **and** ≤7 000 m³ or accept full FRS package.
- Basement FRS can be triggered by **storey count** (8a) **or** **depth** (8b) once volume >7 000 m³ — a 2-level deep basement can still trigger on depth alone.

### 5. Dual use of stairs — MOE ↔ MOA (§6–7)

| Direction | Rule |
|---|---|
| Escape stair → access stair | MOE escape stairs under B(P)R 41(1) + MOE Code **may be taken as** access stairs for 41A |
| Escape stair → FRS access stair | Only if **also** complies with 41C + this Code’s FRS requirements |
| FRS access stair → escape stair | May count for MOE 41(1) **only if** MOE Code escape-stair requirements are also met |

**SD takeaway:** One stair can serve both MOE and MOA, but FRS geometry (width, vents, lobby, FRP) is stricter than ordinary escape — design the FRS stair to the **higher** of the two codes, then claim both credits.

### 6. Fireman’s lift (standalone — Part IV) vs fireman’s lift inside FRS

Use this contrast when Table 1 requires a lift **without** FRS (domestic >30 m, ordinary commercial, hotel/hospital/PPE >2 storeys, industrial 7a).

| Topic | Standalone fireman’s lift (Part IV) | Inside FRS (Part V) |
|---|---|---|
| Ground access | §9 | §16 (same 18 m / 1.5 m open area logic + **same street** for stair & lift) |
| Floor coverage | 60 m / design 40 m (§10.4) | Same (§17.6) |
| Lobby size | ≥ **2.25 m²**, min dim **1.5 m** (§13) | **5–10 m²**, min dim **1.5 m** (§18) |
| Lobby external wall / natural vent | Openings allowed if FRC lobby rules met; **no** 25% free-area mandate in Part IV | **Mandatory** external wall + ≥**25%** free area (above G/F) unless open-stair waiver / mechanical smoke control |
| Floors served | Alternate OK; uniform pattern; every refuge | **Every** floor + every part; carpark/loading too; roof if other stairs serve roof |
| Upper ↔ basement stair | N/A (lift only) | Upper FRS stair must **not** continue directly into basement |
| Perimeter FRP | Lobby walls ≤ **2 hr** cap (§13.1) | Stair/lift/lobby perimeter = **2×** floor FRP, max **4 hr** (§19.2) |

### 7. Fireman’s lift — designation, ground access, floors served (§8–10)

#### 7.1 Designation (§8)

| Rule | Detail |
|---|---|
| Who chooses | If >1 lift in a building that needs a fireman’s lift → **Director of Fire Services** designates which lift |
| Goods lifts banned | Lift mainly for goods **must not** be fireman’s lift in industrial undertaking, bulk storage, or warehouse |

#### 7.2 Ground-level fire service access point (§9) — core placement driver

| Item | Rule |
|---|---|
| Location | At G/F perimeter: **directly** from street accessible by fire appliances, **or** through open area min dimension ≥ **1.5 m** with access free of permanent obstruction to such street |
| Gates / doors | Must not close access unless openable from inside **without a key** |
| Lift setback | Horizontal distance access point → fireman’s lift doors ≤ **18 m** (BA may allow more if fire safety not compromised — Diagram 4) |
| Access passage clear size | Width ≥ **1 500 mm**; height ≥ **2 000 mm** |
| Passage separation from remainder of G/F | Walls FRP ≥ elements of construction in G/F |
| Openings from passage to G/F | Only via **protected lobby**: lobby walls FRP ≥ passage wall; doors FRP ≥ **½** wall FRP + FRC fire-door rules |
| External notice | Form: “Fireman’s Lift 消防升降機”; letter height ≥ **20 mm**; illuminated by **two** separate electric-light systems **or** self-energized safety sign (no external power) |

**SD takeaway:** The **18 m** setback + protected 1.5 m passage from a real appliance street locks tower-core eccentricity and podium deep-plan early. Do not put the only fireman’s lift deep in a mall without a rated approach corridor.

#### 7.3 Floors served & service pattern (§10)

| Item | Rule |
|---|---|
| Performance intent | Firemen reach any fire floor without traversing **more than two floors** |
| Single fireman’s lift | Serve at least **alternate** floors |
| Multiple fireman’s lifts in common shaft | May serve different zones if zones **clearly indicated** |
| Pattern uniformity | Subject to refuge rule: odd floors, even floors, or all floors — **uniform and regular** |
| Refuge floors | Every refuge floor served by ≥ **1** fireman’s lift; landing doors **locked in normal operation**; locking auto-releases on fireman’s switch |
| Top floor | If pattern includes top floor, serve it unless lift machine room must sit on top floor due to **statutory height restriction** |
| Landing vs access-point level | Lowest landing (above-ground service) or topmost landing (basement service) should be at access-point level; if site constraints → ≤ **1 floor** above or below |
| Floor coverage | No part of floor > **60 m** from lift-lobby door along **actual passages** |
| Unknown fit-out | Design-stage **40 m** straight-line OK provided final occupied layout still meets **60 m** |

### 8. Fireman’s lift — well, car, lobby, doors, controls (§11–15)

| Item | Rule |
|---|---|
| Liftwell | Separate well for each fireman’s lift; ≤ **3** fireman’s lifts may share one well |
| Well notice | Outside well: “FIREMAN’S LIFT” + “(消防升降機)” + floors served; letters/characters ≥ **15 mm** |
| Car size / load | Min internal dimension **1.1 m**; net internal floor ≥ **1.35 m²**; rated load ≥ **680 kg** |
| Door opening | ≥ **800 mm** wide × **2 000 mm** high; power-operated automatic self-closing |
| Lobby required | Each discharge to floor served **except** at G/F fire service access point (§9) |
| Lobby size | Floor area ≥ **2.25 m²**; min dimension **1.5 m** |
| Lobby FRP | Walls ≥ FRP of elements of construction on that floor, **subject to max 2 hours**; doors ≥ **½** wall FRP + FRC fire-door rules |
| Lobby external openings | Lighting/ventilation openings in external wall OK if same FRC rules as openings in external wall of lobby to a **required staircase** |
| Shared bank lobby | If only some lifts in a bank are fireman’s lifts, they may share a common lobby **provided** that lobby exists on **every** floor served by any of those lifts |
| Lobby → exit route | Access without obstruction and **without lockable door** |
| Controls / electrical / mechanical | EMSD *Code of Practice on the Design and Construction of Lifts and Escalators* — special fireman’s-lift requirements |

**SD takeaway:** Budget the **2.25 m² / 1.5 m** lobby on every served floor (not just typical floors), and keep a free path from lobby to a protected exit — no tenancy lock beyond.

### 9. Firefighting & Rescue Stairway — treat as one sealed package (Part V)

FRS = **access staircase + fireman’s lift** in one protected stairway. Required mainly for **industrial / warehouse** (Table 1 rows 7b–7d) and **large / deep basements** (8a–8b). Diagrams 1–2 illustrate above-ground and basement lobby ventilation.

#### 9.1 Ground access (§16)

| Item | Rule |
|---|---|
| Access point | Same street/open-area logic as §9 (≥ **1.5 m** open area; no permanent obstruction; no key-locked gates) |
| Setback | ≤ **18 m** horizontal from access point to fireman’s lift doors **or** first step of access staircase |
| Same street | Both lift **and** access staircase must be accessible from the **same** street |
| Separation from remainder of G/F | FRS + approach passage separated by walls FRP ≥ FRS **perimeter** enclosing walls — includes separation from cargo-lift lobby/hall |
| Openings to G/F | Only via protected lobby: walls ≥ FRS perimeter FRP; doors ≥ **½** wall FRP + FRC rules |
| Passage clear size | ≥ **1 500 mm** wide × **2 000 mm** high |
| External notice | “Firefighting and Rescue Stairway 救援樓梯”; letters ≥ **20 mm**; dual lighting or self-energized sign |

#### 9.2 Floors served — no partial coverage (§17)

| Item | Rule |
|---|---|
| Coverage | Access staircase **and** fireman’s lift serve **every floor** (incl. refuge) and **every part** of the building |
| Ancillary uses | Car parking and loading/unloading — whether whole floor or part — **shall also** be served |
| Roof | If roof is served by other staircases, FRS access staircase must also serve roof; fireman’s lift **not** required to serve roof but should serve top floor (unless machine room forced to top by height restriction) |
| Upper ↔ basement | Access staircase serving upper floors must **not** continue directly to serve basement floors |
| Through refuge | Stair must **discontinue** at refuge; access route diverted to pass over refuge area before continuing up; lift doors onto refuge locked normally, auto-release on fireman’s switch |
| Landing vs access point | Same preference / ≤1-floor offset as §10.3 |
| Coverage distance | No part of floor > **60 m** from FRS lobby door along passages; design-stage **40 m** straight-line allowed under same caveat as §10.4 |

**SD takeaway:** FRS is whole-building — you cannot “save” the carpark podium from FRS once Table 1 triggers it. Break the stair at refuge and between upper/basement early in section design.

#### 9.3 Access to floor via FRS lobby (§18) — the SD space & façade killer

On **every floor except the ground storey**, access from FRS to that floor is **only** through a lobby that must satisfy **all** of:

##### Lobby geometry

| Item | Rule |
|---|---|
| Area | ≥ **5 m²** and ≤ **10 m²** |
| Min dimension | **1.5 m** |
| Lift opening | Every FRS fireman’s lift opens **into** this lobby |
| Stair ↔ lift | Communicate with each other at **every** floor served |

##### Above-ground lobby ventilation (§18.1(b)–(c))

| Item | Rule |
|---|---|
| External wall | Lobby must have an **external wall** as one enclosing wall |
| Free area | Openings on that external wall ≥ **25%** of lobby floor area |
| Opening head height | Top of openings as near ceiling as practicable; in no case < **1.9 m** above lobby floor |
| External air “pocket” | Openings face external air with horizontal area ≥ **21 m²**, vertically uncovered and unobstructed above |
| Enclosed court alternative | If enclosed on all sides: area ≥ **1 m² per 1 m height** of enclosing walls, min dimension **1.5 m** |
| Window hardware | Side-hung; open outward ≥ **30°**; openable from inside without key; simple lever handles or rotary rack/gear |

##### Basement lobby ventilation (§18.1(d))

| Option | Rule |
|---|---|
| **(i) Smoke outlets** | Unobstructed outlets ≥ **1 m²** cross-section **per lobby** to outside air above G/F; each basement lobby **individually** ventilated by separate outlets at **lobby ceiling**; covers at/above G/F may be breakable; locate outlets ≥ **5 m** clear of final exit discharge or FS access point (**≥ 2.5 m** only if smoke directed away and unlikely to affect exit/access by natural convection); shafts FRP = FRS perimeter FRP (or enclosed to that FRP); unenclosed shafts → resist accidental mechanical damage + BS 5669 hard-body impact |
| **(ii) Open well** | Openings complying with above-ground free-area / height / hardware rules, ventilating into open well ≥ **1 m² per 1 m** wall height, min dim **1.5 m** |

##### Waiver of natural ventilation to lobby (§18.1 proviso + Diagram 2 Alt. 3)

Natural ventilation to lobby **not** required if the access staircase is open on **3 sides** for ≥ **900 mm** height (balustrade/parapet top → underside of flight above) **and** open to a void ≥ **10 m²**, min dimension **1 m**, unobstructed above for adequate ventilation.

##### Mechanical alternative (§23)

Any required natural ventilation to FRS stairway or lobby may be **omitted** where a mechanical system controlling smoke ingress (e.g. **pressurisation**) is provided to the satisfaction of the **Director of Fire Services**.

**SD takeaways:**
- Do not bury FRS in the plan centre without an external wall, air well, open-stair void, or DFS-accepted pressurization.
- Lobby area is capped at **10 m²** as well as floored at **5 m²** — oversizing the lobby is not compliant.
- Basement smoke outlets need early coordination with landscape / pavement lights and must stay clear of exit discharge and FS access point.

#### 9.4 Protection of FRS (§19)

| Item | Rule |
|---|---|
| Materials | Perimeter walls + landings, flights, balustrades, partitions: **wholly non-combustible**; **no** combustible wall/ceiling lining or floor finishing |
| Perimeter FRP | Walls separating access stair, fireman’s lift and lobby from the served floor, **plus** supporting structure and floor slabs forming enclosures → FRP = **twice** that required for elements of construction on that floor, **max 4 hours** |
| Stair ↔ lobby partition | FRP ≥ **1 hour** |
| Lobby doors | FRP ≥ **1 hour**; FRC fire-door rules; **no** bolts/locks/fastenings except: door between lobby and served floor may have lock openable from **floor side without key** (security) |
| External openings | Also comply with FRC; in no case within **450 mm** horizontally of any opening in external walls of the **same** building |

**SD takeaway:** FRS perimeter at **2× FRP (≤4 hr)** is a structural/façade thickness driver — especially next to basements already on 4 hr FRC logic.

#### 9.5 Access staircase construction inside FRS (§20)

| Item | Rule |
|---|---|
| Clear width | ≥ **1 050 mm** |
| Clear height | ≥ **2 000 mm** |
| Flight plan | Straight flights; **no winders** |
| Risers per flight | ≥ **2** and ≤ **16** |
| Tread | ≥ **225 mm** wide clear of nosings |
| Riser | ≤ **175 mm** high |
| Landings | At top and bottom of each flight; min dimension ≥ width of flight; door swing must not reduce effective width or effective radius |
| Handrails | **Both** sides; height **850–1 100 mm** above steps/landings; projection into clear width ≤ **90 mm** per handrail; continuous throughout each flight (need not continue around landing / half-landing) |

#### 9.6 Ventilation of access staircase (§21)

| Location | Rule |
|---|---|
| Each storey above G/F | Natural vent openings in external enclosure wall ≥ **15%** of internal area on plan of access staircase; windows: side-hung, outward ≥ **30°**, no key, simple lever/rack gear |
| Highest point | Vent ≥ **5%** of stair plan area; openable manually **or** automatically by remote control; remote switch in conspicuous position at G/F fire service access point |

#### 9.7 Fireman’s lifts inside FRS (§22)

| Item | Rule |
|---|---|
| Quantity / exclusivity | ≤ **3** fireman’s lifts may share same liftwell; **no other lifts** in that well |
| Goods lifts | Must not be designated fireman’s lift |
| Car / door / notice / controls | Comply with §§11.2, 12, 14 and 15 (same car size, door size, well notice, EMSD controls) |

### 10. Emergency Vehicular Access (EVA) — B(P)R 41D / Part VI

#### 10.1 Virgin site vs redevelopment (§24.1, 25.1)

| Term | Meaning |
|---|---|
| **Virgin site** | No temporary or permanent building existed before (incl. NT-exempt buildings). §24 requirements also apply to **all subsequent redevelopments** on that virgin site |
| **Redevelopment site** | Not a virgin site → §25 (generally less onerous widths / industrial dual-façade rules) |

**SD takeaway:** First development on a greenfield / NT cleared site locks the stricter virgin-site EVA regime onto later rebuilds — flag this in land due diligence.

#### 10.2 Design appliance & common geometry

| Item | Value / rule |
|---|---|
| Gross weight | **30 000 kg** |
| Turning circle | **26 m** |
| Length | **12 m** |
| Dead-ends | Turning space required at all dead-end EVA |
| Headroom under any structure | ≥ **4.5 m** |
| Gradient | ≤ **1 in 10**; portions **not** serving any major façade may be ≤ **1 in 6** |
| Gradient change (Diagram 5) | Acute angle α between adjoining planes ≤ **6°**; if larger, insert intermediate plane ≥ **10 m** long (or ≥ **12 m** along centreline if the intermediate plane is a bend) so every α ≤ 6° |

#### 10.3 Major façade & “served by EVA” (§24.2(e))

| Item | Rule |
|---|---|
| Major façade | Façade length ≥ **one-fourth** of total length of all perimeter walls |
| If “major” façade < ¼ perimeter | EVA must serve that façade **plus** other façades so aggregate length served ≥ ¼ perimeter |
| Deemed served | Horizontal distance EVA ↔ that part of façade ≤ **10 m** |
| High façade waiver | The ≤10 m rule **does not apply** to façade levels > **60 m** above the level of the EVA serving that façade |
| Covering | Part of EVA serving a building façade must **not** be covered |

#### 10.4 Virgin-site baseline widths (§24.2(a))

| EVA form | Min width |
|---|---|
| Carriageway | ≥ **7.3 m** |
| Not a carriageway | Hard-paved ≥ **6 m**, well demarcated on site |

#### 10.5 Use-specific EVA — virgin (§24.3) vs redevelopment (§25.3)

| Use | Virgin site | Redevelopment |
|---|---|---|
| **Industrial** | **Two opposite** façades, remote from each other, **each** ≥ ¼ perimeter; if multi-street access available, EVAs should gain access from **different streets**; 2-way carriageway ≥ **13.5 m** undivided, **or** ≥ **7.3 m** each side if central divider; if EVA outside site → reserve ≥ **6 m** wide strip measured from building boundary alongside that EVA as additional EVA (Diagram 6) | ≥ **1** major façade per §24.2(e); width ≥ **7.3 m** |
| **Cinema / theatre** | Thoroughfares per MOE §22 (Annex A) — see §10.6 | Same Annex A / MOE §22 |
| **Any other use** | ≥ **1** major façade; carriageway ≥ **7.3 m** or hard-paved ≥ **6 m** | ≥ **1** major façade; width ≥ **6 m** |
| **Mixed use** | Meet **most stringent** use requirements | Meet **most stringent** use requirements |

Redevelopment also inherits virgin rules for headroom, gradient, appliance specs (§25.2 → §24.2(b)(c)(d)); non-carriageway EVA must still be hard-paved and demarcated.

#### 10.6 PPE / cinema thoroughfares (Annex A = MOE §22) — site selection killer

| Capacity / case | Rule |
|---|---|
| All PPE | Site abuts and has frontages to **≥ 2** thoroughfares |
| Frontage length | Subject to ≤500 / BA cases: frontages form ≥ **½** total site boundaries (excl. recesses/projections that do not prejudice exits) and permit exit routes from each tier/floor direct to ≥ 2 thoroughfares |
| Thoroughfare purpose | Enable rapid dispersal + reasonable approach of fire appliances |
| >500–2 000 persons | One thoroughfare ≥ **12 m** |
| >2 000–3 000 | One ≥ **12 m** + other ≥ **9 m** (carriageway) or ≥ **6 m** (footway) |
| >3 000–5 000 | One ≥ **15 m** + other ≥ **9 m** |
| >5 000 | Further frontage as BA requires |
| ≤500 | Number and width of thoroughfares as BA determines |

#### 10.7 Crash gates (§24.4 / §25.4)

If EVA is **not** normally used as access for other vehicles:
- Provide emergency crash gate conforming to (or equivalent to) **Highways Department** standards (Diagram 7)
- Gate perpendicular to EVA centreline
- Clear space in front of gate per Diagram 8

Applies to both virgin and redevelopment sites.

#### 10.9 Exemption, modification & enhanced measures (§27–28)

##### When exemption may be sought (B(P)R 41D(3))

| Ground | Examples / notes |
|---|---|
| **(a) Low fire risk** purpose | Microwave transmitter station; beach house; seawall; pylon supporting cables — still analyse factors below |
| **(b) Topographical impracticability** | Site abutting stepped street; abutting road/street below Code standards where owner has **no control**; remote areas / outlying islands → BA + FSD may specify smaller-appliance access case-by-case |

##### Fire-safety report content (§27.2)

Assess probability and likely consequence of fire. Analyse:
- Fire load; spread of fire; population density in different parts
- Occupant behaviour in panic
- Impact of topographical constraints on ingress/egress (for topography cases)

BA considers with **Director of Fire Services** on individual merits.

##### Enhanced measures if EVA non-provided or deficient (B(P)R 41D(4) / §28)

BA may require enhanced MOE, MOA, FRC, FSI, or a combination. Typical FSI enhancements (may be varied case-by-case) per FSD Minimum FSI CoP:

| Enhancement | Detail |
|---|---|
| **(a) Sprinklers** | Domestic: light-hazard LPC sprinklers to **all common areas** (lift lobbies, staircases, common corridors, all exit routes to G/F) + independent sprinkler tank of appropriate capacity. Composite: appropriate hazard-group sprinklers to **entire commercial portion** (irrespective of floor area) **and** all domestic common areas. Heads: approved **fast response** type |
| **(b) Stair smoke control** | Pressurisation **or** natural venting of staircase to FSD FSI CoP standards |
| **(c) Direct line** | Direct line to FSD Fire Services Communication Centre, connected to sprinkler alarm + manual fire alarm. Even with direct line, sprinkler tank capacity (both ends fed) **must not** be reduced to 2/3 |
| **(d) Water supply** | Enhanced tank size / inflow rate for sprinkler or FH/HR system |
| **(e)** | Any combination of the above |

**SD takeaway:** On stepped-street / constrained urban lots, price the enhanced sprinkler + pressurization + direct-line package at feasibility — do not assume a free EVA waiver.

### 12. Schematic design checklist (day-one)

1. Confirm **virgin vs redevelopment** for EVA regime; measure **cubical extent including basements**.
2. Classify against **Table 1** (use + height above mean lowest street + storeys + basement depth) → access stairs only / + fireman’s lift / + **FRS**.
3. Count MOE escape stairs — claim as access stairs; if FRS required, design one stair to **MOE + FRS** and claim both 41A/41B credits.
4. Pin **FS access point** on appliance-accessible street (or ≥1.5 m open link); keep lift / FRS within **18 m**; reserve protected passage ≥ **1 500 × 2 000 mm**.
5. Keep every floor point within **60 m** of fireman’s-lift / FRS lobby door (use **40 m** radial only as interim tool).
6. Size lobbies: standalone fireman’s lift ≥ **2.25 m²** / 1.5 m; FRS lobby **5–10 m²** / 1.5 m with external wall + **25%** free area (or basement smoke shafts / DFS pressurization / open-stair waiver).
7. If FRS: stair ≥ **1 050 mm**; no winders; perimeter FRP **2×** (max **4 hr**); non-combustible throughout; serve carparks/loading; break stair at refuge; do **not** run upper stair continuously into basement; top vent **5%** with G/F remote.
8. Fireman’s lift car ≥ **1.1 m** / **1.35 m²** / **680 kg**; doors ≥ **800 × 2 000 mm**; ≤3 fireman’s lifts per well; no goods lift as fireman’s lift in industrial/warehouse.
9. Trace **EVA**: 30 t / 26 m turning / ≤1:10 (or 1:6 non-façade) / ≥4.5 m headroom / ≤10 m to façade / uncovered serving length; industrial virgin dual opposite façades + 13.5 m; PPE dual thoroughfares per capacity.
10. If EVA fails → fire-safety report + negotiate **enhanced FSI/MOE/FRC** package with FSD before freezing massing.
11. Cross-check contemporaneous **MOE 1996**, **FRC 1996**, EMSD lift CoP, FSD FSI CoP — or for new work **FS Code 2011 Parts B–D** which supersede this Code.
