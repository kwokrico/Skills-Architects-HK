# Code of Practice for Building Works for Lifts and Escalators 2011
**Architect critical summary for schematic design**  
2020 Edition (September 2020 revision; first issue July 1993; last major revision November 2011) | Buildings Department / Building Authority

> Scope note: This CoP covers **building works** that accommodate lifts and escalators — shaft, pit, headroom, machine/pulley rooms, escalator landings and obstruction clearances — deemed to satisfy **Building (Construction) Regulations reg. 9A**. BA may accept equivalent performance. Fire resisting construction → **FS Code Part C**. E&M / lift safety / obstruction guards → Cap. 618 CoPs (EMSD). Firemen’s lifts → **B(P)R 41B + FS Code Part D**. Barrier-free lift cars/landings → **DMBA 2008** (separate). Do not size shafts from this summary alone — verify Table 1 against selected load/speed and coordinate with lift supplier / RSE / RE.

---

## Regulatory Overview

This Code applies to **building works related to lifts and escalators in general**. **Sections 2–3** apply to all lifts under B(C)R 9A **except service lifts**; **Section 4** covers **service lifts** only; **Section 5** covers **escalators** (including passenger conveyors). Definitions follow Cap. 618: a **service lift** is ≤250 kg rated load, car floor ≤1 m², car height ≤1.2 m. Machine-room-less (MRL) lifts are allowed only where the **lift model is approved by the Director of Electrical and Mechanical Services**, with model particulars and approval indicated on the general building plans (GBP).

## Critical main topics and subtopics

### 1. Definitions that change the design brief (1.2)

| Term | Meaning (architect-critical) |
|---|---|
| **Lift** | Lifting machine/appliance with guided carrier; **or** a mechanized vehicle parking system — **not** an escalator |
| **Service lift** | Rated load ≤**250 kg**; car/cage floor ≤**1 m²**; height ≤**1.2 m** |
| **Escalator** | Powered inclined continuous stairway (up/down/both) **or** passenger conveyor (same or different levels) |
| **Open air** (for shaft vents) | Vertically uncovered & unobstructed; any horizontal dimension ≥**1.5 m**; if enclosed on 4 sides → horizontal area ≥**1 m² per 6 m** of mean enclosing-wall height |

**SD takeaway:** “Dumbwaiter / goods-only cage” vs passenger lift is a **Section 3 vs Section 4** fork — wrong path = wrong pit, notices, and machinery space.

### 2. Lock lift type and shaft package first (SD killer checklist)

| Decision | Which rules apply | SD takeaway |
|---|---|---|
| **Passenger / goods lift** (not service) | §2 + §3 + **Table 1** | Size well, pit, headroom, entrance, machine room by load + speed |
| **Service lift** | **§4 only** (not Table 1) | Pit often not required; different machinery dims & notices |
| **MRL** | §2.3 + §3.11.1 | Table 1 **machine-room min. dims** and **overall headroom (Uh)** do **not** apply; EMSD-approved model on GBP; control-panel access from **common areas** only |
| **Hydraulic lift** | §3.4.2 extra structural loads | Jacks, clamping/pawl devices, buffers, off-centre loads — brief RSE early |
| **Firemen’s lift** | This CoP + **B(P)R 41B + FS Code Part D** | Lobby, size, power, FR — parallel track, not covered in this CoP’s tables |
| **Deviation from Table 1** | §2.2 modification path | Written confirmation from registered lift engineer **or** person authorised by registered lift contractor that: (a) installation fits proposed well/MR; (b) future maintenance/repair/alteration/replacement/examination/testing can be done safely & without difficulty; (c) full Cap. 618 Design & Construction CoP compliance |

**SD takeaway:** Fix **rated load (kg/persons), rated speed (m/s), conventional vs MRL, and firemen’s-lift need** before locking floor-to-floor, basement excavation, roof plant, and core width.

#### 3.3 Table 1 design rules (Notes 1–7) — do not skip

| Note | Rule |
|---|---|
| **1** | Use **Figure 1** for how Cw, Cd, Ww, Wd, Ph, Sh, Uh, etc. are measured |
| **2** | Dims apply also to speeds **lower or higher** than listed (e.g. &lt;1.0 m/s all loads; &gt;1.75 for 630 kg; &gt;3.5 for 1600 kg). Intermediate load/speed → **linear interpolation** |
| **3** | Cw and Cd may vary **provided Cw × Cd ≤ Ca** |
| **4** | 750 kg → Ca max = **1.9 m²** |
| **5** | MR: pick Rw and Rd each **≥** tabulated **and** Rw × Rd ≥ Ra |
| **6** | Load **&gt;1600 kg**: (a) Ca +**0.16 m²** per extra 100 kg (max increment rule as stated); (b) Ra +**0.6 m²** per extra 100 kg; (c) all other dims ≥ 1600 kg same-speed values |
| **7** | Alternative to tabulated MR footprint: provide **sufficient machine-room clearances** (Appendix sample note on GBP); verify on site at completion |

**Speed effect (SD critical):** Crossing ~**2.0 m/s** typically jumps pit from ~1.7–1.9 m to **~2.8 m**, headroom from ~4.3–4.9 m to **~5.7–6.2 m**, and overall Uh by **~1–2+ m**. At **3.5 m/s**, Ph ≈ **3650** mm and Uh often **10.4–10.6 m**. Flag high-speed cores in massing before fixing basement depth and roof plant.

**SD takeaway:** Core depth ≈ well depth + landing lobby + structure. High-speed lifts can force **extra storey-equivalent** headroom at roof and deep pits at basement.

### 4. Liftwell enclosure, structure, and facing walls (§3.1, 3.4, 3.5, 3.9)

#### 4.1 Enclosure & exclusive use

| Item | Rule |
|---|---|
| Enclosure | Each well **totally enclosed** by imperforate walls, floor, ceiling (§3.4 + **FS Code Part C**) |
| Exclusive use (§3.9) | Well **exclusively for the lift** — no other cables, devices, ducts, etc. |
| Sprinklers | **Must not** be fitted in the liftwell |
| Materials (§3.4.3) | Non-combustible, durable, do not assist dust creation; sufficient structural strength |
| Inner wall face (§3.4.4) | Continuous vertical surface of smooth hard elements — **unless** inaccessible from car top (or from car top via adjacent CW / structural supports) |

#### 4.2 Structural loads the well must support (§3.4.1–3.4.2) — brief RSE

| Lift type | Well structure shall support at least |
|---|---|
| **General** | Machine loads; guide loads at **safety-gear operation**; buffer action from **off-centre car load**; **anti-rebound device** loads |
| **Hydraulic** | Machine, **jacks**, and guides; buffers / safety gear / **clamping device** / **pawl device** at application; off-centre car loads |

#### 4.3 Walls facing car entrance — 350 mm band below each landing sill (§3.5)

| Item | Rule |
|---|---|
| Band | Below each landing sill, over a vertical distance of **350 mm** |
| Surface | Continuous smooth hard vertical face; extend ≥**25 mm** beyond full car entrance width **on both sides** |
| Forbidden | **Plaster-faced** walls and **glass** walls in this band |
| If continuous smooth face not practicable | Any projection **&gt;5 mm** shall either: connect to lintel of door opening below; **or** extend downward and splay underside ≥**75°** from horizontal for ≥**20 mm** (metal plates, concrete, or similar) |

**SD takeaway:** Spec shaft finishes early — plaster/glass at the entrance band is a compliance fail; prefer smooth concrete / steel / approved hard lining.

### 5. Inspection / emergency doors & traps (§3.2) — rescue & maintenance access

#### 5.1 When allowed

Inspection/emergency doors and traps: **not permitted** except for **user safety** or **servicing** requirements.

#### 5.2 Sizes and opening rules

| Opening | Size | Opening direction / construction |
|---|---|---|
| **Inspection door** | ≥ **1.4 m** H × **600 mm** W | Imperforate; **must not open into** the well |
| **Emergency (rescue) door** | ≥ **1.8 m** H × **500 mm** W | Same; locate where **readily accessible to rescuers** |
| **Inspection trap** | ≤ **500 × 500 mm** | Imperforate; not into well; key lock; reclose/relock **without** key |

#### 5.3 Intermediate emergency doors — tall floor-to-floor / skipped floors

If distance between consecutive **landing door sills exceeds 11 m** → provide intermediate emergency doors so sill-to-sill ≤ **11 m**.

**SD takeaway:** Double-height lobbies, void floors, and skipped-stop shafts routinely trigger this — plan rescue door / landing access in the section.

#### 5.4 Locks & warning signs (§3.2.7–3.2.9)

| Item | Rule |
|---|---|
| Inspection traps | Key-operated lock; reclose/relock without key |
| Inspection & emergency doors (default) | **Dual** key-operated locks — **two designated keys simultaneously** from outside; reclose/relock without key; openable **from inside well without key** even when locked |
| Warning figure | Except where door is a lift landing door: prominent figure-type warning ≥**100 mm** high immediately above/next to keyholes |
| Dual-lock exception (§3.2.9) | Single designated key OK if design reduces inadvertent entry — e.g. (a) landing doors serving as inspection/emergency doors; or (b) door sill ≥**1 m** above adjoining floor |

#### 5.5 Emergency door notice (exact content — durable, incised/embossed, ≥25 mm)

English: **DANGER / UNAUTHORIZED ACCESS PROHIBITED / LIFTWELL RESCUE DOOR / CLOSE AND LOCK THIS DOOR**  
Chinese: **危險 / 不得擅進 / 升降機槽救生門 / 請關閉並緊鎖此門**

### 6. Liftwell ventilation (§3.3) — roof / plant coordination

| Item | Rule |
|---|---|
| Principle | Well suitably ventilated; **must not** ventilate other rooms except those for **service of lifts** |
| Opening location | **Top of well** → open air **directly**, via **ducting**, or via **machine/pulley room** |
| Area | ≥ **1%** of well horizontal cross-section; **never &lt; 0.3 m²** net free area **per well** |
| Common well with **4 / 5 / 6** lifts | Min vent **0.4 / 0.5 / 0.6 m²** respectively |
| Fall protection | Ferrules projecting ≥**50 mm** above slab or FFL at openings over the well |
| Solid-wall multi-lift separation | Each separated well needs its own §3.3.2 vents |

**Open air** must meet Cap. B(P)R definition (see §1 above) — a “lightwell-like” pocket may fail if too narrow or under-area.

**SD takeaway:** Reserve roof/MR vent path early; do not “borrow” lift-shaft vents for toilets, corridors, smoke, or other rooms.

### 7. Space below lift / multi-lift wells / pit (§3.6–3.8)

#### 7.1 Space below car or counterweight (§3.6)

| Preference | Do **not** place liftwell above a space accessible to persons |
|---|---|
| If accessible space exists beneath car **or** CW | Pit base designed for imposed load ≥**5 kPa**, **and** either: (a) **solid pier** under CW buffer extending to solid ground; **or** (b) CW equipped with **safety gear** |

**SD takeaway:** Transfer floors, retail under towers, and carpark under cores — treat “accessible under shaft” as a structural + safety-gear package, not a late detail.

#### 7.2 Several lifts / service lifts in one well (§3.7)

| Item | Rule |
|---|---|
| Partition | Suitable partition of adequate strength (e.g. solid block wall, wire mesh screen) between moving parts (car or CW) of different lifts/service lifts — prevent trapping |
| Extent | From **pit floor** through **full height** of well, across **whole depth** of well |
| If solid walls separate each lift | Provide ventilation openings for **each** well per §3.3.2 |

#### 7.3 Lift pit (§3.8)

| Item | Rule |
|---|---|
| Bottom | Smooth, approximately level (except bases for buffers, guides, jacks, and drainage devices) |
| Waterproofing | After guide fixings, buffers, grids, etc. built-in → pit **impervious to water infiltration** |
| Access door if Ph **&gt; 2.0 m** | **Mandatory** — leads to stair meeting §3.12.4 |
| Access door if Ph **&gt; 1.6 m and ≤ 2.0 m** | Also required **if building layout permits** |
| Access door construction | Imperforate; **not** open into well; key lock; reclose/relock without key; openable from inside well without key; ≥**1.4 m** H × **600 mm** W |
| Pit access door notice (≥25 mm) | **DANGER / UNAUTHORIZED ACCESS PROHIBITED / LIFTWELL / CLOSE AND LOCK THIS DOOR** (+ Chinese equivalent) |
| If no other access | Permanent means of access + suitable handholds inside well, easily reachable from landing door; **must not project** into clear running space of any lift equipment |
| Handhold guidance | At least one handhold ≈ **1.3 m** above sill and ≤ **0.9 m** from landing entrance opening |
| Fall-arrest anchorage (§3.8.5) | One or more permanent anchorages adjacent to **lowest** landing door for fall-arrest devices **before** descending to pit; height **1.5–1.8 m** above FFL; readily accessible |
| Anchorage waiver | **Not required** if compliant pit access door under §3.8.3 is provided |

**SD takeaway:** Deep pits (&gt;2 m, common at ≥2.0 m/s) need a **pit stair + door** in the core plan — not only a ladder from the lowest landing.

### 8. Outside the well — landing interface (§3.10)

| Item | Rule |
|---|---|
| Landing sill | Sufficient strength for loads being introduced into the car |
| Water control | **Slight counter-slope** in front of each landing sill — prevent washing, sprinkling, draining, or entry of water into well |
| Fire notice location | Outside well at each landing, as near as practical to landing door; if ≥2 adjoining lifts → on landing door of **one in every two** lifts |
| Fire notice size | Durable, incised/embossed, bilingual, characters ≥**15 mm** |
| Fire notice text | **IN CASE OF FIRE DO NOT USE THE LIFT / 如遇火警切勿使用升降機** |

**SD takeaway:** Lobby finishes and wet-clean floors need the counter-slope detailed at every landing — especially malls, kitchens-adjacent goods lifts, and external landings.

### 9. Machine and pulley rooms — conventional lifts (§3.11–3.17)

#### 9.1 Location, enclosure, permitted uses

| Item | Rule |
|---|---|
| Enclosure | Special room — solid walls, ceiling, and door and/or trap |
| Preferred location | Machine rooms **preferably above** the well |
| Use | Only equipment necessary for lift operation |
| Permitted extras | (a) machines for **service lifts and escalators**; (b) **A/C or ventilation** for these rooms; (c) **FSI** as required by Director of Fire Services for these rooms |
| Sprinklers | **Not normally** fitted in machine/pulley rooms |
| MRL exception (§3.11.1 / §2.3) | No MR if EMSD-approved model; show model + approval on GBP; clear & safe access to control panels/cabinets from **common areas** (not through private premises) |

#### 9.2 Access routes (§3.12) — high SD / planning impact

| Item | Rule |
|---|---|
| From where | **Common areas only** — never via private premises; clear & safe access at all times / all circumstances |
| Clear height of access ways & entrances | ≥ **2 m** (door sills/edges ≤ **400 mm** height permitted) |
| Level difference **&gt; 0.6 m** | Access/egress by **stairs** (§3.12.4) |
| Level difference ≤ **0.6 m** | Ladder OK if: permanently fixed; **and** top end has platform with railings + handhold(s) within easy reach |
| Heavy equipment | Provide means of access for hoisting during erection and replacement — **avoid manhandling on stairs** |

#### 9.3 Stair standard for MR / pit access (§3.12.4)

| Item | Rule |
|---|---|
| Width | ≥ **900 mm** |
| Tread | ≥ **225 mm**, anti-slip surface |
| Riser | ≤ **175 mm** |
| Flight | ≤ **16** steps without a landing |
| Handrails | Properly fixed on **both sides** |
| Outer-edge barrier | ≥ **1.1 m** high |

#### 9.4 Structure, floors, internal dimensions (§3.13–3.14)

| Item | Rule |
|---|---|
| Structure | Withstand normal loads/forces; durable; not favouring dust |
| Floor finish | **Non-slip** |
| Size | Sufficient for easy & safe access to all components, especially electrical equipment |
| Clear height (machine room) | ≥ **2.1 m** for movement/working — measured to underside of **structural roof beams**, from access-area floor **and** working-area floor |
| Pulley room height | ≥ **1.5 m** under roof |
| Multi-level MR floor | Level difference &gt; **500 mm** → stairways/steps + guard rails |
| Recesses / channels | Recess &gt;500 mm deep **and** &lt;500 mm wide, or any channels → cover with steel chequer plate ≥**4 mm** thick (or equivalent strength for maintenance personnel) |

#### 9.5 Doors, trap doors, holes, hoisting (§3.15–3.17)

| Item | Rule |
|---|---|
| Access door — machine room | ≥ **600 mm** W × **1.8 m** H; **must not open inward** |
| Access door — pulley room | Min height **1.4 m**; not inward |
| Person trap door | Clear ≥ **800 × 800 mm**; counter-balanced; when closed support **2 persons** = resist **2000 N** anywhere without permanent deformation; **not open downward**; hinges cannot be unhooked |
| Material-only trap | Locked from the **inside only** |
| Door/trap locks | Openable **without key from inside**; bilingual danger notice ≥**25 mm**: **DANGER / UNAUTHORIZED ACCESS PROHIBITED / MACHINE ROOM / CLOSE AND LOCK THIS DOOR** (+ Chinese) |
| Holes in slab/floor | Minimise dimensions |
| Openings above well (incl. cable holes) | Ferrules ≥ **50 mm** above slab/FFL |
| Hoisting in MR | Metal support(s)/hook(s) with **SWL notice** in ceiling or on beams — for erection & replacement |
| Hoisting in liftwell | Metal support(s)/hook(s) with SWL notice at **ceiling soffit** — for car / suspension rope/device replacement |

#### 9.6 Appendix — alternative machine-room clearances (GBP general note)

If using clearances instead of Table 1 Ra footprint, put this class of note on GBP (customise lift nos.):

| Clearance | Minimum |
|---|---|
| Working space in front of control panels/cabinets | Depth ≥ **0.7 m**; width ≥ **0.5 m** or full panel/cabinet width (whichever greater) |
| Maintenance / inspection of moving parts & manual emergency operation | ≥ **0.5 m × 0.6 m** |
| Access ways to working space | ≥ **0.5 m**; or **0.4 m** where no moving parts / hot surfaces |

Details verified on site upon completion of works.

### 10. Service lifts (§4) — full carve-out

#### 10.1 Scope trigger

Use §4 (not Table 1 / §2–3 full package) when Cap. 618 **service lift** definition is met: ≤**250 kg**; floor ≤**1 m²**; height ≤**1.2 m**.

#### 10.2 Well, doors, ventilation, structure

| Topic | Rule |
|---|---|
| Enclosure | Totally enclosed imperforate walls/floor/ceiling (§4.4 + FS Code Part C) |
| Inspection doors/traps | Only for **servicing**; comply with §3.2.2, 3.2.4, 3.2.6, 3.2.7, 3.2.8 (size/lock/opening rules) |
| Ventilation | If ventilated → must **not** ventilate rooms other than machine/pulley room |
| Structure | Support machine, guide loads at safety-gear operation, buffer operation |
| Materials | Non-combustible, durable, non-dust-creating; adequate strength |
| Entrance-facing walls | Comply with **§3.5** (350 mm smooth band rules) |
| Below accessible space | Prefer not above accessible space; if so → safety gear on car and/or CW per Cap. 618 CoP; well bottom sized for safety-gear & buffer forces |
| Multi-lift well | Comply with **§3.7** partition rules |
| Exclusive use | Comply with **§3.9** (no foreign cables/devices; no sprinklers) |

#### 10.3 Pit (§4.8)

| Item | Rule |
|---|---|
| When required | Pit **not required** except where lowest serving level is **at or near floor level** |
| If provided | Bottom smooth & approx. level; **adequately drained** |
| Depth &gt; **1 m** | Permanent means of access + handholds inside well from landing door; must not project into clear running space |

#### 10.4 Outside well — notices & sill (§4.10)

| Item | Rule |
|---|---|
| Landing sill | Sufficient strength for loads into car |
| Notice at every landing door | Durable, bilingual, ≥**25 mm**: **SERVICE LIFT / PERSONS ARE FORBIDDEN TO ENTER THE LIFT CAR OR ENCLOSURE** / **貨物專用升降機 禁止內進** |

#### 10.5 Machinery space (§4.11)

| Rated load | Floor / envelope | Clear height | Access door | Floor strength / reach |
|---|---|---|---|---|
| **≥ 150 kg** | Floor area ≥ **1.5 m × 1.5 m** | ≥ **1.2 m** | ≥ **1.0 m** H × **1.2 m** W | Floor adequate for personnel + equipment at every point |
| **&lt; 150 kg** | Depth ≤ **600 mm** | ≥ **800 mm** | ≥ **800 mm** H; width = lesser of **900 mm** or full machinery width | Either same floor strength as ≥150 kg **or**: reach all equipment by hand while standing outside + rigid partition/wire mesh to stop objects falling into well |

| Common rules | Detail |
|---|---|
| Location | Enclosure **within** liftwell **or** separate machine room |
| Construction | Sound, weather-proof, dry; safe access to all equipment |
| Door orientation | Facing machine & ancillary equipment for install/maintenance |
| Lock + notice | Lockable; same machine-room danger notice as §3.15.3 |
| Access route | Comply with **§3.12.2** (stairs if rise &gt;0.6 m; ladder rules if ≤0.6 m) |
| Exclusive use | No other purposes; no ducts/cables/devices other than for the lift |

### 11. Escalators (§5) — SD space killers

#### 11.1 Separate machine rooms / driving & return stations (§5.1)

| Item | Rule |
|---|---|
| When | Where separate machinery space and/or separate driving & return stations are provided |
| Enclosure | Special room — solid walls, ceilings, door and/or traps |
| Use | Only equipment for escalator operation |
| Permitted extras | Lift/service-lift machines; room A/C or ventilation; FSI as required by DFS |
| Sprinklers | **Not normally** fitted |
| Clear height | ≥ **2.1 m** |
| Size | Sufficient for easy & safe access to all components, especially electrical |
| Access | Entirely by **stairs** if level difference so requires |
| Ladder fallback | Only if stairs impractical: permanently fixed; if ladder height **&gt; 2 m** → safety hoops or other fall-arrest system; top platform with railings + handhold(s) |
| Notices | Same machine-room danger notice (≥25 mm) on access doors/inspection traps |

#### 11.2 Steps and landings — unrestricted passenger area (§5.2)

| Item | Rule |
|---|---|
| Width of unrestricted area | ≥ distance between escalator **handrail centrelines** |
| Depth (from end of balustrade) | ≥ **2.5 m** — **or** ≥ **2.0 m** if unrestricted width ≥ **2×** handrail-centreline distance |
| Clear height | ≥ **2.3 m** above: (a) steps at **all points**; and (b) the unrestricted landing area |

**Worked SD check:** 1000 mm handrail CL spacing → unrestricted width ≥1000 mm and depth ≥2500 mm; **or** width ≥2000 mm and depth ≥2000 mm. Clear height 2300 under soffits/beams/signs over the entire escalator run and landing box.

#### 11.3 Obstructions (§5.3)

| Item | Rule |
|---|---|
| Building parts that may hit riders | At floor intersections, criss-cross escalators, etc. → obstruction guards per Cap. 618 **Design & Construction of Lifts and Escalators** CoP |
| Handrail to wall / obstruction | Horizontal distance from **outer edge of handrail** to any wall or building part likely to obstruct: **never &lt; 80 mm** |

**SD takeaway:** Escalator planning is driven by the **2.5 m (or 2.0 m widened) clear landing**, **2.3 m headroom**, and **80 mm** side clearance — these routinely break atrium/mall sections and tight retail cores if ignored until DD.

### 14. SD checklist (print / pin)

**Type & sizing**
- [ ] Passenger vs **service lift** vs escalator path chosen correctly
- [ ] Rated load, speed, conventional vs **MRL** fixed with supplier
- [ ] Well Ww×Wd, pit Ph, headroom Sh / Uh from **Table 1** (watch **≥2.0 m/s** and **3.5 m/s** jumps)
- [ ] Cw×Cd ≤ Ca; MR Rw×Rd ≥ Ra (or Appendix clearances note on GBP)
- [ ] Firemen’s lift need flagged → B(P)R 41B / FS Code Part D

**Well & landings**
- [ ] Totally enclosed well; exclusive use; **no sprinklers** in well
- [ ] Entrance-band finishes: no plaster/glass in 350 mm zone; smooth + 25 mm side extension
- [ ] Roof/MR **vent** ≥1% well area (min 0.3 m²; shared 4/5/6 lifts → 0.4/0.5/0.6)
- [ ] Open-air discharge meets B(P)R “open air”
- [ ] Landing sill spacing ≤**11 m** or intermediate emergency doors
- [ ] Landing **counter-slope** + fire notices (≥15 mm)
- [ ] Dual-key / single-key strategy for inspection/rescue doors understood

**Under / multi / pit**
- [ ] No accessible programme under shaft without **5 kPa** + pier **or** CW safety gear
- [ ] Multi-lift well: full-height/full-depth partition (+ per-well vents if solid walls)
- [ ] Pit waterproofing strategy; access door if Ph &gt;2 m (and if &gt;1.6–2.0 m where layout permits)
- [ ] Fall-arrest anchorage 1.5–1.8 m at lowest landing **or** compliant pit door

**Machine room / MRL**
- [ ] MR preferably above shaft **or** MRL + common-area cabinet access
- [ ] MR access from common area only; clear height ≥2 m on access route
- [ ] Stair ≥900 / tread≥225 / riser≤175 if rise &gt;0.6 m
- [ ] MR clear height ≥2.1 m to structural beams; pulley room ≥1.5 m
- [ ] Hoisting hooks in MR **and** liftwell soffit with SWL notices
- [ ] No sprinklers normally in MR; FSI only as DFS requires

**Service lifts / escalators**
- [ ] Service lift: machinery dims by ≥150 / &lt;150 kg; landing “persons forbidden” notice
- [ ] Escalator: unrestricted landing **2.5 m** (or **2.0 m** if double width); clear height **2.3 m**; handrail clearance ≥**80 mm**; obstruction guards at intersections
