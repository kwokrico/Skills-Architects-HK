# Code of Practice on Access for External Maintenance 2021
**Architect critical summary for schematic design**  
First issue February 2021 | 2024 Edition (Sept 2024 amendments via PNAP APP-163) | Buildings Department

> Scope note: Deemed-to-satisfy guidance for **B(C)R Cap. 123Q ss. 27(2), 28(5), 31(3) and 34(3)** — adequate maintenance & repair (M&R) access to the **outer surface** of external walls, claddings, curtain walls, roofs, and projections therefrom. Supersedes the advisory CoP on Design for Safety – External Maintenance 2019. Does **not** override OSHO / FIUO work-at-height duties. Always cross-check FS Code Parts B & C, B(C)R protective barriers, Loading Code, Wind Code, PNAP APP-2 / APP-19 / APP-93 / APP-110 / APP-117 / APP-126 / ADV-11, JPN 1 & 2, and CIC cast-in anchor guidelines (Version 2).

---

## Regulatory Overview

This Code applies to **all buildings** where B(C)R requires adequate means of access for maintenance of external walls, curtain walls, external claddings, roofs, and building projections (balconies, UPs, AC platforms, canopies, fins, signboards, drainage pipes, vertical greenery, roof plant, solar frames, etc.). Compliance with the Code is **deemed to satisfy** those B(C)R M&R-access provisions.

At schematic design, lock the **access strategy per façade zone / roof / projection type** before fixing recesses, free-form profiles, podium setbacks, roof plant, and AC disposition — the Code’s **≤ 500 mm hand-reach** rule, element-specific allowed access methods, and DMC / GFA hooks drive massing, core/stair to roof, BMU/gondola parking, and balcony/AC typology.

## Critical main topics and subtopics

### 1. Terms that change the design brief (Part 1 §2)

| Term | Meaning for SD |
|---|---|
| **External building element** | External wall, CW, external cladding, **or** roof — **plus** any projection from those |
| **Maintenance** | Inspection, routine cleansing, repair **and replacement** of defective external elements and components |
| **Projection** | B(P)R Part II projections, PNAP APP-19 projections, BO signboards, **and** other architectural projections — eave, cornice, moulding, overhang, fin, canopy, sun-shade, reflector, projecting window, balcony, UP, projecting planter, drying rack, AC platform, external drainage pipe, vertical-greenery support frame, retractable awning |
| **Projection from a roof** | Anything erected/installed on a roof — architectural projection, water tank, gantry, lightning rod, signboard, solar energy support structure, etc. |
| **Roof** | Flat, main, upper, pitched, profiled, skylight, membrane, **and** roof of covered walkway or footbridge |
| **Direct staircase** | Stair providing access to an **accessible** roof (not a cat ladder) |
| **Suspended working platform / gondola** | Cap. 59AC definition — suspended scaffold/platform with lifting gear; **excludes** boatswain’s chair; includes appliances, counterweights, ballast, outriggers, mechanical/electrical apparatus |
| **Power-operated elevating work platform** | Cherry pickers / aerial platforms — vehicle-mounted, self-propelled, towed or manually moved |
| **Maintenance access ladder and gantry system** | Track-mounted gantries on the building — for **inclined façade, dome roof, skylights** or similar free-form features |
| **Fixed maintenance ladder / external walkway** | Metal cat ladder or maintenance walkway |

**SD takeaway:** “Roof” and “projection” are broad — walkway roofs, footbridge roofs, solar frames and lightning rods are all in scope. Free-form / inclined / dome geometry almost always triggers a **gantry** strategy, not a simple vertical gondola alone.

### 2. Lock access strategy before façade articulation (Part 2 §1 + Part 3 §1)

| Rule | SD implication |
|---|---|
| Suitable, adequate, **safe** M&R access to **every** EW / CW / cladding / roof / projection | No orphaned façade bay, deep recess, decorative fin, or planter without a named access method |
| Part 2 list is **not exhaustive**; combination of types allowed | Mix gondola + access windows + cherry picker + walkways by zone — document on elevations early |
| Design of projection / recess / free-form profile must still allow **bamboo scaffold** erection (BD Bamboo Scaffold Guidelines) | Gondola alone does not excuse unscaffoldable geometry |
| Workers must reach intended element within **≤ 500 mm** hand-reachable range in front of it | Deep recesses, stacked fins, stepped façades, and deep canopies commonly fail — redesign geometry or add walkway / gantry |
| M&R access sized for operational need **including material delivery** | Window/door clearances are not “person only” |
| If access is via **individual premises** | DMC (or SPA / Assignment / Tenancy if no DMC) must grant reasonable right of access for M&R personnel |
| Parallel compliance | FS Code **Parts B & C**; B(C)R ss. **36, 37, 38** protective barriers; B(P)R **3A**; PNAP **APP-110**; Loading Code |
| Fall risk ≥ **2 m** | Guard-rails + toe-boards (App. D) **unless** B(C)R ss. 37–38 protective barrier provided |
| Guard-rail design loads | Loading Code Table 3.13 — “Area where congregation of people is **not** expected”; if wind-exposed, take **more stringent** of imposed vs Wind Code |
| Cast-in anchors | App. D §7 + CIC Guidelines; structural details for BO approval |

**SD takeaway:** Treat maintainability as a massing constraint equal to MOE and OTTV. Freeze an elevation-by-elevation access matrix before SD freeze.

### 3. Element-by-element requirements (Part 2) — what you must provide

Each subsection below: **what M&R covers** → **allowed access** → **extra SD hooks**.

#### 3.1 External wall, curtain wall, external cladding (§2)

| Item | Detail |
|---|---|
| M&R scope | Inspection, cleansing, repair/replacement of wall finishes, windows, window walls, glass panes, cladding panels, etc. |
| Allowed access | Maintenance access **window**; maintenance **door**; cherry picker; **gondola** |

**SD:** Full-height CW / unitised cladding on towers → gondola + façade restraint grid from concept. Low podium / courtyard may use cherry picker **only if** parking + reach geometry work (see §8).

---

#### 3.2 Air-conditioner (AC) platform (§3.1 + App. B & C)

| Item | Detail |
|---|---|
| M&R scope | Inspection, cleansing, repair/replacement of AC **and** of the platform itself |
| Access **into** platform | Access window **or** balcony/UP **combined** with AC platform (must follow App. B) |
| Access to **outer surface** of platform | Cherry picker **or** gondola only |
| Dual use | Platform may serve as M&R access for **other** utilities/services **if** AC working space is not jeopardised |
| Mandatory | **All** App. C design & safety provisions |

→ Full dimensional / GFA rules in **§10** below.

---

#### 3.3 Balcony and utility platform (§3.2)

| Item | Detail |
|---|---|
| M&R scope | Inspection, cleansing, repair |
| Access **onto** balcony/UP | Maintenance access **door** (not merely a window) |
| Access to **outer surface** | Cherry picker **or** gondola |
| Fall-arrest anchor | ≥ **1** per every balcony **and** every UP |

| Anchor rule | Requirement |
|---|---|
| Reach | Readily accessible from adjoining floor |
| Height | **1.5–1.8 m** above adjoining FFL |
| Compliance | App. D §7; structural / fixing details submitted under App. F |

**SD:** Every residential balcony/UP needs an anchor position in the wall/parapet design from SD — not a DD add-on. Outer-face cleaning still needs gondola or cherry picker.

---

#### 3.4 Canopy (§3.3)

| Item | Detail |
|---|---|
| M&R scope | Inspection, cleansing, **debris removal**, repair/replacement of canopy **and drainage outlet** |
| Allowed access | Cherry picker; gondola; maintenance access window |

**SD:** Deep street canopies often exceed 500 mm hand-reach from a façade gondola — either keep canopy shallow enough for access-window/gondola reach, or plan dedicated cherry-picker / walkway access including drainage outlets.

---

#### 3.5 Drying rack (§3.4)

| Item | Detail |
|---|---|
| M&R scope | Cleansing, repair/replacement of defective part |
| Allowed access | Access window; access door; cherry picker; gondola |

---

#### 3.6 External drainage pipe (§3.5)

| Item | Detail |
|---|---|
| M&R scope | Inspection, repair/replacement of defective drainage pipes |
| Allowed access | **Cat ladder + grating platform in pipe well** (PNAP **APP-93**); projecting platform (e.g. AC platform); access window; cherry picker; gondola |
| New buildings | Planning & design of M&R access to drainage **must** comply with **PNAP APP-93** |

**SD:** Pipe-well strategy (APP-93) vs façade-hung stacks with gondola/AC-platform access — decide at SD with BS/drainage. Do not leave “external SVP with no access” as a default.

---

#### 3.7 External vertical greenery (§3.6)

| Item | Detail |
|---|---|
| M&R scope | Inspection, general gardening, repair of drainage points, irrigation/drainage pipework, **and supporting frame** |
| Allowed access | Cherry picker; gondola; **or** fixed walkway from interior via access window **or** maintenance door |

**SD:** Living walls need either continuous gondola coverage **or** a fixed walkway band with interior access doors/windows. Irrigation/drainage repair is in scope — not just leaf trimming.

---

#### 3.8 Planter box (§3.7)

| Item | Detail |
|---|---|
| M&R scope | Cleansing, irrigation, replacement of flower pots |
| Outer-surface access | Access window; cherry picker; gondola |

---

#### 3.9 Projecting window (§3.8)

| Item | Detail |
|---|---|
| M&R scope | Inspection, cleansing of glass, repair/replacement of panes, casements, sealant |
| Outer-surface access | Access window; cherry picker; gondola |

**SD:** Bay / projecting windows create outer faces that a room window cannot reach — count them as separate outer-surface zones on the access matrix.

---

#### 3.10 Signboard (§3.9)

| Item | Detail |
|---|---|
| M&R scope | Inspection, repair/replacement of signboard and components |
| Allowed access (other than inspection panel) | Fixed maintenance ladder or external walkway; maintenance staircase; ladder + gantry accessible from interior via access window/door; cherry picker; gondola |
| Concealed fixings / structural members | Inspection panel required **unless** designated exempted works under Building (Minor Works) Reg Cap. 123N Sch. 2 Part 2 |
| Inspection panel size | Side or diameter ≥ **200 mm** |
| Operability | Readily openable **without** special tools or destructive means |
| Vinyl / banner exception | Panel **not** required if banner/vinyl on supporting frame is readily removable to expose concealed fixing |

**Roof signboard height trigger (accessible or inaccessible roof):** if any part is **> 5 m** above roof finishes → **fixed maintenance ladder or external walkway** mandatory (§4.1.4 / §4.2.5).

**SD:** Large podium / tower crown signs need inspection-panel detailing and often a dedicated ladder/walkway — coordinate with APP-126 early.

---

#### 3.11 Architectural projections (§3.10)

Sun-shade, reflector, eave, cornice, moulding, overhang, fin, and other architectural projections.

| Item | Detail |
|---|---|
| M&R scope | Inspection, repair/replacement of defective part |
| Allowed access | Access window; cherry picker; gondola |

**SD:** Feature fins and deep sun-shades are the classic 500 mm hand-reach failures. Either thin them, interrupt them with access gaps, or add walkway/gantry.

### 4. Roofs — accessible vs inaccessible (Part 2 §4)

#### 4.1 Accessible roof

| Item | Rule |
|---|---|
| Definition (implied) | Roof intended for occupation / general access (not M&R-only) |
| Edge | Protective barrier per B(C)R ss. **37 & 38** |
| M&R scope | Inspection, cleansing, repair/replacement of roof finishes, features, facilities (**incl. solar energy system and building services**) and signboards |
| Access | **Direct staircase** or maintenance door |
| Tall signboard | Fixed ladder/walkway if any part **> 5 m** from roof finishes |

#### 4.2 Inaccessible roof

| Item | Rule |
|---|---|
| Definition | **Not** intended for occupation; accessible to M&R personnel only |
| M&R scope | Same family of works — finishes, features, facilities (water tank, solar, BS), signboards |
| Access | Fixed ladder/walkway; ladder + gantry; maintenance door; cherry picker; gondola |
| If workers **step onto** the roof | Permanent guard-rails + toe-boards at edge (App. D §4), **or** approved alternatives below |

##### Alternatives when full permanent perimeter rails are impracticable (§4.2.3–4.2.4)

| Option | Conditions |
|---|---|
| (i) Proprietary **collapsible** guard-rail | Designed for imposed + wind loads **not inferior** to B(C)R, Loading Code, Wind Code |
| (ii) Temporary edge protection + platform + access ladder | Per **prior** risk assessment (LD “Overview of Work-at-Height Safety” §3 + “Five Steps to Risk Assessment”) |

**Mandatory accompanying provisions for (i) and/or (ii):**

| Item | Requirement |
|---|---|
| Anchorage / horizontal lifeline | For personal fall-arrest **and/or** travel-restraint; OSHO + FIUO compliant |
| Location | At **roof access**, **or** other locations **≥ 2 m** from roof edge / fragile area |
| Clip-on sequence | Lanyard attachable **before** user moves into a fall-risk position (to erect collapsible rails / temp protection) |
| Access within **2 m** of edge / fragile area, **or** opens onto pitched roof | **Permanent** guard-rails at least around the access point / landing |
| GBP note (where appropriate) | Anchorage points / horizontal lifeline as indicated on building plan / M&R plan; structural details submitted separately |
| Temporary edge protection (operational) | Before each M&R task: LD Five Steps risk assessment + temp protection + platform/ladder per OSHO / FIUO |

**Tall signboard on inaccessible roof:** same **> 5 m** → fixed ladder/walkway.

**SD takeaway:** Decide roof typology early. Accessible = stair + permanent B(C)R barrier (GFA / headroom / escape implications). Inaccessible = ladder/gantry + edge strategy; pitched / membrane / skylight / fragile roofs almost always force inaccessible + careful anchor placement ≥ 2 m from edges.

### 5. Projection from a roof (Part 2 §5)

| Item | Detail |
|---|---|
| M&R scope | Inspection, cleansing, repair/replacement of defective part |
| Allowed access | Fixed ladder/walkway; ladder + gantry; maintenance **staircase**; cherry picker; gondola |

**SD:** Water tanks, solar arrays, roof gantries and crown signs each need a named path — do not assume “roof is accessible so everything on it is covered.”

### 6. Suspended working platform / gondola (Part 3 §2.1)

Must be designed into the building from SD — not a façade-consultant afterthought.

| Requirement | Detail |
|---|---|
| Building design | Building designed/constructed to take the gondola serving its designed functions |
| Structure | All supporting frames, members, fixings **including any screen** — all load combos **incl. wind**; BO approval |
| Durability | Corrosion resistant **or** anti-corrosion protection |
| MOE | Must **not** obstruct FS Code Part B means of escape |
| Parked / idle | Properly **tied** to the building to prevent undue movement |
| Façade restraints | Strategic restraints on wind-exposed façades — prevent tip, tilt, sway, horizontal movement in operation |
| Access to platform | Suitable, adequate, safe |
| Boarding at height (fall ≥ 2 m) | ≥1 permanent **cast-in anchor** on roof for **each** worker’s fall-arrest device |
| **Temporary** gondola option | Provide mechanical **booms or roof anchorages** now for later installation; all associated members/fixings/anchorages corrosion protected |

**SD checklist:**
- Roof plant zone + davit/boom positions reserved
- Gondola parking / tie-down without blocking escape stairs, refuge floors, or firefighting access
- Elevation restraint-socket grid coordinated with CW mullion rhythm
- Cradle length and tie-back restraint strategy sketched for App. F technical specs

Also reference: PNAP **ADV-11**, Cap. 59AC, LD CoP for Safe Use and Operation of Suspended Working Platforms.

### 7. Maintenance access window, door, stair, ladder, walkway, gantry (Part 3 §2.2–2.6)

#### 7.1 Maintenance access window (§2.2)

| Rule | Dimension / detail |
|---|---|
| Clear opening | ≥ **460 mm wide × 1100 mm high** (for M&R **including material delivery**) |
| Sill | ≥ **1.1 m** above internal FFL of adjoining floor |
| Cast-in anchors | ≥1 permanent cast-in at external wall; worker attaches **before** climbing out |
| Anchor position | Close to window; readily accessible; **1.5–1.8 m** above adjoining FFL |
| Sash conflict | Opened window must **not** obstruct use of cast-in anchors |

#### 7.2 Maintenance staircase (§2.3)

| Rule | Detail |
|---|---|
| Width | ≥ **900 mm** (workers holding equipment/materials) |
| Guard-rails | Both sides; App. D §4 |

#### 7.3 Maintenance door (§2.4)

| Rule | Detail |
|---|---|
| Size | ≥ **600 mm wide × 2000 mm high** |
| Security | Locked — avoid misuse / unauthorised access |
| Warning notice | Outside face, conspicuous; English **and** Chinese; letters/characters ≥ **25 mm** high |

Exact wording required:

```
DANGER
UNAUTHORISED ACCESS PROHIBITED
CLOSE AND LOCK THIS DOOR

危險
不得擅進
請關閉並緊鎖此門
```

#### 7.4 Fixed maintenance ladder (§2.5.1 + App. D §8)

| Rule | Detail |
|---|---|
| Ladder width | **400–600 mm** |
| Safety hoop width | **650–800 mm** |
| Slab opening for access | Side or diameter ≥ **500 mm** |
| Rise > **3 m** (highest point to ground/floor) | Anti-climb device at lower level (ladder guards/lock etc.) **+** suitable safety hoops |
| Rest landings | ≤ **9 m** centres; with guard-rails + toe-boards (Part 3 §1.4) |

#### 7.5 Fixed external walkway (§2.5.2)

| Rule | Detail |
|---|---|
| Edge protection | App. D §4 |
| Obstruction | Must **not** obstruct M&R of external building elements |
| Over roof / other projections | Clear working height **underneath** walkway ≥ **1.2 m** |

#### 7.6 Maintenance access ladder and gantry system (§2.6)

| Rule | Detail |
|---|---|
| Design | Fit building profile **and** the specific M&R works |
| Safety | Comply with App. D §8 |
| Typical triggers | Inclined façade, dome roof, skylights, free-form features |

### 8. Power-operated elevating work platform / cherry picker (Part 3 §2.7)

| Rule | Limit |
|---|---|
| Vertical coverage | Extent of external walls accessed ≤ **1.5 m above** platform level at **maximum** operating height |
| Parking | **Levelled and firm designated area** in the development for parking the platform |

**SD takeaway:** Low-rise / podium / courtyard façades can rely on cherry pickers **only if** (a) ground/podium can reach the full height within the 1.5 m-above-platform rule, and (b) a permanent parking bay is reserved. Tall towers almost always need gondola + restraints. Vehicle path, headroom under transfer structures, and soft landscaping must not sterilise the parking/operating zones.

### 9. Reverse matrix — access method → which elements (App. E)

Use this when choosing systems at SD (mirrors BD’s checklist logic):

| Access method | Typically covers |
|---|---|
| **Gondola** | AC platform (outer); balcony/UP (outer); canopy; architectural projections; CW; drying rack; cladding; drainage; vertical greenery; EW; inaccessible roof; planter; roof projections; projecting window; signboard |
| **Access window** | AC platform; canopy; architectural projections; drying rack; drainage; vertical greenery; EW; signboard; planter; projecting window |
| **Maintenance staircase** | Roof projections; signboard |
| **Maintenance door** | Vertical greenery; inaccessible roof; signboard *(also: balcony/UP access onto the platform itself per §3.2)* |
| **Fixed ladder / external walkway** | Drainage; vertical greenery; inaccessible roof; roof projections; signboard |
| **Ladder + gantry system** | Inaccessible roof; roof projections; signboard *(esp. free-form)* |
| **Cherry picker** | AC platform; balcony/UP; canopy; architectural projections; CW; drying rack; cladding; drainage; vertical greenery; EW; inaccessible roof; planter; roof projections; projecting window; signboard |

### 10. AC platforms — full design rules (App. B & C)

#### 10.1 Combined balcony/UP + AC platform (App. B)

Disposition must follow **Figures B1 / B2 / B3** (AC in balcony; AC in UP; AC in combined balcony+UP — one AC platform also acceptable on combined).

| Criterion | Requirement |
|---|---|
| (a) Disposition | Figures B1, B2 or B3 |
| (b) Level change | ≥ **50 mm** rise from balcony/UP FFL into AC platform |
| (c) Working space location | Front **or** back of AC; **direct** access from balcony/UP |
| (d) Working space size | Length ≥ length of AC platform; depth ≥ **400 mm** |
| (e) Outer edges | Protective barriers per B(C)R ss. **37 & 38** |
| (f) Screens separating AC from balcony/UP | Height ≤ **1.6 m**; permeability ≥ **70%** (visual **and** physical porosity) |
| (g) Screens at platform edge | ≤ balcony/UP parapet level (≤ **1.6 m** if stacked ACs); permeability ≥ **70%** |

##### GFA exclusion of the AC platform (App. B (h)) — all must apply

| Condition | Detail |
|---|---|
| Connected balcony/UP | Must be under **JPN 1 and JPN 2** |
| Platform area | Each AC platform (B1–B3) ≤ **0.8 m²** |
| Perimeter / covered area | Outer edges of AC platform **excluded** from balcony/UP perimeter and from covered area under lowest balcony/UP |
| Open-air 40% test | Use perimeter of **merged** balcony/UP + AC floor; edge screen (g) higher than parapet is **not** “facing into the open air” |
| DMC / SPA undertaking | Designate AC platforms as **‘areas for air-conditioning’** with use + location; **forbid** individual AC platforms on external walls of the building |

#### 10.2 Standalone / all AC platforms — App. C

**Show on GBP:** platform size **and** AC size (to prove working space).

| Parameter | Limit |
|---|---|
| Access opening | Normally ≥ **460 × 1100 mm**; **never** smaller than the AC unit |
| Opening bottom | ≤ **1300 mm** above adjoining AC platform FFL |
| Max projection | ≤ **900 mm** — **disregard** thickness of protective barrier / guard-rail / screen **and** their supports |
| Width | Only for housing AC + working space — **not** a catwalk |
| Working space (front or back) | Length ≥ length of AC; depth ≥ **400 mm** |
| Side working / landing via window | ≥ **400 mm**; may increase to max **500 mm** if also worker’s landing through window |
| Passage use of working space | Allowed to other ACs / services **if** screens (§5) or guard-rails (§6) **and** cast-in anchors (§6) provided |
| Minor encroachment | e.g. stacked-AC support frame — may be accepted |
| Ventilation gap | ≥ **100 mm** between AC and outer edge / inner face of screen / external wall |
| Stacked ACs (access from unit) | Max **2** layers; screen ≤ **1.6 m** |
| Single-layer screen height | **0.9–1.1 m** |
| Other services through platform | Allowed if working space / safety not compromised (e.g. vertical stack outside working space; horizontal run above platform) |

##### Screens (App. C §§4–5)

| Rule | Detail |
|---|---|
| Thickness | ≤ **50 mm** |
| Permeability | ≥ **70%** from elevation |
| Panels | Size/weight reasonably operable by one trade worker |
| Impact load | Loading Code Table 3.13 “congregation not expected” |
| Dual role | Compliant screen may serve as guard-rail under §6 |
| Projection measurement | Screen/guard-rail + supports **excluded** from the 900 mm max projection |

##### Anchors and guard-rails on AC platforms (App. C §6)

| Rule | Detail |
|---|---|
| When | Where access to an external wall is required |
| Standard | CIC Guidelines on Cast-in Anchors at External Walls of New Buildings (Version 2) |
| Drawings | Design + location on **GBP and structural plans** |
| Mandatory GBP note | *“Cast-in anchors and guard-rails at air conditioner platforms will be provided in accordance with the Code of Practice on Access for External Maintenance. Their structural details will be submitted separately for approval.”* |

**SD takeaway:** Decide AC strategy at SD — (1) combined JPN balcony/UP ≤ 0.8 m² with DMC control, (2) separate App. C platforms ≤ 900 mm projection, or (3) central plant / no external AC. Outer-face cleaning of the platform still needs gondola or cherry picker.

### 11. Occupational safety dimensions & hierarchy (App. D)

Designers must leave geometry that lets employers/occupiers meet OSHO / FIUO; this Code does **not** replace those duties.

| Trigger | Requirement |
|---|---|
| Construction / M&R with fall ≥ **2 m** | Third Schedule, Construction Sites (Safety) Reg Cap. 59I |

| Element | Dimension |
|---|---|
| Top guard-rail | **900–1150 mm** |
| Intermediate rail | **450–600 mm** |
| Toe-board | ≥ **200 mm** |
| Gangway / run | ≥ **400 mm** wide |
| Gangway for material movement | ≥ **650 mm** so far as reasonably practicable |
| Workplace platform fencing (OSHR Cap. 509A s.6) | Securely fenced ≥ **900 mm**; if not practicable → effective personal fall protection |

| Hierarchy (App. D §6) | Rule |
|---|---|
| First choice | Safe suitable working platform + access/egress |
| Last resort / supplementary only | Personal fall protection including cast-in anchors |

| Anchorage standards (App. D §7) | LD Guidance Notes on Safety Belts & Anchorage Systems **+** CIC Cast-in Anchor Guidelines (Version 2) |

| Occupier duty reminder | OSHO s.7 — where workplace is not under employer’s control, **occupier** (e.g. owner) must ensure premises and access/egress are safe so far as reasonably practicable |

### 12. Cast-in anchors — structural / material rules (App. F §3 + App. G)

| Rule | Detail |
|---|---|
| Host structure (new buildings) | External RC walls ≥ **125 mm** thick, **or** external structural elements |
| Placement | Pre-determined locations; installed **before** casting supporting structure |
| Visibility / safety | Safely accessible and easily visible; securing/detaching must **not** expose worker to fall risk |
| Design life | Same as building design life |
| Anchor bars (CIC example) | Stainless steel Grade **B500**, BS 6744:2016 designation **1.4436** (or equivalent); min Ø **16 mm**; **or** designed to sustain Type A load test per **BS EN 795:2012** |
| A&A / existing buildings | Drill-in anchors allowed only with structural viability assessment (PNAP **APP-117**) submitted with structural plans |

### 13. Submission, undertakings & OP (App. F) — AP programme hooks

#### 13.1 M&R access plans content

| Item | Requirement |
|---|---|
| (a) Drawings | Plans, elevations, sections — legible ratio, preferably ≥ **1:300** — location + design of M&R access to external elements at **each floor/zone**, building by building |
| (b) Technical specs | Adequacy proof — e.g. cradle length, tie-back restraints for gondolas |
| (c) Summary | App. E checklist-style summary of proposed access |

#### 13.2 Timing vs GBP / consent

| Stage | Action |
|---|---|
| First GBP | M&R access plans **need not** be final |
| Required GBP note | *“Before applying for the consent to commence the superstructure works, the provisions for M&R access required under the Code of Practice on Access for External Maintenance will be submitted to and approved by BD.”* |
| Before superstructure consent | Full M&R access package submitted **and approved** |
| Structural (separate submission) | Cast-in anchors, restraint sockets, mechanical booms / anchorages for temporary gondolas, etc. |

#### 13.3 Structural plan package (App. F §4)

Include as applicable:
- Framing, details, sections and/or elevations
- Design loads
- Anchors and support details
- Design standards / codes
- Material specs (steel, aluminium, cast-in / drill-in anchors, fixings, proprietary products)
- Workmanship: welding, galvanisation, **bi-metallic** effects, durability / corrosion prevention
- Calculations: parent-structure check under M&R loads; adequacy/stability of M&R structures; element design (steel / aluminium / metal grating); deflection of major members

#### 13.4 Letter of undertaking (App. F §5) — **mandatory for new buildings**

| Content | Detail |
|---|---|
| Common areas | Designate M&R access as **‘common areas’** in DMC with use + location |
| Timing | Submit together with GBP that includes M&R access provisions |
| Access via premises | DMC must allow reasonable right of access by M&R personnel |
| No DMC | Same designation + access route / egress for communal use + right of access in SPA / Assignment / Tenancy |

#### 13.5 Record plans at OP / BA14 (App. F §7)

In addition to PNAP **APP-13**: submit an **additional set** of M&R access record plans on OP application (or BA14 for A&A where M&R access is proposed) — for referral to **Labour Department**.

### 15. Schematic design kill-list (check before freezing massing)

1. **Every** façade zone / projection / roof element has a named access method that achieves ≤ **500 mm** hand reach — including deep recesses, fins, canopies, bay windows, planters, and vertical greenery.
2. Recess / free-form / projection geometry still allows **bamboo scaffold** erection as a fallback.
3. Tower elevations: gondola path + façade **restraint** grid; roof davits/booms/parking/tie-down without blocking MOE / refuge / FSI access.
4. Temporary-gondola option (if used): roof booms/anchorages reserved and corrosion-protected from day one.
5. Podium / courtyard / low-rise: cherry-picker reach within **1.5 m-above-platform** rule + **designated firm parking** area.
6. Roof typology decided: accessible (direct stair + B(C)R barrier) vs inaccessible (ladder/gantry + permanent or collapsible edge strategy + anchors ≥ **2 m** from edge/fragile; permanent rails at access if within 2 m or onto pitched roof).
7. Roof plant / solar / tanks / crown signs each have a named access path; roof signboards **> 5 m** get fixed ladder/walkway.
8. AC strategy locked: combined JPN balcony/UP (≤ **0.8 m²**, DMC controls) vs App. C platforms (≤ **900 mm** projection, ≥ **400 mm** working space, ≥ **100 mm** vent gap) vs no external AC; GBP will show platform + AC sizes.
9. Every balcony/UP: maintenance **door** access + fall-arrest anchor at **1.5–1.8 m** AFFL.
10. Pipe wells / external drainage: **APP-93** path (cat ladder + grating) or equivalent façade access.
11. Signboards: ≥ **200 mm** inspection panels for concealed fixings (unless MW-exempt or removable vinyl); access method named.
12. Maintenance windows ≥ **460 × 1100** with sill ≥ **1.1 m** and anchors **1.5–1.8 m**; doors ≥ **600 × 2000** lockable with bilingual 25 mm warning; stairs ≥ **900 mm**; ladders 400–600 mm with hoops 650–800 mm, anti-climb if > 3 m, rests ≤ 9 m; walkways leave ≥ **1.2 m** clear underneath.
13. Cast-in anchors: host EW ≥ **125 mm** RC (or structural element); design life = building life; shown on GBP.
14. Legal path: M&R access as DMC **common areas**; right of access through premises if needed; GBP superstructure-consent note; programme for App. F package before consent; OP record plans for LD.
