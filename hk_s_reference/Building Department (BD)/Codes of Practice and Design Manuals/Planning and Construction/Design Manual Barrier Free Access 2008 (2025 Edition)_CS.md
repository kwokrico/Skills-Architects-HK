# Design Manual: Barrier Free Access 2008
**Architect critical summary for schematic design**  
2025 Edition (June 2025 revision; amendments via PNAP APP-41 through May 2024 / June 2025) | Buildings Department

> Scope note: Chapters 3–4 **Obligatory Design Requirements** align with the **Third Schedule of the Building (Planning) Regulations**. Alternative designs are acceptable only if they achieve the stated **Performance Objectives**. Best Practice / Recommended items are **not** B(P)R minima — use them for tender quality, elderly / welfare briefs, and client-enhanced schemes. Read with PNAP APP-41 / APP-152 for BD plan-marking. Visual fire alarm cross-refers FSD CoP; lift emergency call cross-refers Cap. 327 CoPs.

---

## Regulatory Overview

This Manual governs **barrier-free access and facilities** for persons with a disability (vision, hearing, locomotion — including ambulant, wheelchair, blind/deaf) and supports elderly / infirm users. It applies to **new buildings and A&A**. Extent is locked by **Table 1** (domestic / non-domestic / composite) plus **Table 2** (extra assistive provisions by use). Mandatory = Performance Objectives + Obligatory Design Requirements; Best Practice = Design Considerations + Recommended Design Requirements.

**Exempt buildings (§2.2.1):** single-family ≤ **13 m** above ground; temporary buildings / contractor’s sheds (B(P)R Part VII). **Exempt areas (§2.2.2)** even inside otherwise covered buildings: commercial kitchen / cold room / cinema projector room; plant & maintenance-only spaces; hazardous or non-public bulk stores; storage-only mezzanines; security / lifeguard raised platforms; swimming-pool **water body** only; any path serving only an exempted area.

## Critical main topics and subtopics

### 1. How the Manual is structured — what is enforceable at GBP

| Layer | Status | SD use |
|---|---|---|
| **Performance Objectives** | Guiding principles | Alternative design must still meet these |
| **Obligatory Design Requirements** | **Must comply** (Third Schedule / related CoPs) | Lock geometry, counts, routes on GBP |
| **Design Considerations** | Best practice narrative | Brief / QA talking points |
| **Recommended Design Requirements** | Enhanced standards | Client upgrade; elderly / BEAM / quality tenders |

**SD takeaway:** Do not mark Recommended items as “statutory” on drawings unless the project has elevated them. Do mark every Obligatory item that affects cores, lobby, toilets, parking, and tactile paths.

### 2. Design-critical definitions (Chapter 3) — get these right before measuring

| Term | Meaning that drives SD |
|---|---|
| **Access** | Approach, enter, leave, and use facilities **without assistance or undue difficulty** |
| **Accessible** | Barrier-free and complies with this Manual |
| **Accessible lift** | Lift **fully** complying with Division 19 Obligatory requirements |
| **Accessible route** | Continuous, unobstructed, easily identifiable path for PWD / elderly |
| **Common areas** | Open to and for common use/enjoyment of **all** occupiers |
| **Door** | Includes **one leaf** of a pair of double doors |
| **Persons with a disability** | Impaired in vision, hearing or locomotion (ambulant, wheelchair, visual, blind, hearing, deaf) |
| **Persons with ambulant disabilities** | May need prosthesis, orthosis, stick or crutch |
| **Required staircase** | Access stair in FRS **or** MOE-required stair |
| **Tactile guide path** | Directional + positional + hazard-warning tiles combined for wayfinding |
| **Tactile warning strip** | Hazard-warning tiles only (stair/ramp/kerb/escalator ends) |
| **Luminous contrast** | `[(B1−B2)/B1] × 100` where B1 = lighter LRV, B2 = darker LRV |
| **Unjustifiable hardship** | DDO Cap. 487 s.4 factors (accommodation reasonableness, benefit/detriment, disability effect, financial/expenditure) — BA may weigh under DDO s.84 |

### 6. Continuous accessible route (Division 4) — the primary spine

#### 6.1 Obligatory

| Item | Rule |
|---|---|
| Start / end | From a **prominent lot-boundary point** connected to public street / pedestrian way → **commonly used public entrance** → **accessible lift** |
| Min clear width | **≥ 1050 mm** |
| Free of barriers | No protrusion hazards, steps, kerbs (other than dropped kerbs), steep ramps, or doors that impede wheelchair passage |
| Surface | Firm |
| Main entrance not accessible | Acceptable only for difficult terrain / steep driveway **if** PWD can arrive by vehicle **and** conspicuous directional signs show the accessible entrance and route |

#### 6.2 Tactile guide path tiles (Figs 6A–6C)

| Tile type | Pattern | Use |
|---|---|---|
| **Directional** | Parallel raised bars | Safe intended path |
| **Hazard warning** | Large dots ~**35 mm** Ø, square grid | Stair/ramp ends, dropped kerb; forms tactile warning strips |
| **Positional** | Small dots ~**23 mm** Ø, staggered | Change of walking direction / junction |

#### 6.3 Recommended (not obligatory)

| Item | Recommendation |
|---|---|
| Clear width | ≥ **1500 mm** |
| Large open floor >200 m² without wall/handrail cues | Add tactile guide paths for orientation |
| Slip resistance | Firm + “Good” static coefficient of friction (Appendix C) |
| Clearance from directional tiles to obstruction | 1050–&lt;1200 route → **350 mm**; 1200–&lt;1350 → **450**; 1350–&lt;1500 → **500**; ≥1500 → **600** |

**SD takeaway:** Principal entrance should **be** the accessible entrance. A remote “disabled entrance” is a last resort for terrain, not a default.

### 7. Level changes — ramps, dropped kerbs, stairs, handrails

#### 7.1 Ramps (Division 5) — Obligatory

| Item | Rule |
|---|---|
| Clear width | ≥ **1050 mm** |
| Head / foot landing | ≥ **1500 × 1500 mm** clear — **door swings must not** eat the landing |
| Max gradient | **1:12** generally |
| Minor-rise exceptions (**not combinable**) | **1:10** → max length 1500 / rise 150 mm; **1:8** → max length 600 / rise 75 mm |
| If gradient ≥ **1:20** | Intermediate landing ≥**1200 mm** long every **10 m** horizontal run; handrails both sides (Div. 8); tactile warning at head, foot, landings |
| Short / lift ramps | Landing / handrail / tactile rules **do not apply** if length **&lt; 300 mm** or ramp access to lift |
| Edge protection | Kerb ≥**100 mm** **or** rail **200 mm** above ramp, both sides |
| Projections | Fixtures ≤**90 mm** from wall below **2000 mm**, else extend to floor or guide by tactile flooring |
| Colour | Floor and wall along ramp in contrasting colours |
| Toward vehicles | Rise &gt;200 mm → railing/barrier across full width ≥**1500 mm** from foot of ramp |
| Traction strips | Raised traction strips **avoided** |

#### 7.2 Ramps — Recommended

| Item | Recommendation |
|---|---|
| Preferred slope | **1:20–1:15** (less fatigue / tip risk) |
| Slope / length / rise table | 1:20 → 10 000 / 500; 1:16 → 6400 / 400; 1:14 → 4200 / 300; 1:12 → 1800 / 150 |
| Width | ≥1200 (turn); ≥1500 (two chairs pass) |
| Slip | “Very Good” friction grading |
| Tactile luminous contrast | ≥ **70%** vs adjoining surfaces |
| Floor/wall contrast | ≥ **30%** |
| Avoid | Curved ramps; significant crossfall; long multi-flight ramps where a lift is better |

#### 7.3 Dropped kerbs (Division 6) — Obligatory

| Item | Rule |
|---|---|
| Where | Pedestrian crossings; each end of footpath of private street / access road; kerb separating footpath/ramp from vehicles |
| Size | ≥ **1200 × 1200 mm**; ≥ **800 mm** clear at back of footway |
| Gradient | ≤ **1:10** |
| Level to vehicular area | ≤ **15 mm** |
| Tactile | Warning strip **300 mm** from vehicles + **600 mm** nominal width at the ramp |
| Location | Unobstructed view of approaching traffic |
| Traction | Raised traction strips avoided |

**Recommended:** “Very Good” slip; tactile ≥70% luminous contrast; pair with visible/audible/tactile crossing devices where traffic lights exist.

#### 7.4 Steps & staircases (Division 7) — required stairs + main common circulation stairs only

| Item | Obligatory |
|---|---|
| Tread / riser (internal) | Tread ≥**225 mm** (centre of flight); riser ≤**175 mm** |
| Nosing | Vertical or ≤**15 mm** receding face; **no projecting nosing** |
| Flight | ≤ **16** risers without landing |
| Handrails | Both sides (Div. 8) |
| Nosing finish | Non-slip, contrasting colour |
| External stairs | Riser ≤**160 mm**; tread ≥**280 mm** |
| Colour | Treads and walls in contrasting colours |
| Tactile warning | Top, bottom, **and landings** — **300 mm** if landing enclosed by wall/rail/balustrade; **600 mm** if leading to open space / building exit (+ Braille/tactile info on adjacent wall for the opening). Intermediate steps between flights follow Fig. 13 |
| Projections | ≤90 mm below 2000 mm above treads, else extend to tread level |

**Recommended:** heavy-circulation / external → riser ≤150 / tread ≥300; flight height ≤1800 mm or ≤12 risers; top nosing ≥300 mm from returning wall; avoid winders, spirals, splayed steps, open risers; nosing & tread luminous contrast ≥30%.

#### 7.5 Handrails (Division 8) — Obligatory

| Item | Rule |
|---|---|
| Height | Top of rail **850–950 mm** above nosing / floor / landing |
| Clear of wall | **30–50 mm**; **70 mm** clear height from top of bracket to top of rail |
| Profile | Tubular **Ø 32–50 mm**, or equivalent grip (Fig. 16AA) |
| Extensions | ≥ **300 mm** horizontal beyond first/last nosing or ramp ends; closed return to wall/post; ≥**100 mm** allowed if door opening conflicts |
| Loading | ≥ **1.3 kN** vertical or horizontal; no rotation in fittings |
| Braille on stair handrails | Directional arrow + floor number on every floor (Figs 16A / 13); where directional sign exists on handrail, Braille/tactile also required |

**Recommended:** rough wall → ≥45 mm clear; recess ≥450 mm above rail top; second lower rail **700–800 mm** for schools & places of public entertainment; ≥30% luminous contrast; slip-resistant finish (e.g. hairline SS); exit-landing Braille “exit” (Fig. 16C).

### 8. Corridors, lobbies, paths (Division 9)

#### 8.1 Obligatory manoeuvring

| Item | Rule |
|---|---|
| Clear width | ≥ **1050 mm** |
| Dead-end turning | ≥ **1500 × 1500 mm** within **3500 mm** of every dead end (“dead end” = exit for PWD in **one direction only**) |
| Corridor lobby length | ≥ **1200 mm** excl. door swings |
| Building entrance | Level area ≥ **1200 mm** beyond door swings **and** ≥ **1500 mm** wide on **both** sides |
| Stair-only lobby | ¶31 does **not** apply |
| Channel covers | Flush; holes ≤ **20 mm** |
| Gratings | Slot ≤ **13 mm**; slots **not parallel** to travel |
| Projections | ≤90 mm below 2000 mm AFL, else to floor or tactile guide |
| Controlled passages / turnstiles / cashier / security | ≥1 path ≥ **800 mm** with accessibility symbol (or adjacent alternative) |
| Headroom ≤2000 mm | Warning guardrail / barrier with leading edge ≤ **680 mm** AFL |

#### 8.2 Recommended

| Item | Recommendation |
|---|---|
| Path width | &gt;1200 (pass one); ≥1500 (two chairs) |
| Sites ≥1000 m² — hospital, clinic, welfare, transport, school, shopping | Public routes / corridors / lobbies / paths ≥ **1500 mm**; inside corners at right-angle turns splayed/rounded ≥**300 mm** radius |
| Slip | “Good” friction; no loose gravel/stone |
| Luminous contrast | ≥30% between wall, floor, door |
| Resting | Seats / fold-down / lean-rails recessed every **≤50 m** in long transport corridors and public passages connecting to transport |
| Round edges | On controlled-passage counters and low-headroom guards |

### 9. Doors on accessible routes (Division 10)

#### 9.1 Obligatory

| Item | Rule |
|---|---|
| Clear opening | ≥ **800 mm** (incl. one leaf of a pair) |
| Latch-side clear (leading face) | ≥ **330 mm** unobstructed beside handle |
| Corner rule | If door &lt;330 mm from room corner → swing from the side nearer that corner |
| Double-action self-closing | Check mechanism to prevent swing beyond closed; vision panel bottom ≤**1000 mm**, top ≥**1500 mm** AFL |
| Handle height | Top of grip **950–1050 mm** AFL |
| Threshold | ≤ **20 mm**, bevelled |
| Opening force | Exterior ≤ **30 N**; interior ≤ **22 N**; FRR doors on accessible routes ≤ **30 N** |
| Interior closer timing | ≥ **3 s** from 70° open to 75 mm from closed (leading edge) |
| Frameless glass | Prominent marking with portion between **900–1500 mm** AFL; same for adjacent glass panels |
| **Automatic main entrance door — mandatory** for | Sports stadium, town hall, civic centre, theatre, museum, public library, shopping complex, sports complex, public swimming pool complex, **office building**, **hotel**, **hospital** — at one commonly used main entrance |

#### 9.2 Recommended

| Item | Recommendation |
|---|---|
| Clear width | ≥ **850 mm** |
| Latch approach | ≥ **600 mm** |
| Kick-plate | ≥ **200 mm** high on swing-away face |
| Auto doors (non-domestic, all public entrances) | Remain open ≥**5 s**; guardrail if swings into travel route; “automatic door” sign; controls outside swing; prefer sliding + overhead sensor or large button |
| Glass marking | Horizontal band ≥100 mm high, ≥**10%** of glazing in 900–1500 zone; **or** other horizontal marking ≥**30%** of that zone |
| Handle / power-button contrast | ≥30% |
| Fire doors to accessible areas | Hold-open **except** required stair + protected lobby doors; non-FR doors to accessible areas → automatic |
| Threshold detail | Bevelled + round edges, gradient ≤ **1:2** |
| External doors | Prefer single-action outward (wind closer force) |
| Latched doors | Lever handles |

#### 17.1 Car & door — Obligatory (if any passenger lift exists)

| Rule | Requirement |
|---|---|
| Coverage | **Every floor** by ≥1 lift fully complying with Div. 19, with **direct access to main lift lobby** |
| Other passenger lifts | Must still meet ¶79 (doors) & ¶80 (buttons) |
| Min car | **1200 × 1100 mm**; clear entrance ≥ **850 mm** |
| Handrails | Extend to within **150 mm** of rear & side corners; top of grip **850–950 mm**; wall gap **30–50 mm** |
| If **&gt;3 lifts** in building | ≥1 car **1500 × 1400 mm** (either orientation), door ≥850 mm |
| Doors | Horizontal sliding, power, auto; audible close signal; obstacle re-open detector at **500–600 mm** AFL |
| Buttons (car & hall) | **900–1200 mm** AFL; min size **20 mm**; Braille/tactile on or left of buttons; tactile numerals ≥**15 mm**, raised ≥**1 mm**; main entrance floor = **star**; alarm = **bell** shape |
| Emergency | Alarm with acknowledgement light + intercom to management/caretaker; powered by emergency electricity supply; EN/中 notice by blinking light |

#### 17.2 Indication — Obligatory

| Item | Rule |
|---|---|
| Landing | Illuminated visual + audible (1× UP / 2× DOWN) before arrival (or audible from car if heard in lobby) |
| Jamb designations | Arabic ≥**60 mm**, raised 1 mm, both jambs @ **1200 mm** AFL |
| In-car | Visual direction + position (chars ≥**50 mm**); audio stop floor in **English, Cantonese, Putonghua** |
| Lobby symbol | If only some lifts comply → identify each compliant lift at each landing; if all comply (or only one lift) → ≥1 accessibility symbol at each entrance-level lift lobby |

#### 17.3 Recommended lift enhancements

| Item | Recommendation |
|---|---|
| Tactile warning | In front of accessible lift door at each landing |
| Priority call | Separate call button for accessible lift with priority attendance |
| Destination Control System | Keypad with raised-dot “5”, Braille notice, wheelchair button, star for main floor, speech EN/粵/普, buttons 900–1200 AFL, extended door-open time, tactile guide path to keypad then to designated lift (EN 81-70 reference) |
| Voice level | &gt;10 dB and ≤80 dB above ambient; 300–3000 Hz |
| Video call | Monitor for hearing-impaired emergency communication |

**Illumination note (related):** threshold, landing sill, lift landing recommended **150 lux** min in best-practice text.

### 19. Building services (Chapter 5)

#### 19.1 Switches & controls (§5.1) — Best Practice

| Item | Recommendation |
|---|---|
| Reach band (except Div. 19 lifts) | Controls **450–1200 mm** AFL |
| Sockets | ≥ **450 mm** AFL |
| Contrast | ≥30% vs background |
| Operation | No tight grasp/twist; visible from seated position; avoid tiny buttons; one-hand operation |

#### 19.2 Fire alarm visual signals (§5.2) — Obligatory where Table 2 = Y

| Item | Rule |
|---|---|
| Form | Flashing **red** light labelled “Fire Alarm / 火警” (plate or engraved) |
| Location | Prominent, readily noticeable in Table 2 uses |
| **Not required** | Exit staircases under FS Code + adjoining smoke lobbies; domestic unit interiors; staff-only / back-of-house areas listed per use in §5.2.3(b) (offices, plant, kitchens, projector rooms, etc.) |
| Lone worker | Visual alarm also where hearing-impaired person works alone (best-practice note) |

#### 19.3 Public telephones (§5.3) — Recommended

In any group of ≥2 payphones, provide at least one of each type as applicable:

| User | Key requirements |
|---|---|
| Wheelchair / ambulant | Obstacle-free approach; no stepped base (or Div. 5 ramp); cord ≥**750 mm**; operable parts / coin slot ≤**1200 mm** AFL; clear floor ≥**750 × 1200 mm**; enclosure rules for parallel (sides ≤250 mm forward) or forward approach (clear ≥800, footplate 750×650×430); booth door outswing clear ≥800 **or** doorless entry ≥800; grab rails both sides **or** ≥900 clear for crutches; fold-down seat |
| Visual impairment | Mechanical keypad with **digit-5** indicator; pickup activates recorded operating instructions; phone cards with left-bottom notch |
| Hearing impairment | Amplifying handset or inductive coupler + hearing-loss symbol |
| Speech impairment | Capable of handling written messages |

#### 19.4 Remote signage / talking signs (§5.4) — Best Practice

Voice message to users with proper receivers — consider for complex public buildings with heavy visual-impairment footfall.

#### 19.5 Vertical lifting platforms (§5.5) — Recommended alternative only

Use only where passenger lift / ramp is impractical. Target: door clear ≥**900 mm**; platform ≥ **1100 × 1500 mm**; barriers ≥**1100 mm**; buttons per Div. 19; hold-to-run ≥50 mm; common key self-operation; call + CCTV/intercom to caretaker/counter; auto-home on power failure; grabs @ 900 AFL; max travel **7000 mm**; load ≤**500 kg**; rated-load sign. **Prefer designing out at SD.**

#### 19.6 Drinking fountains (§5.6) — Recommended

If fountains provided, ≥1 per floor complying: spout opening **750–900 mm** AFL near front; water trajectory parallel to front; flow ≥100 mm high; lever/fist or auto control ≤22 N, control ≥50 mm; clear floor ≥**800 × 1200**; knee ≥800×200×680; toe ≥800×230×230; wall-mounted units in alcove or with wall guard.

### 20. Elderly-friendly design guidelines (Chapter 6) — not Third Schedule

Encouraged guidelines in four groups: **Mobility & Accessibility**, **Design Adaptability**, **Well-being**, **Gerontechnology**. Adopt for elderly / welfare / aging-in-place briefs.

#### 20.1 Mobility highlights (A1–A17 range)

| Topic | Key recommendations |
|---|---|
| Residential bathroom | ≥**1200 mm** Ø turn; grab bars |
| Doors (units) | Clear ≥**850 mm**; prefer sliding / folding / double-swing |
| Bath / shower | Built-in or secure portable bath seat; shower ≥**1500 × 900** + folding seat + grabs |
| Floors | Slip-resistant; avoid shiny marble/glazed; avoid rough open-joint external pavers |
| Fittings | Double-switching; bedside switches; lever handles/faucets (no knobs / spring self-close); no high cupboards; avoid projecting drying racks |
| Common corridors | Level where possible; handrails along corridors; luminous contrast at level changes |
| Elderly handrail height | Top **810–900 mm**; timber or plastic-coated for grip |
| Door forces (elderly) | External ≤**28 N**; internal ≤**18 N** |
| Larger lifts | Clear depth ≥ **1.5 m**; folding seats / lean rails (except fireman’s lifts); lobby buttons @ **1050 mm**; back-lit car buttons; audio orientation |
| Escalators | Slower speed |
| Illumination | Common areas ≥**120 lux** emphasised |

#### 20.2 Adaptability / well-being / gerontechnology

Sample themes in Manual: lower eye viewers; adaptive room layouts; lower window cills; elderly toilet layouts; knee space under community-farming planters; colour sensitivity (elderly less sensitive to short wavelengths — use luminous contrast carefully); emergency call buttons reachable from floor.

**SD takeaway:** Treat Chapter 6 as a **brief checklist**, not statutory. Escalate selected items into Employer’s Requirements when the client is HA / elderly home / age-friendly residential.

### 22. Schematic design hold-points (before freezing cores / lobby / parking)

1. **Table 1 extent** + full **Table 2** assistive package by use (tactile path? Braille plan? counter? visual alarm? ALS?).
2. **One continuous accessible route:** street → entrance → lift → every floor → accessible unisex toilet → principal public destinations.
3. **Level strategy:** thresholds ≤20 mm (doors) / ≤13 mm (roll-in showers); if ramping, reserve **1500 × 1500** landings and stay ≤ **1:12** (no stacked 1:8/1:10 tricks).
4. **Lift bank:** min **1200 × 1100 / 850 door**; if &gt;3 lifts lock one **1500 × 1400**; every floor served; main lobby direct access.
5. **Toilet:** ≥1 unisex accessible per toilet floor; envelope ≥ **1500 × 1750** with **1500** turn @ 350 AFL; emergency call + grabs.
6. **Typology counts:** auditorium wheelchair spaces; hotel accessible rooms (+ recommended visual/Braille rooms); carpark bays **3500** or paired **2500+1200**.
7. **Auto door** at commonly used main entrance for listed public/commercial types (office, hotel, hospital, shopping, cultural, sports, library, etc.).
8. **Escalators ≠ BFA** — always parallel accessible lift/ramp + tactile at escalator ends.
9. **Do not BFA-budget** §2.2.2 exempt zones; **do** BFA pool decks, changing, and routes to them.
10. **Elderly brief?** Pull Chapter 6 items into ER early (850 doors, corridor handrails, larger lift cars, slip finishes).

### 23. Common SD failure modes

| Failure | Fix |
|---|---|
| Separate “disabled entrance” as default | Make principal entrance accessible |
| Tactile path only in lobby token strip | Continuous from lot boundary to lift / toilet / counter / Braille plan / stair |
| Ramp landings eaten by door swings | Keep 1500×1500 clear of swings |
| Combining 1:8 + 1:10 minor rises | Forbidden — redesign to ≤1:12 or lift |
| Accessible bay at 3300 mm | Manual requires **3500** (or 2500+1200 shared) |
| Lift car 1100×1400 assumed OK | Obligatory minimum is **1200×1100**; large car **1500×1400** if &gt;3 lifts |
| Escalator as accessible route | Not accepted — provide lift/ramp |
| Accessible toilet only inside sex toilet without unisex | Still need **unisex** accessible facility on that floor |
| Visual fire alarm in exit stairs | Not required / excluded — put in occupied accessible areas per Table 2 |
| Marking Recommended as statutory | Keep layers clear on drawings and Form BA |
