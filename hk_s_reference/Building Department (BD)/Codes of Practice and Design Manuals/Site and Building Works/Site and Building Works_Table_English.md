# Site and Building Works Index (English)

**Issued by:** Buildings Department
**Scope:** The September 2016 and October 2023 amendment sheets to the Code of Practice for Demolition of Buildings 2004 (2 documents). The 2004 code summary sits beside `source_reference/` and is not repeated here. This library was not checked against the live departmental website.
**How to use:** The date links to the critical summary in `summaries/`. The PDF link opens the file in `source_reference/`.
**Titles:** The official title is the summary heading.
**Caveat:** Desk reference only. Before a demolition submission, check the 2004 code and both amendment sheets.
