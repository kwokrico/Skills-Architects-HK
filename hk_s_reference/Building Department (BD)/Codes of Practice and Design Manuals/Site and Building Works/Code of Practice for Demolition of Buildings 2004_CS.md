# Code of Practice for Demolition of Buildings 2004
**Architect critical summary for schematic design**  
First issue 2004 | Amendments Sept 2016 & Oct 2023 | Buildings Department

> Scope note: Guidance for planning and executing demolition under the Buildings Ordinance, Building (Administration) Regulations and Building (Demolition Works) Regulations. Read with **PNAP APP-21** (demolition / video), APP-71 / PNRC-6 (public safety), APP-75 / PNRC-4 (hoardings & walkways), APP-175 (antiquities), CoP Site Supervision / TMSS, MWCS Technical Guidelines (Type G), and EPD/LD ordinances for asbestos, noise, dust and waste. Does **not** cover MWCS Type G demolition as a substitute for those guidelines, nor major civil works (underpinning, excavation, highway/railway bridges, dams). Where slopes / retaining / geotech content exists, involve **RGE** (2016 amendment). Other methods may be used if AP / RSE / **RGE** / RSC (Demolition) substantiate them with engineering assessment.

---

## Regulatory Overview

This Code applies to demolition of **buildings and common structures** in Hong Kong — including individual structures, **partial demolition**, basements, underground tanks, and civil-type structures such as silos, industrial plants and piers — where a Demolition Plan and Stability Report are prepared for Building Authority approval.

At schematic design for redevelopment or major A&A involving strip-out, lock **setback vs building height** (hoarding / covered walkway / catch platform), **party-wall / cantilever-over-street** strategy, **plant-on-slab vs ground-based methods**, **utilities / asbestos / contamination lead-in**, and whether the existing building contains **complex structures** (prestress, transfer, long span > 10 m, hanging, earth-retaining) — these drive programme, RSC (Demolition) appointment, resident site engineer, street occupation, and the new scheme’s abutment / foundation sequence before massing is frozen.

## Critical main topics and subtopics

### 1. Pre-demolition appraisal — Building Survey (§2.1.1)

Retrieve record layout plans of the building **and** adjoining properties, walkways, roads. If records are missing → on-site survey ± material testing (2016).

| Survey item | What to lock at SD |
|---|---|
| Age of building; construction materials; dilapidation of façades / projections **facing or over streets** (2016) | Street-protection level; cut-and-lift vs break-in-place |
| Existing + past uses | Contamination / DG / asbestos likelihood |
| Hazardous materials; wastewater; toxic / flammable / explosive / radioactive; air-pollution & soil-contamination sources | Specialist removal **before** structural demo; programme lead time |
| Dangerous layouts: enclosed voids, **non-ventilated light wells** that can trap gas | Confined-space regime; chute strategy |
| Adjoining conditions: slopes, RW, walls supporting ground, illegal structures, bridges, **MTR** (entrances, vents, substations, plantrooms, overhead structures, surface track), overhead cables / guy wires, utility connections | Method vetoes; RGE / MTR liaison |
| Drainage / flooding / erosion risk (esp. sloping sites, water-receiving bodies) | Temp drainage; post-demo sealing |
| Shared facilities: common stairs, party walls; self-enclosed walls to neighbours | Access continuity for adjoining occupied buildings |
| Hoarding / covered walkway need | Street occupation width |
| Pedestrian + vehicular traffic | TIA trigger |
| Headroom, clear spaces, lot-boundary setback for debris loading / haul | Truck gate; GF early-removal for logistics |
| Neighbourhood sensitivity: noise, dust, vibration, traffic; EIAO Schedule 2 designated project? | Method choice (crusher vs breaker vs saw); EIA |
| Space for **on-site sorting** of debris | Selective demolition / recycling |
| Street furniture: hydrants, meters, lights, signs, hawker stalls | Temporary diversion / protection |

**Hazardous materials (§2.1.1(C) + §2.3):** Unless survey shows no obvious hazard → AP causes sampling & testing. Asbestos / petroleum → remove per EPD / FSD / LD. Former chemical / DG storage → soil contamination assessment pre- and/or post-demolition. Former explosives storage → special clearance that nothing remains.

### 2. Structural Survey (§2.1.2)

Study record layout, framing, and details. RSE must watch unusual detailing that fails mid-demolition (e.g. **upward anchorage of tensile reinforcement in cantilevers**).

| Survey item | SD implication |
|---|---|
| Age + structural materials (2016) | LCC-era slabs → Table 3.4 props may overstress without spreaders |
| Original structural system & construction method | Reverse-order sequencing |
| Dilapidation / deterioration of members | Pre-strengthen before plant / traffic |
| Adjoining structures + their shoring | Interface props |
| Continuous structures that will be **truncated** | Temporary continuity / bracing |
| Basements, underground tanks, vaults | Uplift, ELS, new-foundation integration (§5.9) |
| Exposed or covered bracing | Lateral stability during strip |
| Wall nature: block / RC / loadbearing / partition / **screen / retaining** (2016) | What can come down early |
| Cantilevers: canopies, balconies, architectural features | Street platforms or cut-and-lift |
| Fixtures: signboards, sun-shades | Strip sequence |

**Special-structure review (§2.1.2(C)):** Confirm structural info; flag unconventional elements needing defined modification procedures; check whether temporary structural mods can enable demolition traffic; note limits on shoring.

**No structural drawings:** Measure on site, retrieve framing as far as practicable, test / expose key members so stability can be proven at every stage.

| Category | Examples |
|---|---|

| Special skins / steel | Stressed-skin; steel framed structures |

### 4. Demolition Plan + Stability Report (§2.1.3 + B(A)R 8(3)–(4))

#### 4.1 Demolition Plan — minimum content

| Drawing / note set | Must include |
|---|---|
| Site plan | Building location; topography / contours / slope sections where building supports ground; ground removal / backfilling; distances to adjacent buildings, streets, structures, significant street furniture |
| All-floor layouts + sections | Occupancy; structural support systems; principal materials; condition / deterioration; relationship to neighbours (adjoining buildings, UBW, shared stairs, party walls, truncated continuous frames, slopes, RW, overhead cables, guy wires, underground utilities) |
| Unconventional structures | Full arrangement of §2.1.3(A)(3) elements |
| Procedure plan | Detailed sequence for particular members; method; **restrictions** on equipment types |
| Mechanical plant plan (if used) | Plant movement routes; method of lifting plant onto top floors; structural alterations (e.g. early GF / cockloft removal for vehicles); temporary strengthening of deteriorated key members; shoring / floor propping |
| Public protection plan | Hoardings, covered walkways, catch platforms, catchfans, scaffolding, protective screens, safety nets |
| Adjoining protection | Shoring / precautions for affected buildings, slopes, RW, services **at each stage** |
| Temporary support to building being demolished | Props, bracing, platforms |
| Debris & waste system | (a) permissible temporary accumulation upper floors + GF; (b) handling method; (c) routing each floor → on-grade holding; (d) off-site transport; (e) time / frequency; (f) trip-ticket records (tonnage, plate, driver, dump site); (g) responsible supervisory personnel; (h) temporary parking for machines / trucks if needed |

#### 4.2 Stability Report — six mandatory parts

1. Stability of the building **at all stages** of demolition  
2. If powered plant used: prove plant will not make inadequate the margin of safety of, or damage, any building / structure / street / land / services  
3. If powered plant used: calculations for **all** temporary supports and bracings  
4. Stability of neighbouring buildings, adjoining properties (§2.1.1(B)(5)), party walls, streets, land, services  
5. If temporary / permanent supports needed to those parties → structural calculations  
6. Overall demonstration that demolition will not render inadequate the margin of safety of, or damage, any building / structure / street / land / services  

Checklist: Appendix B. Worked examples: Appendix F (manual), Appendix G (machines). Procedure flowchart: Appendix H.

|---|---|

### 7. Clear space vs building height — hoarding / walkway / catch platform (§3.2)

**Clear space** = distance from building line to lot boundary. **Building height** = topmost part being demolished to lowest ground level.

| Condition | Required protection |
|---|---|
| Clear space ≥ building height | **Hoarding only** |
| Clear space < building height | **Covered walkway** |
| Clear space < **½** building height | Covered walkway **+ catch platform** |
| Building height < **4 m** | Catch platform **not** required |
| Along public access | Hoarding / walkway for **full** site boundary length |

| Dimension / load | Rule |
|---|---|
| Walkway headroom | ≥ **2.3 m** clear |
| Walkway on carriageway | ≥ **1.1 m** clear width (no obstruction by signs, props, scaffolds) |
| Walkway on footpath (Table 3.1) | Pavement ≤ 2.5 m → normally **1.5 m** min (exemption if pavement too narrow); 2.5–3 m → pavement − 0.8 m (max **2 m**); > 3 m → **2 m** |
| Catch platform width | ≥ **2 m** abutting street (reducible by building setback) |
| Catch platform over carriageway | ≥ **5.5 m** clearance within ≥ **500 mm** of carriageway edge (HyD may vary); gantry headroom **5.5 m** preferred |
| Covered walkway UDL | **5 kPa** |
| Catch platform | **5 kPa** UDL **or** **20 kN** on **300 × 300 mm** (worse case) + wind per Wind Code |
| Outer edge | Upstand ≥ **1.1 m** from toe of outer roof line; roof pitched **inwards** for containment + drainage |
| Lighting | Average **35–50 lux**; weather-proof (typical: 18–20 W 600 mm fluorescent @ 3 m centres) |
| Use restriction | **No** debris or materials storage on / in walkway; contractor shed over walkway must be **structurally independent** and designed to catch-platform / walkway loads as applicable |
| Construction preference | Prefabricated bolt-up; minimise site welding over public realm |

**SD takeaway:** Most urban lots need walkway + catch platform — reserve pavement / carriageway occupation early; coordinate with APP-75 / PNRC-4.

### 8. Scaffold, screens, catchfans (§3.3–3.4)

| Item | Critical rule |
|---|---|
| Scaffold type | Bamboo or metal OK if per LD scaffold CoPs + Construction Sites (Safety) Regs; elevated supports / brackets designed by **RSE** |
| Work platforms | Three consecutive lifts directly **below** floor being demolished; toe boards at outer edge; clear debris regularly |
| Bamboo ties / struts (2016) | ≤ **4 m** centres H & V; secure **cantilever above topmost floor / floor being demolished**; if scaffold > **15 m** → steel brackets / supports ≤ **15 m** centres; follow BD Bamboo Scaffold Guidelines |
| Metal scaffold | Design for live load on **three** consecutive work platforms + self-weight; ties per manufacturer |
| Unbraced after ties cut | ≤ **2 m** above nearest anchor; dismantle in step with demolition |
| Screens | **Two** layers: tarpaulin **over** heavy-duty net; ties ≤ **2 m** or net width; overlap ≥ **300 mm**; must satisfy Air Pollution Control (Construction Dust) Reg |
| Polyethylene net (Table 3.3) | Ø 1 mm, 16 ply, **20 mm** mesh, ≥ **130 g/m²**; UV resistant; secured so debris is retained, not deflected to ground |
| Tarpaulin | Fire-retardant: BS 5867 Class B, Japanese FR canvas standard, or equivalent |
| Catchfan purpose | Catch **small** debris that passes screens — **not** for large pieces or structural support |
| Catchfan spacing | ≤ **10 m** below working floor |
| Catchfan geometry | Project **1.5 m** beyond scaffold face; incline **20°–45°** |
| Bamboo catchfan | Supports Ø ≥ **40 mm**, spacing ≤ scaffold standard spacing or **1.3 m**; anchors ≤ **3 m**; deck bamboo Ø ≥ 40 mm @ ≤ **200 mm** centres; tarpaulin + net + **0.5 mm** metal sheet on top |
| Steel catchfan | Prefer bolt-up prefab; avoid expansive anchors as **primary** support (vibration loosens them); metal catchfans only on metal scaffolds |

### 9. Temporary supports & plant on suspended floors (§3.5 + Table 3.4)

**Props mandatory when:** excess demolition / plant / debris load; members not self-supporting; stability impaired by sequence. Do not remove props until their loads are gone. Remaining temporary works after shutdown → Owner / AP / RSE / RSC responsible for inspection until removed.

#### 9.1 Cantilevers over public realm (§3.5.1(B) + Oct 2023)

| Trigger | Requirement |
|---|---|
| External cantilever facing public street, **> 4 m** above ground, setback **< ½ building height** | Temporary platforms under the feature for demolition + construction loads — **unless** cut-and-lift (or similar) |
| Any cantilever | Do **not** remove anchorage / holding-down before the cantilever is demolished or temporarily supported |

#### 9.2 Catch platforms under features (§3.5.1(C))

Also under projected canopies / balconies / architectural features / prestressed elements where the area below needs protection — install **before** demolition starts; design for anticipated demolition loads.

#### 9.3 Adjoining & incomplete projects (§3.5.1(D)–(E))

- Prop adjoining buildings, utilities, slopes, RW, land if removal affects stability  
- Protect truncated continuous beams, exposed party walls, common stairs; maintain safe ingress/egress for neighbours  
- Tenement / shared-structure cases: brace remaining integral structure  
- Prolonged shutdown: stabilise remaining structure with temporary support / bracing

#### 9.4 Design & erection rules (§3.5.3–3.5.6)

| Rule | Detail |
|---|---|
| Foundation of props | Adequate foundations / floors; if floor below inadequate, carry shores down until capacity OK; align props vertically floor-to-floor (avoid punching / reverse bending); avoid differential settlement foundations; check concentrated loads — use sleepers / base plates |
| Materials | Structural steel, heavy timber, fill embankment / buttress, or appropriate equivalent; pre-manufactured systems only to manufacturer capacity |
| Ramp (Table 3.4 basis) | Structural steel access ramp; gradient ≤ **30°** (machine descent ramp in §4.3.1(C): ≤ **1.75:1** or manufacturer) |
| Prop capacity | ≥ **25 kN** under plant; ≥ **45 kN** under ramp |
| Bracing (2016) | Lateral restraint ≥ **2** directions; **cross bracing at perimeter & end bays** |
| Spacing | Max **1.2 m** each way (Table 3.4) |
| Not applicable | Special / unconventional layouts in §2.1.3(A)(3) — full engineering required |
| Debris | Generally **not** permitted on floors without calculation; if allowed, include in prop design |
| Old LCC buildings (2016) | Lower permissible stresses — substantiate alternate props; distribute via sleepers / plates |

#### 9.5 Table 3.4 — mechanical plant on suspended floors

| Design floor imposed load | Max plant weight | Min consecutive floors to prop (plant) | Min floors for temporary ramp load |
|---|---|---|---|
| 3 kPa | 11,600 kg | 5 | 5 |
| 5 kPa | 11,600 kg | 3 | 4 |
| 7.5 kPa | 11,600 kg | 2 | 3 |
| 12.5 kPa | 11,600 kg | 2 | 2 |

**Oct 2023:** Table also covers **light-weight plant ≤ 5,800 kg** (reduced propping — use current BD amendment table).  
**2016:** Props differing from Table 3.4 need full RSE substantiation.

### 10. Party walls, adjoining property & foundations (§3.6)

| Rule | Detail |
|---|---|
| Party wall | **Remain and protect** during and after demolition; remove only if redundant |
| Work next to party / neighbour external wall | **Manual method**, extreme care |
| Timing | Waterproofing + structural treatment **floor-by-floor immediately** after that floor is demolished |
| Waterproofing coats | Clean; bonding agent; coat 1 ≥ **10 mm** cement:lime:sand **1:2:6**; coat 2 ≥ **10 mm** **1:3:6**; or temporary waterproofing paper (upper overlaps lower), securely fixed |
| Structural support | Timber raking shores or steel stiffeners with concrete cover / corrosion protection (RSE design); may leave stubs of common beams/slabs if stability allows |
| New building | Temporary support layout must suit **new construction**; permanent support continuity required; temporary treatment kept until permanent works |
| Basement / below-ground affecting neighbour foundations | Evaluate; shoring / underpinning as needed (§5.9) |

**SD takeaway:** Design the new abutment, waterproofing junction, and foundation sequence together with temporary party-wall support — do not leave it to post-demo improvisation.

### 11. Traffic, site access, safety & vibration (§3.7–3.8)

| Topic | Constraint |
|---|---|
| Lane / walkway closure | Avoid if practicable; else prior TD + Police; night work often preferred; exceptional daytime closure for canopies / balconies / verandahs only if no safe alternative |
| TIA | Required if closure proposed — to TD / Police standards |
| Site access | Headroom, sightline, segregation, loading/unloading, illumination for construction vehicles |
| Training | Demo workers / plant operators: job safety + on-job training (HKIC courses); induction on method, hazards, exits; regular safety meetings |
| Training topics | Working at height; confined spaces; lifting appliances; PPE; hot works; chemicals; health hazards; safe plant operating / manipulation zones |
| Equipment | Test & examine before use; daily inspection recorded |
| Electrical | Utility supply or mobile generator; FIU (Electricity) Regs |
| Fire | Remove flammables unless needed; proper storage; clear furniture/timber/doors before welding; maintain fire appliances |
| Occupational health | Dust, chemicals, heat/ventilation, noise, first aid, sanitation, occupational diseases |
| Emergency exit | ≥ **1** protected, lit, signed, unobstructed route at all times — also a lifeline for injured workers |
| Vibration guideline | PPV at adjoining structures ≤ **15 mm/s** for prolonged mechanical demolition; implosion needs dedicated method-statement assessment (ground distortion, settlement, fly rock, air blast) |
| Adjacent sites (Oct 2023 §3.8.8) | AP/RSE design precautions for interface with adjoining demo/construction; coordinate with other APs; review as circumstances change; amend plans to BD if needed; RSC coordinates with adjacent contractors |

### 13. Floor openings, free edges & debris (§3.10 + Oct 2023 §§3.8.9–3.8.10)

| Constraint | Limit / rule |
|---|---|
| No free fall | Debris must not be thrown / tipped from height where it can injure; exterior free-fall only inside a chute |
| Chute options | Existing lift shaft, light well, floor openings, or designed exterior chute |
| Lift shaft | Adequately enclose openings to prevent spill |
| Light well | Remove or protect all glass windows first |
| Created floor openings | Aggregate ≤ **25%** of floor area; each ≤ **900 × 900 mm** unless structurally justified for impact / remaining structure; do not cut critical supports |
| Opening covers (2023) | Solid, sufficient strength, securely fixed, boldly marked; or safety nets if cover impracticable (kept clear of debris) |
| Free-edge railings (2023) | Top **900–1150 mm**; mid **450–600 mm**; toe board **200 mm**; bright mesh top-to-toe; else LD fall-arrest system if rails/covers impracticable |
| Debris through openings (2023) | Only chute / full enclosure / shaft in **AP/RSE-accepted designated areas**; fence off; suspend overhead conveyance during removal below; warn at entries; chute must be strong, fully enclosed at entries, dust-tight, noise-mitigating |
| Exterior chutes | Adequate clear space; no obstruction to public; dust barrier if outlet near public; no old metal-barrel chutes |
| Debris on floors | No accumulation unless calculated; never against hoarding / external wall; include in prop design if allowed |
| Selective demolition | Strip non-structural recyclables first (furniture, appliances, metal windows/pipes, timber doors/floors, tiles, asphalt, ceramics); then structural demo; separate concrete from steel; break for recycling / public fill |
| Broken concrete | Prefer C&D recycling facilities; sort out from mixed waste on site; AP/RSE may consult CEDD at planning stage |
| Waste management (2023) | Dispose per Waste Disposal Ordinance; on-site sort inert → public fill, remainder → landfill; public fill = earth, building debris, broken rock, concrete — free of marine mud, refuse, plastic, metal, industrial/chemical waste, animal/veg matter (small timber may be allowed); RSC should submit waste management plan to AP/RSE before start |
| Debris loading at GF | Check truck/loader routes vs props; check headroom — design local strengthening if mezzanine / 1F beams removed early; load vehicles per TD Loading of Vehicles CoP |

### 14. Inspection, maintenance & post-demolition (§3.11–3.12)

| Item | Rule |
|---|---|
| AP / RSE / RSC inspection frequency | Not less than TMSS + CoP Site Supervision requirements |
| RSC daily | Clear catchfans / catch platforms; continuous full-time supervision; confirm unstable / partial structure safe each day before leaving |
| Deviation from method statement | Stop further demolition until rectified and AP/RSE issues written restart |
| Unsafe condition | Halt all demolition immediately; report to AP/RSE |
| Scaffold inspections | Before first use; after alteration; after adverse weather; ≤ **14 days** before each use; signed approved-form report |
| Post-demo | Level + clear + drain; enclose if new works delayed; finish party-wall weatherproofing & stabilisation; AP+RSE final inspection of adjoining supports; brace excavations |
| Sloping / RW sites | Seal ground against infiltration; stabilise unstable ground/structures; **hand demolition temporary-works drawings to subsequent foundation / site formation contractor** |

### 15. Method selection — SD decision matrix (§4 + Table 4.1)

General: demolish in **reverse order of construction** where appropriate. Busy urban default = **top-down**. Projections over streets → hand tools or **cut-and-lift**. Wrecking ball / explosives only with extreme care and adequate precautions.

| Method | Best when | Hard stops / key criteria |
|---|---|---|
| **Top-down manual** | Tight sites, localised work, near neighbours | Broad applicability; high noise; sequence in §16 |
| **Top-down machine** (breaker / hydraulic crusher) | Adequate propped floors; mobility | Floor capacity + Table 3.4; plant limits in §17 |
| **Hydraulic crusher, long boom** | Dangerous buildings, silos; quieter — use wherever practicable | Clear space ≥ **½ height** debris zone; debris platform ≤ **3 m**, side ≤ **1:1**, plan ≥ **1.5 ×** machine length; firm ground; pre-soak + continuous spray; 24-hr security; no workers in operating zone / inside building; spotter required |
| **Wrecking ball** | Dilapidated / industrial with large setbacks | Crane–building clear ≥ **50% height**; boundary–building ≥ **50% height + 6 m** on **all** sides; jib ≥ **3 m** above work; wire/boom ≥ **5×** ball; wire ≥ **2×** tensile of slab/beam rebar; swivel anti-spin; inspect wire/boom/pins **twice daily**; no slewing preferred; no overhead power lines; 24-hr security; fence impact-resistant; only operator + spotter in radius; proven operator + equivalent spotter |
| **Implosion** | Rare; Risk + Environmental assessments via BD central processing | Exclusion ≥ **2.5 ×** height; Mines authorisation; implosion + blasting experts; trench/bund for debris unless basement; prefer early Sunday/PH; non-electrical initiation + redundancy; **no nitroglycerine explosives**; geotech if slopes/RW; check tunnels/utilities/adjoining; 24-hr security from explosive install to blast |
| **External mechanical** (pusher arm / wire rope / clam shell) | Isolated buildings on flat ground only | Firm ground + counterweight; check collapse impact on floors / vibration / underground utilities; full-time security; nobody in working area or building during operation |
| **Saw / wire saw / stitch drill** | Precision A&A, sensitive neighbours; pile-cap openings for new bored piles | Cooling water supply + disposal; solid platform; lift-out plan; wire-break countermeasures |
| **Cut-and-lift** | Canopies, balconies, cladding, bay windows, projections | Check remaining stability; secure before cut; wire ≥ **4×** load; controlled lower — **no free fall** |
| **NEDA** | Restricted noise/vibration; foundations / pile caps / fully supported structures | Drill pattern + test breaks; control water/loading to avoid blow-out; secondary mechanical break; in rock contain in strong flexible impermeable bags |
| **Thermal lance / water jet** | Special materials / access | Intense heat / high-pressure water protection; fire damage / drainage + recycle water |

**Pollution quick read (Table 4.1):** Manual jack hammer = high noise, moderate dust; machine breaker = high noise/vibration/dust; hydraulic crusher = quieter, better steel separation; saw/wire = low vibration, needs drainage; implosion / external mechanical = high everything + debris protection.

Pulling wires (any method): strength ≥ **4×** anticipated pull; check ≥ twice daily; shield workers from wire snap-back.

### 16. Top-down manual — sequence architects must respect (§4.2)

| Step | Rule |
|---|---|
| Each floor | Demolish **all** cantilevered structures, canopies, verandahs, external features **before** main/internal structure |
| Roof | Lift machine rooms & water tanks top-down to main roof; parapets per exterior-wall rules |
| Slabs | Start at **mid-span**, work toward supporting beams |
| Beams | (1) cantilevered → (2) secondary → (3) main; prop if restraint lost |
| Walls | Non-loadbearing before loadbearing |
| Columns / loadbearing walls | After beams on top removed |
| GF option | 1F slab may be machine-demolished from ground if conditions allow |
| Brick infill | Push **inward** from outside platforms, top-down, layers ≤ **300 mm**, before RC frame dismantling |
| Exterior column (Oct 2023) | Tie **top and bottom** with wires/winches; pre-weaken base (expose rebar, cut exterior half immediately before pull); pull **inward** controlled |
| Reinforcements | Keep until connecting/supporting concrete is broken or support no longer needed |
| Cantilever slab/beam | Break from exterior edge inward; do not advance beam ahead of slab; or saw-cut & lift |

### 17. Top-down by machines — plant envelope (§4.3)

| Rule | Detail |
|---|---|
| Lift plant to roof | Mobile crane or RSE-approved means; props installed on floors beneath **before** lift; block operating area; Police + TD if road closure |
| Plant movement banned | Within **2 m** of building edge; within **1 m** of floor openings; on **any** cantilever — mark propped zones with ribbons/paint |
| Descent | Temporary ramp ≤ **1.75:1** (or manufacturer) with Table 3.4 props; or crane-lower with same precautions as lift |
| Sequence | Cantilevers first; then slab → secondary → main beams; plant may demolish two consecutive floors once descended (work same floor + break slab above) |
| Exterior wall sections | Width by RSE; plant capacity for section weight; may leave ~**300 mm** slab stub on external beam to keep load resultant inward |
| Brick infill | Manual remove first (push in from outside), then machine RC frame |
| Exterior RC frame / wall | Break concrete on cut lines first, keep rebar; excavator secures; pre-weaken columns; cut rebar; pull/guide **into** building |

### 18. Special structures — expanded red flags (§5)

#### 18.1 Precast (§5.1)

- Study joint continuity; open-up critical joints if doubtful  
- **Simple precast** (stability from stairs/cores/shear walls): reverse erection; break on ground or adequately supported floor; do not demolish lateral-stability elements before precast removed or temporary braced  
- **Do not reuse** existing lifting points unless record erection plans verify adequacy  
- Long slender units: spreader beams to reduce lift-point spacing  
- **Continuous precast**: cut continuous joints to maintain lateral stability; saw-cut then lift piece-by-piece if reversing erection

#### 18.2 Prestressed — identify before you commit (§5.2 + App. C)

**Suspect prestress if (no drawings):**

| Indicator | Threshold |
|---|---|
| One-/two-way slab span | > **8 m** |
| Joist system span | > **11 m** |
| Beam system span | > **15 m** |
| Span/depth exceeds Table C-1 | One-way slab 25–30 (single) / 30–35 (cont.); two-way 30–35 / 35–40; joists 20–25 / 25–28; beams 18–20 / 20–25 |
| Other clues | Large beams supporting multi-storey columns; visible precast joints; anchorage patches at slab edges / stair-lift shafts / beam ends; unusually resilient concrete under impact |

One post-tensioned floor ≠ all floors. Classes: precast pre-/post-tensioned (grouted/ungrouted); cast-in-place post-tensioned (incl. staged); segmental / circumferential tanks.

**Universal precautions:** Shore floor system **before** detensioning; protect tendon ends from shoot-off (backed plywood / screens); if ungrouted → fill voids with grout first; workers briefed + safety plan; sequence reverse of construction; experienced PE for segmental / circumferential tanks (chain nets / friction brakes against unwinding).

#### 18.3 Statically determinate / cantilevers / trusses (§5.3)

- Lack of continuity → failure of one part can collapse the system; redundancy may **become** determinate mid-demolition  
- Cantilevers: demolish **before** main structure each floor and before removing supports/anchors — else shore fully  
- Pin-jointed trusses: provide temp supports if bracing removed; prefer lift whole to ground; if dismantled in place, check every partial configuration

#### 18.4 Steel / composite (§5.4)

Often “simple” or “semi-rigid” joints → may become determinate during demo. Shore slender members when lateral restraints removed (except concrete-encased steel if capacity proven).

#### 18.5 Cladding (§5.5)

External features — extreme caution. Reverse of installation; **saw-cut & lift** preferred. Fully support (crane capacity for full cladding weight) **before** disconnecting joints; lower to ground / supported floor for reuse or break-up.

#### 18.6 Hanging structures (§5.6)

Floor loads hung by tension members from upper structure. Demolish **bottom → upward** (opposite to conventional). Cut-and-lift typically suitable. Gradually reduce hanging loads; **destress ties before cutting**; do not demolish main gravity / lateral structure until all hanging ties released; check main structure stability at every stage (brace if needed).

#### 18.7 Oil storage (§5.7)

Clean-up and DG/hazardous disposal dominate. Gas-free; confined-spaces regime; WDO / WPCO / Chemical Waste Regs; notify FSD or Gas Authority if DG licence exists; avoid flame cutting if flammable fuel likely. After demo: SCA per EPD-agreed proposal; remove contaminated soil entirely and replace with clean fill under AP/RSE supervision (or in-situ treatment if EPD approves); confine contamination during tank excavation; design temp shoring per §3.5.

#### 18.8 Marine structures (§5.8)

- Pre-demo **soundings** define seabed + unexpected underwater structure; set restoration baseline  
- Check pier platform capacity if plant/trucks travel on it  
- If not reclaiming: remove all seabed debris; restore to comparable pre-demo depth; silt screen / underwater fence during works  
- Piles: pull entirely if practicable, else cut ≥ **3 m** below seabed (or depth for future use)  
- Sensitive water: prefer saw-cut & lift to keep debris out of water; NEDA for piers

#### 18.9 Underground structures (§5.9) — integrate with new foundations

| Topic | Rule |
|---|---|
| Strategy | Prefer incorporating underground demo into **new foundation** construction to avoid redundant ELS / dewatering |
| Methods | Top-down above basement floor with shoring; NEDA to cut vibration; diamond stitch-drill for local pile-cap openings for new large bored piles |
| Uplift | In high water table, ensure FoS against uplift at all stages; relieve uplift before demolishing structure if needed |
| Shoring | Geotech evaluation for soil retention protecting neighbours; if floors prop basement walls, maintain that propping or replace with shoring when stripping structure |
| Dewatering | Assess effect on adjoining buildings/streets/services; disposal must not pollute or flood |
| Existing piles | Evaluate reuse in new foundation (records + load tests / borings) |
| Security | Secure against unauthorised entry to basement; escape route in deep excavations |

#### 18.10 Structures supporting ground / on slopes (§5.10 + 2016)

| Topic | Rule |
|---|---|
| Risk | Removing toe weight / support can cause regional slope instability |
| Who engineers | **RGE** (2016) — not “competent geotech engineer” alone |
| Building as retaining | Determine height that must remain to support RW; install adequate shoring/buttress **before** demolishing remainder; pass demo plan to foundation contractor |
| RW demolition | Stabilise retained ground **first** (cut to free-standing slope, or sheet/soldier piles, soil nails, etc.) |
| On-grade slabs | Generally **remain** against erosion / infiltration unless engineering report allows removal |
| Surcharge | **No** debris or surcharge behind or on top of RW / slope |
| Drainage | Manage surface runoff, off-site drainage, infiltration; maintain existing subsoil slope drains |

### 20. SD quick checklist (use before massing freeze)

1. Measure **clear space / building height** → hoarding vs walkway vs catch platform; reserve street occupation.  
2. Complete Building + Structural Surveys (or budget opening-up if no records); flag age / LCC capacity.  
3. Map **party walls, shared stairs, truncated frames, cantilevers over street, MTR / utilities / slopes**.  
4. Screen for **prestress** (spans + Table C-1) and all §2.1.3(A)(3) unconventional elements.  
5. List **complex structures** → §6.2 site engineer + specialist method + video / Chinese procedures.  
6. Decide **top-down machine vs manual vs cut-and-lift vs long-boom** from slab capacity, setbacks, and neighbour sensitivity.  
7. Lock plant envelope: props (Table 3.4 / ≤5,800 kg light plant), **2 m / 1 m / no-cantilever** exclusion zones, roof-lift / ramp logistics.  
8. Programme **asbestos (AIR + 28-day AAP)**, utility termination, soil SCA if DG/chemical history.  
9. Coordinate **temporary party-wall support** with **new abutment / waterproofing / foundations**.  
10. If basement / slopes / RW → appoint **RGE**; plan ELS / dewatering / pile reuse with new foundation; hand temp-works drawings across contracts.  
11. Budget TIA, debris truck gate, on-site sorting space, and adjoining-site interface precautions.  
12. Confirm RSC (Demolition), TCP grades, and Supervision Plan scale factor for demolition (see CoP Site Supervision — basic value 750 m² max floor area per storey).
