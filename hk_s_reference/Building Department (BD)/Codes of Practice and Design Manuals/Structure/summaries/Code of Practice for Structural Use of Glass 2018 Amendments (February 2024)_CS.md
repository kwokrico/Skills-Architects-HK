# Code of Practice for Structural Use of Glass 2018 — Amendments (February 2024)
**Architect critical summary for schematic design**
February 2024 | Buildings Department

> Scope note: This is the February 2024 amendment sheet to the Code of Practice for Structural Use of Glass 2018. It removes balustrade weep holes from a typical detail, and it redefines the cyclic-pressure test pressure p2. It is **not** the 2018 code.

## Regulatory Overview
The cyclic positive and negative pressure test now uses the net wind pressure on the mullion from the 2019 wind code, with at least five pulses. A footnote keeps the older cp times qz product only where the 2004 wind code is still the curtain-wall design basis.

## Critical main topics and subtopics

### 1. Balustrade weep holes (Figure 6.1)

| Item | Change |
|---|---|
| Figure 6.1 | The **8 mm** diameter weep holes for external application are deleted from the typical glass balustrade details |

The replacement figure did not extract as a drawing. Do not keep 8 mm weep holes from the pre-amendment detail.

**SD takeaway:** Do not show 8 mm external weep holes on the typical glass balustrade in Figure 6.1.

### 2. Repeated pressure test (clause 8.3.1(b), Annex B)

| Item | Rule |
|---|---|
| p2 | Net wind pressure **P** on the mullion of the representative portion in the performance test, from the Code of Practice on Wind Effects in Hong Kong **2019** |
| Pulses | Not less than **5** |
| If the curtain wall is still designed to the 2004 wind code | p2 is the product of the total pressure coefficient **cp** and the design wind pressure **qz** for that part of the building |
| Annex B step k | Record the failure load (the symbol is amended; the text layer shows W) and the time to reach it |
| Figure B1.1 | The expression of applied load is revised. The printed expression did not extract as text |

**SD takeaway:** Set the cyclic glass test pressure p2 to the 2019-code net pressure on the mullion, unless the curtain wall is still on the 2004 wind code, in which case p2 stays cp times qz.
