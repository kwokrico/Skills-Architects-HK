# Code of Practice for Precast Concrete Construction 2016 — Amendments (November 2020)
**Architect critical summary for schematic design**
November 2020 | Buildings Department

> Scope note: This is the November 2020 amendment sheet to the Code of Practice for Precast Concrete Construction 2016. It retargets corrosion cover and material rules to the concrete code, and it widens the alkali-silica controls. It is **not** the 2016 code, and it is **not** the June 2026 sheet.

## Regulatory Overview
Corrosion cover and material properties for precast concrete now follow the Code of Practice for Structural Use of Concrete 2013. Fire cover still follows the Code of Practice for Fire Safety in Buildings.

## Critical main topics and subtopics

### 1. Cover, durability and materials (clauses 2.4.3, 2.4.4.1, 2.6.1)

| Item | Amended rule |
|---|---|
| Fire cover | Code of Practice for Fire Safety in Buildings |
| Corrosion cover | Code of Practice for Structural Use of Concrete 2013 (replaces the Building (Construction) Regulations for this item) |
| Connections | Fill to prevent corrosion, cracking, spalling, **or water seepage** |
| Materials | Building (Construction) Regulations **and** the Code of Practice for Structural Use of Concrete 2013 |
| Design properties | From the Code of Practice for Structural Use of Concrete 2013 |

**SD takeaway:** Size precast cover for corrosion from the 2013 concrete code, and detail every connection against water seepage as well as corrosion.

### 2. Alkali-silica reaction (clause 2.6.2.1)

The reactive alkali content, as equivalent sodium oxide, must not exceed **3.0 kg per cubic metre**. The supplier still gives the authorized person or registered structural engineer a mix design and HOKLAS-endorsed certificates for that limit.

Additional means now listed:

| Means | Rule |
|---|---|
| Cement | Control the amount, or use a low-alkali cement |
| Replacement | Pulverised fuel ash (pfa) where appropriate |
| Aggregate | Seek expert advice before alkali-reactive aggregates are used, or use non-reactive aggregate in accordance with CS1 |
| Moisture | Restrict water ingress from the environment |

**SD takeaway:** Keep equivalent sodium oxide at or below 3.0 kg/m³, and do not specify a reactive aggregate without expert advice or a CS1 non-reactive aggregate.
