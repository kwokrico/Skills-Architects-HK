# Code of Practice on Wind Effects in Hong Kong 2019 — Amendments (December 2023)
**Architect critical summary for schematic design**
December 2023 | Buildings Department

> Scope note: This is the December 2023 amendment sheet to the Code of Practice on Wind Effects in Hong Kong 2019. It revises when a wind-tunnel test is required, corrects figure cross-references, and elaborates the size factor. It is **not** the 2019 code, and it is **not** the companion explanatory notes (those have their own December 2023 sheet).

## Regulatory Overview
The sheet’s own list of changes is short: Figures 2-1 and 2-2 change the condition for a wind-tunnel test, Table 4-1 and two appendices are textual, and Figure 5-2 with Appendix C1 elaborates the size factor. The figure graphics themselves did not come through as text, so the numeric wind-tunnel trigger must be read from the PDF.
