# Structure Codes Index (English)

**Issued by:** Buildings Department
**Scope:** Amendment sheets in this folder that have a critical summary: concrete (February 2022, June 2023, April 2024), precast concrete (November 2020, June 2026), structural glass (2020 annex, February 2024), wind code and wind explanatory notes (December 2023), foundations (September 2025), and structural steel (April 2026). This table also indexes the explanatory materials to the 2011 steel code and the 2019 wind explanatory notes. It does not index the parent codes whose summaries sit beside `source_reference/`. This library was not checked against the live departmental website.
**How to use:** The date links to the critical summary. The PDF link opens the file in `source_reference/`. June 2023 onward summaries are in `summaries/`. The February 2022 summary stays in this folder.
**Titles:** The official title is the summary heading.
**Caveat:** Desk reference only. Before a submission, check the current code and every later amendment sheet.
