# Minor Works Control System (MWCS)
**Architect critical summary for schematic design**  
Source: *Introduction to Minor Works Control System* pamphlet (January 2022) — Buildings Department  
Statute: Building (Minor Works) Regulation Cap. **123N** | Fully in force **31 Dec 2010**  
Amendments: **2012** (+8 items); **1 Sep 2020** (9 repealed / 56 amended / **70 added** → current **187** items)  
Also: [BD MWCS introduction](https://www.bd.gov.hk/en/building-works/minor-works/introduction-to-minor-works-control-system/index.html) · PNRC 71 · Technical Guidelines on MWCS · Cap 123N Schedules 1–3

> Scope note: MWCS is a **simplified statutory pathway** for **187 scheduled small-scale building works** grouped into **40+ nature/substance categories**. It is **not** a design code and **not** a waiver of Cap 123 standards (fire, structure, drainage, BFA, etc.). At SD: decide whether the scope is (a) **s.14(1) full approval + consent**, (b) **MWCS Class I / II / III**, (c) **Designated Exempted Works (30 items)**, or (d) **s.41(3) general exempted works**. Wrong track = UBW risk, programme blow-up, or unenforceable tenant fit-out. Always verify live numeric limits in Schedule 1 / Technical Guidelines — the pamphlet tables are a **routing map**, not the full criteria.

---

## Regulatory Overview

MWCS applies to **187 prescribed minor works items** under Cap **123N**, classified by scale, complexity and safety risk into **Class I (58)**, **Class II (68)** and **Class III (61)**. Works that fit an item may start **without** prior BA plan approval and commencement consent under Cap 123 **s.14(1)**, if the correct **Prescribed Building Professional (PBP)** and/or **Prescribed Registered Contractor (PRC)** are appointed and the simplified notice / certify regime is followed.

It does **not** apply to Cap **121** New Territories Exempted Houses; does **not** legalise works that still breach Cap 123 regulations; and sits beside **30 Designated Exempted Works**, **s.41(3) general exempted interior works**, and three **validation schemes** for certain pre-cut-off unauthorised household features, amenity features and signboards.

## Critical main topics and subtopics

### 1. SD gate — which track is this scope on?

| Track | When it fits | SD implication |
|---|---|---|
| **Full Cap 123 s.14(1)** | Outside Schedule 1 size / location / criteria; structural works beyond MW limits; new building; large A&A | Full AP/RSE plans + consent |
| **Class I MW** | Highest complexity/risk among the 187 (e.g. internal stair linking floors, many underground drains, larger signboards, SDF packing item 1.41) | **PBP + PRC**; notice **≥7 days** (MW01); complete **14 days** (MW02); **supervision plan** for some items |
| **Class II MW** | Medium complexity (e.g. many external wall repairs, medium frames/ducts/signboards) | **PRC only** for plans + carry out; notice **≥7 days** (MW03); complete **14 days** (MW04) |
| **Class III MW** | Low risk / household & amenity scale | **PRC only**; **no** pre-start notice; complete **14 days** (MW05 — plans **or** description + photos) |
| **Designated Exempted Works (30)** | Below MW thresholds (height, weight, projection, excavation, etc.) | No BA approval, no MWCS forms, **no** mandatory AP/RC — still must not breach Cap 123 regs |
| **s.41(3) general exempted works** | Works **in a building** that are **not** minor works **and do not involve the structure** | No MWCS; still comply with fire / structural / drainage regs |
| **Validation schemes** | Existing UBW matching Schedule 3 **and** pre-dating the scheme cut-off | Retain after inspect / strengthen / certify — **still UBW in law**; enforcement deferred unless dangerous |

**SD takeaway:** Lock the track before massing AC plant, signage, roof amenity, subdivided layout, or fit-out. Size / height / projection / cantilever / load-path criteria decide Class — design above the limit and you leave MWCS.

### 2. How to read every pamphlet item number (mandatory interpretation)

| Rule | Meaning for SD / tender |
|---|---|
| **`1.5`** = Class I, item 5 in B(MW)R Schedule 1 | Always quote class + item on forms and drawings |
| **Alteration** includes **strengthening** | Do not invent a separate “strengthen only” track outside the item |
| **Erection** includes **replacement** | Same item covers like-for-like swap if criteria still met |
| **Removal** includes removal of **UBW** matching that item’s description | Use MW removal items to clear illegal fabric of the same type |
| Item criteria are mostly **structural-safety gates** | Typical bans: **no additional load to any cantilevered slab**; **no alteration of other structural elements**; if on slab/roof → often **slab/roof must not be cantilevered** |
| PBP/PRC must ensure **all** requirements of the chosen item are met | If any criterion fails → wrong class, or leave MWCS entirely |

**Who is “the person who arranged the works” (PAW):** owner, occupant, **or agent (e.g. the design company)** — PAW must appoint PRC for **all** classes, and PBP for Class I.

**PBP (note 1):** AP / RI\* + (if required) RSE / RGE.  
\*RI may assume AP role only for **prescribed repair or associated demolition** (MBIS context).

**PRC (note 2):** RGBC, **or** Registered Specialist Contractor (matching specialised category), **or** RMWC registered for the **class / type / item**.

**Mid-job additional items (Class I/II only):** if extra Class I/II items arise after the original notice → submit **MW11** (Class I) or **MW12** (Class II) **≥7 days** before those additional items start, with plans/details. On completion, one MW02/MW04 package covers **all** completed items including the additions.

### 5. Universal design kill-switches (before any sketch)

| Constraint | Why it matters |
|---|---|
| **No additional load to any cantilevered slab** | AC frames, signboards, tanks, planters, poles, ducts on canopies / cantilevered roofs often **out** |
| **No alteration of other structural elements** (unless the item expressly allows) | Openings, thickening, stairs, dowelled panels |
| **Roof / slab not cantilevered** (many items) | Confirm from approved structural plans / BRAVO |
| **Projection / height / weight / thickness / display-area / excavation-depth caps** | Cross Class I↔II↔III and DEW; millimetres decide track |
| **Scheduled Areas (Cap 123 Sch 5)** | Some excavation / footing items barred |
| **Common parts / external wall / street projection** | DMC + OC / management consent; many household items ban projection over street / common parts |
| **Cap 123 regs still apply** | MOE, FRC, drainage, BFA, lighting/ventilation — MWCS only skips s.14(1) procedure |

### 7. s.41(3) general exempted works (not MW, not DEW)

Building works **other than minor works**, carried out **in a building**, that **do not involve the structure** → Cap 123 **s.41(3)** exempted. No prior BA approval/consent; **no** mandatory PBP/PRC — **but must not contravene** Cap 123 regulations (fire, structure, drainage, etc.).

**Pamphlet examples (common interior renovation):**
- Painting, internal plastering, wallpaper
- Repair/replacement of **internal branch pipe** (**other than embedded pipe**) or sanitary fitments
- Removal of **non-load bearing partition walls** that **need not have fire resistance rating**

**SD trap:** If the partition is FRR-required, load-bearing, or the pipe is embedded → **not** this free pass. If the works match a Schedule 1 MW item → use MWCS, not s.41(3).

**How to read Columns A and B (all three MW06 forms):** Column A = inspected, no alteration or strengthening required. Column B = minor works to alter, rectify or strengthen are necessary under BO **s.39C(4)**. The certificate says the works are structurally safe and comply with the Buildings Ordinance **except s.14(1)** and **Building (Administration) Regulations reg. 25**. Validation is not a retrospective approval.

**VSR** (Safety Inspection Checklist) is the attachment to a validation submission, not a separate notice. One report may cover more than one prescribed building or building works item; if the same item has **different descriptions**, submit a **separate** VSR set for each description. It ticks Schedule 3 features against designated-exempted-works exclusions. Numeric envelopes stay in §8 and on the checklist — a failed tick means the feature is outside that validation item, or it needs alteration or strengthening on the matching MW06.

**Signboard Validation (pamphlet only):** pre-**2 Sep 2013** prescribed signboards; typically a **5-year** re-validation cycle. Do not assign an MW06 number. Unauthorised signboards are excluded from the MW01/MW03 validation tick.

Pamphlet position, unchanged: validated works remain **UBW in law**. BA generally will not enforce solely for lack of prior approval unless they become dangerous. Works after the cut-off on the form cannot join that list. Class III items **3.34–3.37** remain the MW pathway when household-type AC frames, drying racks or canopies need strengthening.

**SD takeaway:** Do not use one date for every validation. On **MW06-3**, household items (Schedule 3 Part 2) are pre-**31 Dec 2010**; amenity items (Part 4) are pre-**1 Sep 2020**. Class I amenity uses **MW06-1** (and MW01 if works already started); Class II amenity uses **MW06-2** (and MW03).

### 12. Civil / liability / site rules (pamphlet pp.15–16)

| Topic | Rule |
|---|---|
| **Building records** | PBP/PRC must base plans on **site inspection of actual condition** + available records. Inspect at **BIC** (2/F, BD HQ North Tower, 11 Hoi Ting Road, Yau Ma Tei) or via **BRAVO** ([bravo.bd.gov.hk](https://bravo.bd.gov.hk)); copies on application + fee |

| **Pay for Safety Scheme** | Encouraged: tender includes priced safety items; employer pays only if satisfactorily carried out — keeps safety from being tendered away |

### 13. SD decision tree (every A&A / fit-out / amenity package)

1. Cap **121** NTEH? → stop (different regime).
2. Involve **structure**? Match **Schedule 1 MW** or **DEW**? Or pure **s.41(3)** non-structural interior?
3. Measure **height, projection, weight, display area, excavation depth, cantilever / load path, on-grade vs roof**.
4. Fit **DEW** → document numeric envelope; no MWCS forms.
5. Else fit **exact MW item** (§6 tables) → Class → Types A–H (§11) → appoint PBP/PRC with matching registration → use the §9 form for that class (MW01/MW11 then MW02; MW03/MW12 then MW04; MW05 only). **MW32** is a display number for Class III signboard items 3.16 / 3.17; it does not replace MW05.
6. Else → **full s.14(1)** A&A.
7. Existing UBW? → validation forms in §10 (**MW06-1 / MW06-2 / MW06-3**) or removal items (§6.4) or formal A&A. Signboard validation has no form in this folder set — pamphlet only.
8. Cross-check **FS Code / FSI / drainage / BFA / DMC** — MWCS never overrides these.
9. Pull **approved architectural + structural** records (BIC/BRAVO) before locking openings, roof loads, barriers, or façade works.

### 14. Appointment changes, supplementary documents, attachment sheets

A change of person is its own form. Do not resubmit MW01 / MW03 to swap an AP, RSE, or contractor. All of these are **within 7 days**.

| Form | When | What it does |
|---|---|---|
| **MW08** (09/2021) | Within 7 days after the **new** appointment | New AP or RI in place of the original (B(MW)R **s.27**, confirmation **s.48(3)**). Where the Technical Memorandum requires a supervision plan, submit a **revised** supervision plan (**s.48(3)(b)**) |
| **MW07** (09/2021) | Within 7 days after appointment of the new person(s) | New RSE, RGE, or PRC (appointment under **s.27** and/or **s.28**; confirmation **s.48(2)**, and **s.48(4)** for the contractor). AP or RI submits the revised supervision plan when the Technical Memorandum requires one |

| **MW31** (09/2020) | Within 7 days after the date of **cessation or nomination** | PBP (AP, RSE, RI, or RGE) ceases to be appointed or nominated (**s.50**). State the date and the minor works completed under that person’s supervision |
