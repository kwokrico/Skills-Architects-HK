# ADM-9

**Official title:** Colouring of Plans

**In plain words:** Building (Administration) Regulation 14(3) requires one copy of every plan submitted for approval to be coloured, so existing work can be told apart from new work, and one part of the new work from another. This note sets the preferred colours. It does not change gross floor area (GFA) or site coverage (SC). Clear colouring helps the Buildings Department read which work is accountable.

**Numbers that matter**
- Plot colours at full intensity (screening 100). Preferred colours, with red-green-blue values and the AutoCAD colour index:

| Material or marking | Colour | RGB | AutoCAD index |
| --- | --- | --- | --- |
| Hardcore or dry fill | Putty | 204, 178, 102 | 43 |
| Brick | Orange Red | 255, 63, 0 | 20 |
| Concrete slab (lighter wash) | Witch Haze | 223, 255, 127 | 61 |
| Concrete (plain or reinforced) | British Racing Green | 0, 76, 38 | 118 |
| Solid concrete blocks | Electric Blue | 127, 223, 255 | 141 |
| Hollow concrete blocks | Purple | 191, 127, 255 | 191 |
| Lightweight partition (for example plasterboard) | Macaroni and Cheese | 255, 191, 127 | 31 |
| Plaster or cement rendering | Wild Willow | 204, 204, 102 | 53 |
| Impermeable or non-absorbent floor or wall | Neon Pink | 255, 127, 223 | 221 |
| Glass | Electric Blue | 127, 255, 255 | 131 |
| Timber | Muesli | 153, 133, 76 | 45 |
| Metalwork or steel | Heliotrope | 223, 127, 255 | 201 |
| Stone finish | Dark Grey | 173, 173, 173 | 253 |
| Sanitary fittings | Yellow | 255, 255, 0 | 50 |
| Demolition, or deletion of approved work | Blue | 0, 63, 255 | 160 |
| Underline for a revision | Venetian Red | 204, 0, 51 | 242 |

- Leave ducts, light-wells, and lift shafts uncoloured.
- On elevations and large plan areas, use a lighter wash of the preferred colour. A light wash may also mark a phase of the development.
- Put a colour legend on every drawing set.
- On an amendment, colour or otherwise mark the proposed work so it is distinct from the approved work. Use the same method on every set.

**What to submit**
- One coloured copy, as Building (Administration) Regulation 14(3) requires, using the Appendix A colours, with a legend. Amendment sets must identify the changes in the same way on every set.

**Watch-outs**
- An uncoloured approval copy is contrary to Building (Administration) Regulation 14(3).
- Amendment sets that are coloured differently from each other delay processing.
- Colouring ducts, light-wells, or lift shafts goes against the guidance. Leave them blank.
- Colour alone does not survive imaging. ADM-10 requires hatching or notes as well, because colours are not readable on the archive image.
