# APP-153

**Official title:** Code of Practice for Fire Safety in Buildings 2011

**In plain words:** This note says when the Code of Practice for Fire Safety in Buildings 2011 applies, and when an older code may still be used. It does not change gross floor area (GFA) or site coverage, but fire rules still limit permeable elements, refuge floors, sky gardens, emergency vehicular access, and voids used with APP-151 and APP-152, and those concessions never override this Code.

**Numbers that matter**
- The Fire Safety Code replaces the Means of Escape Code 1996, the Fire Resisting Construction Code 1996, and the Means of Access Code 2004. Operative 1 April 2012. PNAP revised September 2024, consolidating amendments (Appendices B to H) into the Fire Safety Code (2024 Edition) on the Buildings Department website. Detailed fire design is in the Code, not in this practice note.
- The Code has Parts A to G, plus Annex A on licensing-authority codes.
- Works consented before 1 April 2012 may continue on the old Means of Escape, Fire Resisting Construction, and Means of Access Codes. For a new building, the relevant consent is the foundation consent. Submissions made before 1 April 2012 may use the Fire Safety Code only in its entirety.
- Cap. 502 and Cap. 572 upgrading stays on the APP-94 and APP-145 basis. The Fire Safety Code does not apply to those improvement regimes.
- For alteration and addition, or licensed premises, generally only the affected areas, plus affected exit routes, need the Fire Safety Code. The rest of the building need not.
- Consent for plans approved before the Fire Safety Code is generally acceptable if consent is within 2 years of the first approval. Then amend the plans for the Fire Safety Code before the occupation permit as necessary. Otherwise the occupation permit may be refused under Buildings Ordinance section 21(6), and/or consent may be refused under section 16(3)(d).
- When the Fire Safety Code governs, the practice notes in Appendix A of this PNAP do not apply: APP-14, 75, 80 to 83, 85, 87, 91, 92, 106, 121, and 123. Those practice notes still apply to old-Code designs and to Cap. 502 and Cap. 572 works.
- Consolidated amendments through September 2024 include, as examples from early corrigenda and not a full list: swimming-pool occupant capacity based on water surface (Use 5d); fire door and shutter insulation rules, with a sprinkler option if openings are more than 25% of the wall length; combustibility classifications for linings (BS EN 13501-1 and Table E1 equivalences). Take the full current text from the Fire Safety Code 2024 Edition.

**What to submit**
- Design the whole of the building works to the Fire Safety Code, or wholly to the applicable old codes under the grandfather rules.
- For alteration and addition, limit the Fire Safety Code upgrade to the affected areas and exit routes unless more is required.
- Track Technical Committee amendments in Appendices B to H, and use the 2024 Edition on the Buildings Department website.

**Watch-outs**
- Do not mix the old codes with the Fire Safety Code in part.
- Do not apply the Fire Safety Code to Cap. 572 or Cap. 502 upgrading, and do not apply those obsolete practice notes to a new building governed by the Fire Safety Code.
- If consent is more than 2 years after an old-Code approval, address the Fire Safety Code before the occupation permit.
- Do not rely on the amendment notes in this practice note instead of the consolidated Code.
