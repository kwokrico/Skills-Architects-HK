# APP-82

**Official title:** Code of Practice for the Provision of Means of Escape in Case of Fire 1996

**In plain words:** This note explains the 1996 Means of Escape (MOE) Code, which guides Building (Planning) Regulations section 41(1), including a new Part III for places of public entertainment. It does not change gross floor area or site coverage, but travel distance and exit capacity still drive the core layout.

**Numbers that matter**
- Formerly practice note (PNAP) 195. First issued June 1996. Re-issued August 2009. See also PNAP 163, PNAP 192, and PNAP 194.
- The main code takes effect on 1 December 1996 (1.12.96).
- Part III was already in force on 28 June 1996 (28.6.96), under PNAP 194 and APP-81.
- Works already being carried out, or consented on or before 1 December 1996, may use the earlier MOE edition.

**What to submit**
- State which MOE edition applies, based on the consent date.
- The code is sold at the Government Publication Centre.

**Watch-outs**
- Part III and the main code have different start dates. Using one date for both is wrong.
- A scheme consented on or before 1 December 1996 does not automatically switch to the new code.
- A fire engineering approach for an existing building needs an agreed framework. This note says further guidelines may follow.
