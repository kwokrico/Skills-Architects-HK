# APP-80 Code of Practice for Fire Resisting Construction 1996
**Architect critical summary for schematic design**
First issued April 1996 | Buildings Department (re-issued under the new categorization in August 2009)

> Scope note: Announces the Code of Practice for Fire Resisting Construction 1996 as guidance on Part XV of the Building (Construction) Regulations. The construction rules are in that Code, not in this note.

## Regulatory Overview
The 1996 Code revises the 1990 Code: it clarifies anomalies, upgrades standards for some building components, and removes duplication with the Code of Practice for the Provision of Means of Escape in Case of Fire. It is effective on 1 August 1996 and does not apply to buildings or building works being carried out, or consented to commence, on or before that date.

## Critical main topics and subtopics

### 1. Which edition applies (paragraph 3)
| Works | Code |
| --- | --- |
| Consented to commence, or being carried out, on or before 1 August 1996 | Not subject to the 1996 Code |
| Later works | The 1996 Code |

**SD takeaway:** Use the 1996 Fire Resisting Construction Code for works whose consent is after 1 August 1996.
