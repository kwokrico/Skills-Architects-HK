# APP-90 Buildings Ordinance Section 18(6) Authority to Enter Buildings
**Architect critical summary for schematic design**
First issued June 1997 | Buildings Department (re-issued under the new categorization in August 2009)

> Scope note: How to apply for Building Authority authorization to enter an adjacent building to erect shoring under section 18. Shoring for demolition is also covered in PNAP 71. Compensation is under sections 18(4), 18(5), and 18A.

## Regulatory Overview
Section 18(1) authorizes shoring necessary for specified purposes, and section 18(6) empowers the Building Authority to authorize entry for that shoring. An application is made only after all reasonable steps to obtain the owners' and occupants' consent have failed, and only if there is no other way to provide the precautionary measures.

## Critical main topics and subtopics

### 1. Application and authorization (paragraphs 3–5)
| Item | Content |
| --- | --- |
| Written application | Name of applicant; HKID, passport, or business registration number; full address and lot number of the building to be entered; purposes; justification that shoring inside the adjacent building is the only possible precaution; name of any agent under section 18(6)(b); registration certificate number if the applicant or agent is a registered contractor |
| Issue | Written authorization normally within 2 weeks of an application that contains all the necessary information, once the Building Authority is satisfied there is no alternative support |
| Posting | A copy is posted in a conspicuous position on the building |

**SD takeaway:** Design shoring that stays on the site if at all possible; entry under section 18(6) is only after consent has been refused and the submission proves there is no other precaution.
