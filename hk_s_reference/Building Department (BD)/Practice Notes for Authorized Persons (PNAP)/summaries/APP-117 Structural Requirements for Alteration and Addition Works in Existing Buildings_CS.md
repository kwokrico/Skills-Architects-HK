# APP-117 Structural Requirements for Alteration and Addition Works in Existing Buildings
**Architect critical summary for schematic design**
First issue December 2000 | Buildings Department (previously PNAP 249)

> Scope note: Structural checking for alteration and addition works in existing buildings. Fire-safety code application is in PNAPs 202 and 231. It is not a new-building structural code.

## Regulatory Overview
Alteration and addition works need new structural elements designed to current regulations and a check of the existing construction they affect. Existing members may be checked to the regulations and codes to which they were designed, except where wind, storage load, or flat-slab shear triggers a current check.

## Critical main topics and subtopics

### 1. Existing condition and new work (paragraphs 2–3)
| Item | Rule |
| --- | --- |
| Viability | Every structural-plan submission is accompanied by an assessment of structural viability |
| Inspection | The authorized person, or the registered structural engineer if appropriate, inspects existing structural elements affected by the works. Site photographs of all affected elements should be submitted wherever possible |
| New elements | Designed to the current Building Regulations and relevant codes of practice |
| Tests | Include, if appropriate, tests of existing elements likely to be affected, and any planned remedial works |

**SD takeaway:** Inspect and photograph every existing member the alteration touches, and design every new member to the current codes.

### 2. When the old code is not enough (paragraph 4)
Existing structural adequacy may be checked to the then prevailing Building Regulations and codes, subject to:

| Trigger | Check |
| --- | --- |
| Wind: removal | Partial or total removal of existing major wind-resisting walls or frames that reduces their stiffness by 5% or more: check wind adequacy to the current wind code |
| Wind: exposure | Extension of building dimensions that increases wind exposure area by 10% or more: check to the current wind code |
| Storage floors | Existing floors used for storage, when affected, checked using the minimum imposed loads in the current Building (Construction) Regulations |
| Flat slabs | Flat slabs originally designed by the working-stress method, if structurally altered or given any additional load: check shearing stresses using the Code of Practice for the Structural Use of Concrete 1987 |

**SD takeaway:** A 5% loss of wind-frame stiffness or a 10% increase in wind exposure area forces a current wind-code check of the whole building.

### 3. Missing original plans (paragraph 5)
| Item | Rule |
| --- | --- |
| Source of details | Original approved plans |
| If plans are unavailable | Justification by comparing effects of new and original loading, bending moments, and shear forces may be accepted |
| Opening up | If necessary, open up affected elements to ascertain reinforcement and concrete strength |
| Drawings | Reinforcement details of affected existing members, when available, should be shown on drawings, following paragraph 6 of PNAP 121 |

**SD takeaway:** If the original structural plans are missing, compare new and original forces or open up the members before relying on the old design.
