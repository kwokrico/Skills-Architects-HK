# ADM-6 Computer Programs for Use in Structural and Geotechnical Design
**Architect critical summary for schematic design**
This revision June 2016 | Buildings Department (previously PNAP-79; first issue December 1981)

> Scope note: Requires prior acceptance of a structural or geotechnical computer program before it is used to support a submission. It does not transfer design responsibility to the Buildings Department.

## Regulatory Overview
An authorized person, registered structural engineer, or registered geotechnical engineer who uses a computer program to produce calculations or designs for submission must ensure the program is acceptable to the Building Authority before plans are submitted for approval. Acceptance assigns a Buildings Department reference number, but the registered structural engineer or registered geotechnical engineer remains responsible for execution of the program.

## Critical main topics and subtopics

### 1. Prior acceptance (paragraphs 2–3 and 6)
| Item | Rule |
| --- | --- |
| Who applies | Registered structural engineer for a structural program; registered geotechnical engineer for a geotechnical program |
| Reference number | Prefixed S for structural and G for geotechnical; quote it in submissions |
| Form | Appendix A pro forma, with a user's manual covering modelling, flow charts, codes complied with, theory and algorithm, limitations, input and output, interpretation of results, and examples verified by the RSE or RGE |
| Copies | One program manual for a structural program; two for a geotechnical program |
| No valid reference | The Building Authority may require all of the paragraph 3 information in the submission |

**SD takeaway:** Do not base a structural or geotechnical submission on a program that has no current S or G reference; apply for acceptance, or attach the full paragraph 3 pack, before plan approval.

### 2. Use in a plan submission (paragraphs 4–5)
| Item | Rule |
| --- | --- |
| Calculations | Provide the information required in the first part of the structural calculations by paragraph 9(b) of PNAP ADM-8 |
| Execution | The RSE executes a structural program; the RGE executes a geotechnical program |
| Forms | Complete Appendix B and/or C and include them in the submission |

**SD takeaway:** Quote the BD reference and include the Appendix B or C certificate; acceptance of the program does not move design responsibility off the RSE or RGE.

### 3. Expiry, renewal, and changes (paragraphs 7–10)
| Item | Rule |
| --- | --- |
| Validity | Up to three years; treated as expired three years from the date of the last acceptance |
| Renewal | On expiry, not earlier than four months before the expiry date |
| Changes | Submit details of amendments and the updated user manual, if applicable, and obtain acceptance before using the revised program |
| Lists | Currently accepted programs and limitations are at the New Buildings Divisions Receipt and Dispatch Counter, 7/F, Cityplaza 3, 14 Taikoo Wan Road, or at www.bd.gov.hk |

**SD takeaway:** Check that the program's acceptance is still inside the three-year window, and re-submit any change before the revised program is used.
