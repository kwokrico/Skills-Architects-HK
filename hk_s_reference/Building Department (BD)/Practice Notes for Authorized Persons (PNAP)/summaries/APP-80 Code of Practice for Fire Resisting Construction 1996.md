# APP-80

**Official title:** Code of Practice for Fire Resisting Construction 1996

**In plain words:** This note brings in the 1996 Fire Resisting Construction (FRC) Code, which guides Part XV of the Building (Construction) Regulations. It does not change gross floor area or site coverage, but the upgraded fire resistance can still constrain compartment walls, ratings, and openings.

**Numbers that matter**
- Formerly practice note (PNAP) 192. First issued April 1996. Re-issued August 2009.
- The revised code takes effect on 1 August 1996.
- It does not apply to building works that were already being carried out, or that already had consent to start, on or before 1 August 1996.
- See also PNAP 163.

**What to submit**
- Use the 1996 FRC Code for plans where consent is after 1 August 1996.
- The code is sold at the Government Publication Centre.

**Watch-outs**
- Using the wrong edition for the consent date is a common error.
- The 1990 code does not govern works after the 1 August 1996 effective date.
- Later corrections are in APP-83. For newer projects, check whether the Fire Safety Code 2011 has taken over, based on that project’s approval and consent dates.
