# APP-142

**Official title:** Code of Practice for Structural Use of Concrete 2013

**In plain words:** This note publishes amendments to the Code of Practice for Structural Use of Concrete 2013 (2020 Edition). It does not change gross floor area (GFA) or site coverage.

**Numbers that matter**
- Amendments are in Appendix A (February 2022), Appendix B (June 2023), and Appendix C (April 2024). Latest PNAP revision April 2024. The full text is in the Code amendments on the Buildings Department website.
- February 2022, key item: new clause 6.2.3 on plain concrete linings for tunnels and caverns, with interaction curve Figure 6.18b. Where eccentricity ec is 0.1h or less: nLT ≤ 0.32 h fcu. Where 0.1h < ec ≤ 0.3h: nLT ≤ 0.4(h − 2ec) fcu. Maximum eccentricity is 0.3h. Shear follows the Code clauses cited in the amendment.
- Cube tests: 100 mm cubes are the default. Use 150 mm cubes if the maximum aggregate is over 20 mm. Maturity method: Table 11.2 and ASTM C1074.
- Appendices B and C add further Technical Committee updates (June 2023 and April 2024). Use the consolidated Code on the Buildings Department website.

**What to submit**
- Structural submissions to the current Concrete Code 2013 (2020 Edition) as amended.
- Quality-control testing and maturity monitoring during construction follow the amended clauses.

**Watch-outs**
- Do not design plain concrete linings outside the compression and rock criteria, or beyond 0.3h eccentricity.
- Do not use the wrong cube size for the aggregate, and do not ignore maturity-method correction factors.
