# APP-153 Code of Practice for Fire Safety in Buildings 2011
**Architect critical summary for schematic design**
This revision September 2024 | Buildings Department

> Scope note: When the Code of Practice for Fire Safety in Buildings 2011 applies, and when the 1996 means-of-escape and fire-resisting-construction codes and the 2004 means-of-access code may still be used. The code gives guidance on regulations 41(1), 41A, 41B, 41C, and 41D of the Building (Planning) Regulations and section 35 of the Building (Construction) Regulation. Later amendments are Appendices B to H, the last dated September 2024 against the June 2023 Edition. It does not apply to improvement works under the Fire Safety (Commercial Premises) Ordinance (Cap. 502) or the Fire Safety (Buildings) Ordinance (Cap. 572); those follow PNAP APP-94 and PNAP APP-145.

## Regulatory Overview
The 2011 code substitutes the three earlier codes and has been in operation since 1 April 2012, except where foundation consent, or consent to the works, had already been given on or before that date. It is applied to the whole building or the whole of the works; a partial application is not accepted.

## Critical main topics and subtopics

### 1. Which code applies (paragraphs 1–2)
The code has Parts A to G (introduction, means of escape, fire resisting construction, means of access, fire properties, fire safety management, and fire engineering) and Annex A for licensing guides.

| Case | Code |
| --- | --- |
| Works being carried out, or consent already given, on or before 1 April 2012 | The 1996 and 2004 codes may continue. For a new building, the relevant consent is the consent to commencement of the foundation works |
| Plans submitted before 1 April 2012 that elect the 2011 code | The 2011 code must be used in its entirety |
| Cap. 502 or Cap. 572 improvements | Not this code |

**SD takeaway:** A new building whose foundation consent is after 1 April 2012 is designed to the 2011 fire safety code as a whole.

### 2. Alteration, licences, and late consent (paragraph 3)
| Case | Rule |
| --- | --- |
| Alteration and addition | Only the areas affected, including the affected exit routes, need to comply. The rest of the building need not be brought up to the code |
| New licence, or works in licensed premises | Same limit: the licensed area or the affected area, including affected exit routes |
| Consent for plans approved before 1 April 2012 | Generally no objection if the application is within two years of the first approval and is otherwise in order. Amended plans showing compliance with the 2011 code are submitted as necessary before the occupation permit. An occupation permit may be refused under section 21(6) if the works do not comply. Consent may be refused under section 16(3)(d) if the first approval was more than two years earlier |

**SD takeaway:** An alteration is checked only on the affected area and its exit routes, but an occupation permit for a pre-2012 approval still needs the 2011 code before occupation if consent was given under the two-year rule.
