## Regulatory Overview

This page covers **Class I** item **1.14**. Registered contractor types on the page: **A**. BD files it under: Supporting structures for a radio base station on a roof. Nature of works stated on the page: **Erection/Alteration**.

## Critical main topics and subtopics

### 1. Item gate

| Parameter | Requirement |
|---|---|
| Item no. | 1.14 |
| Item class/type | Class I Type A |
| Nature of works | Erection/Alteration |
| Result in any additional load to any cantilevered slab | No |
| Scope of works | Any supporting structure for a radio base station solely for telecommunications services in the form of an equipment cabinet |
| Location of the structure | Located on the roof of a building |
| Length of the cabinet | **Not more than 1.5m** |
| Width of the cabinet | **Not more than 1m** |
| Height of the cabinet | **Not more than 2.3m** |
