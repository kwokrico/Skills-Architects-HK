## Regulatory Overview

This page covers **Class III** item **3.54**. Registered contractor types on the page: **A**. BD files it under: Poles on a roof. Nature of works stated on the page: **Erection/Alteration**.

## Critical main topics and subtopics

### 1. Item gate

| Parameter | Requirement |
|---|---|
| Item no. | 3.54 |
| Item class/type | Class III Type A |
| Nature of works | Erection/Alteration |
| Location of the external pole | Located on a roof of a building |
| Result in any additional load to any cantilevered slab | No |
| The works involve the alteration of any other structural elements | No |
| The height of the pole, including any feature at the top | **Not more than 1.5m** |
| The weight of the pole, including any feature at the top but excluding any pedestal | **Not more than 100**kg |
| If there is **more than 1** pole on the roof, the distance between the poles | **At least 2.5m** away from each other |
| The thickness of the roof slab supporting the pole | **Not less than 150mm** |
| Other requirement | Not involve Designated Exempted Works item 19 |
