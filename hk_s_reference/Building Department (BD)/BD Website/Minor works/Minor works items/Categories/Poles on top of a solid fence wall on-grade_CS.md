### 2. Class I item 1.59 Erection

| Gate | Requirement |
|---|---|
| Not located on an unauthorised solid fence wall |  |
| The aggregate height of the wall and the pole, including any feature at its top **≤ 10m** |  |
| Height of the wall alone **≤ 2.5m** |  |

If any gate fails, item 1.59 on this card does not apply.
