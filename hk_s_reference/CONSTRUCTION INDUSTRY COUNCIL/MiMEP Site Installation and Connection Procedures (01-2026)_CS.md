# MiMEP Site Installation and Connection Procedures (01/2026)
**Architect critical summary for schematic design**
Version 01/2026 | Hong Kong Construction Industry Trade Testing Centre, Construction Industry Council

> Scope note: Site installation and joint making-good for **prefabricated single-trade modules** (water meter, fire hose reel, electricity meter), plus how BIM is used on MiMEP. The sequences also apply to MiMEP but are **not** exhaustive. Other joint types and standards are allowed. Design requirements, manufacturer rules and the project specification govern. This leaflet does not set statutory acceptance criteria.

## Regulatory Overview

MiMEP combines several building-services trades into factory-made multi-trade modules that are delivered and assembled on site so that site work is mainly connection and making-good.

The worked examples are a water-meter module, a fire-hose-reel module and an electricity-meter module, with BIM used from design through as-built and facilities management.

## Critical main topics and subtopics

### 1. What MiMEP is (機電裝備合成法)

| Term on the sheet | Meaning given |
|---|---|
| MiMEP | Multi-trade integrated Mechanical, Electrical & Plumbing |
| Module | Several services split and regrouped, mostly assembled and tested in a controlled factory, then delivered for site assembly |
| Leaflet aim | Site procedures for prefabricated services modules, and BIM, to support local prefabricated construction |

| Feature | Design implication |
|---|---|
| Modular design | Group trades into modules; most assembly and testing off site |
| Standardised production | One interface and component standard for repetition and fast site install |
| Efficient site install | Site work is connection and making-good between modules |
| BIM collaboration | Design, checking and information management in BIM to cut errors |

Cited advantages: shorter site programme and less trade overlap and waiting; less work at height; factory pre-check and test before modules leave the plant; less site noise, waste and carbon; fewer site errors and material losses; modules easier to identify and maintain later.

**SD takeaway:** Standardise module interfaces in the design. Site scope in this leaflet is the joint between modules, not the factory assembly.

### 2. Water-meter module (水錶模組現場安裝及收口接駁)

| Design / pre-install lock | Requirement |
|---|---|
| Room layout | Pipes and equipment to the drawing, the design standard and pipe-spacing rules, with maintenance space |
| Access before install | Route clear; tidy, well-ventilated work area |
| Module vs route | Module size must fit the delivery space and the width and height limits of the site hoisting route |
| Connections | Reserved pipe-connection positions standardised for fast site jointing and sealing |
| Materials | Approved by an Authorized Person (認可人士) before jointing |
| Meter room | Enough lighting for installation and later maintenance |
| Fixings | Pre-drill screw holes in the module where practicable |
| Welders | Valid gas-welding safety training certificate, and the pre-start measures from the risk assessment |

| Sequence | Action |
|---|---|
| 1 | Measure the exact position and size of the cut-out in the water-meter module bracket |
| 2 | Set out bracket position and size from the construction drawing |
| 3 | Metal-detect rebar and pipes in the concrete, then install expansion anchors (爆炸螺絲) |
| 4 | Drill at the support marks and fix the bracket |
| 5 | Install the prefabricated water-meter module in the specified position |
| 6 | Connect the floor mains; joint firm and sealed |
| 7 | Connect each unit’s branch supply and complete the system |

Water-meter crimp tools are operated with **both hands**, with cut-resistant gloves and goggles or a face shield in addition to ordinary PPE. Welding or hot-melt work needs power isolation, fire precautions and a hot-work permit. Lifting: plant in good condition with a valid certificate; operator trained and qualified; do not strike pipes or equipment; meet Waterworks Ordinance and water-meter position and size requirements. After installation, properly connect protective conductors (water pipes / conduits).

**SD takeaway:** Size the water-meter module to the delivery space and the hoisting-route width and height, standardise connection positions, and leave maintenance space and room lighting in the meter-room design.

### 3. Fire-hose-reel module (消防喉拉轆模組現場安裝及收口接駁)

| Design / pre-install lock | Requirement |
|---|---|
| Site | Enough temporary lighting and a complete set of escape signs |
| Materials | Approved by an Authorized Person (認可人士) before jointing |
| Bells and alarms | Wiring routes of automatic or manual call points and the alarm system marked in advance so they do not clash with other pipes |
| Hose-reel location | Clearly signed, with a guardrail or protective device against collision |
| Fixings | Pre-drill screw holes in the module where practicable |

| Sequence | Action |
|---|---|
| 1 | Measure the exact position and size of the bracket cut-out |
| 2 | Set out bracket position and size from the drawing |
| 3 | Metal-detect rebar and pipes, then install expansion anchors |
| 4 | Drill at the support marks and fix the bracket |
| 5 | Deliver and install the hose-reel module in the specified position |
| 6 | Install the nozzle and drum; confirm the device is complete and correctly placed |
| 7 | Complete the hose-reel supply connection |

Lifting rules match the water-meter sheet, and the lift must also satisfy the relevant fire-services legislation and hose-reel position and size requirements. Off-ground work uses a safe working platform. After installation, connect protective conductors (water pipes / conduits).

**SD takeaway:** Coordinate hose-reel position, collision protection and alarm wiring on the drawing before the module is fixed, and keep the supply connection as a separate final joint.

### 4. Electricity-meter module (電錶模組現場安裝及收口接駁)

| Working space (this sheet) | Minimum |
|---|---|
| Meter-room working width | **Not less than 600 mm** |
| Meter-room working depth | **Not less than 900 mm** |
| Clearance each side of the meter | **70 mm** |

| Other pre-install locks | Requirement |
|---|---|
| Module vs site | Size must suit the site, with enough delivery and operating space and no obstruction |
| Meter room | Enough lighting |
| Materials | Approved by an Authorized Person (認可人士) before jointing |
| Fixings | Pre-drill screw holes where practicable |
| After install | Confirm the workplace meets the safety standard, check whether circuits are isolated, and take the required precautions |
| Completion | Test and inspect as required by statute |

| Sequence | Action |
|---|---|
| 1 | Set out bracket position and size from the drawing |
| 2 | Metal-detect rebar and pipes, then install expansion anchors |
| 3 | From the survey, mark support points and support positions in the meter room |
| 4 | Drill at the support marks and fix the bracket |
| 5 | Adjust the bracket and the green setting-out lines so the runs are level and plumb |
| 6 | Place the prefabricated module in the specified position in the meter room |
| 7 | Install the rising main and the remaining trunking |

Off-ground work uses a safe platform. Lifting: avoid damaging electrical equipment. Insulating gloves are part of the PPE list on this sheet. After installation, connect protective conductors (water pipes / conduits).

**SD takeaway:** The meter room in this mock-up needs **≥600 mm** working width, **≥900 mm** depth, and **70 mm** clear each side of the meter. The last site joint is the rising main and remaining trunking.

### 5. BIM on MiMEP (建築信息模擬於機電裝備合成法的應用)

The sheet states BIM is used through design, construction and operation so that information stays connected across the project life.

| Stage | What this sheet requires |
|---|---|
| Design | 3D clash detection; find and resolve clashes early so late changes do not delay the works |
| Design | Parametric and visual design so drawings are accurate enough for team review |
| Design | Issue construction drawings **from the BIM**, so drawings do not conflict with each other |
| Construction | Check drawings against the site with BIM before installation |
| Construction | Update the model with site conditions and produce the **as-built model** |
| Construction | Use the model for progress tracking to cut omissions and rework |
| Operation | Carry design and construction data into facilities management |
| Operation | Build a database for day-to-day operation and decisions |
| Operation | Leave a base for a later digital facilities-management system |
| Operation | Locate plant and extract data from BIM for maintenance |

Illustrated chain on the sheet: BIM model → BIM module → installed product on site (hose reel shown).

**SD takeaway:** Clash-detect module interfaces in BIM before tender, issue site drawings from that model, and keep the as-built model as the FM record.
