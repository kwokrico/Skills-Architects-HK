## Regulatory Overview

This Manual guides planning, design, operation and maintenance of **stormwater** drainage works commonly built in Hong Kong — pipelines, box culverts, nullahs, river training, polders and floodwater pumping — and parts apply to natural watercourses. The fifth edition’s design-critical updates are climate-change rainfall/sea-level allowances and the blue-green drainage concept (Ch1–6, Ch13).

## Critical main topics and subtopics

### 1. Drainage reserves and outfall siting (§3.2.5)

| Rule | SD implication |
|---|---|
| Prefer **Government land** | Put public drains on statutory / town plans early; minimise private resumption |
| Location | Nullahs, culverts, pipelines in **road reserves** or designated **drainage reserves** = **non-building areas** with free construction / O&M access |
| Min reserve width | **6 m + outside diameter** of pipe **or outside width** of culvert (working space, plant access, depth, clearance to foundations) |
| Land intake | Keep to minimum; LCSD land → consult early |
| Outfall ban (HKPSG) | **No new** stormwater outfalls / nullahs into a **typhoon shelter, marina, or boat park** |

**SD takeaway:** Freeze drainage corridors before building footprints and softscape — reserve width is a lot-layout killer.

### 2. Blue-green drainage — early planning (§3.2.2)

Blue-green infrastructure reduces runoff volume, attenuates peaks, and supplements conventional drains. Consider at **early planning** of drainage and new development; co-use scarce land with other public facilities where possible.

| Type | Examples |
|---|---|
| Conveyance | Swales, conveyance channels |
| Filtration | Filter strips, filter trenches, bioretention |
| Infiltration | Soakaways, infiltration trenches/basins, rain gardens |
| Storage | Detention basins, retention ponds, geocellular storage, wetlands |
| Site SuDS | Green roofs, porous pavements, rainwater harvesting |

Natural-stream / river ecological features → AFCD + DSD **PN 1/2015**.

**SD takeaway:** Peak attenuation on site can shrink downstream pipe / culvert / reserve demand — decide before massing hardscape.

### 3. Flood protection return periods (Table 10 / §6.2, §6.6)

| System | Design return period (flood levels) |
|---|---|
| Intensively used agricultural land | **2–5 years** |
| Village drainage (incl. polder internal) | **10 years**¹ |
| Main rural catchment drainage channels | **50 years**² |
| Urban drainage **trunk** | **200 years** |
| Urban drainage **branch** | **50 years** |

Notes:  
¹ Also assess **50-year** impact — higher than 10 years may be justified.  
² Embanked channels must pass **200-year within banks**.

| Classification (§6.6.2) | Rule of thumb |
|---|---|
| Urban **branch** | Largest pipe / equiv. box diam. normally **&lt; 1.8 m** |
| Urban **trunk** | Pipe / equiv. box diam. normally **≥ 1.8 m** |

Always confirm hierarchy against the relevant **Drainage Master Plan** / DSD advice. Temporary works / diversions: no unacceptable flood-risk increase — **DSD TC No. 1/2017** (or prevailing).

**SD takeaway:** Trunk vs branch (≈1.8 m) sets which return period drives site outfall sizing and any DIA.

### 4. Freeboard and flood level definition (§6.4–6.5)

**Freeboard** = crest of embankment **or MH cover level** − design flood level.

| Component | Allowance |
|---|---|
| Bend super-elevation + wave run-up (normal, if both apply) | **200 mm** |
| Safety margin for computation inaccuracy | **≥ 300 mm** |
| Sediment thickness | **Excluded** from freeboard — use lower design bed level (§9.3) |

**Fluvial-tidal design flood** = higher of Case I / Case II (Table 11):

| T (years) | Case I (rain + sea) | Case II (rain + sea) |
|---|---|---|
| 200 | 200y + **10y** | **10y** + 200y |
| 100 | 100y + 10y | 10y + 100y |
| 50 | 50y + 10y | 10y + 50y |
| 10 | 10y + **2y** | **2y** + 10y |
| 5 | 5y + 2y | 2y + 5y |
| 2 | 2y + 2y | — |

Rule: companion sea/rain return period **X = 10** when T = 50/100/200; **X = 2** when T = 2/5/10.

**SD takeaway:** Platform levels, MH covers, and embankment crests must clear design flood **plus** freeboard — lock formation levels early on low sites and harbourfront lots.

### 5. Climate change allowances (§6.8 / Table 28)

Add to design rainfall intensities/profiles **and** extreme sea levels:

| Horizon | Rainfall increase | Sea level rise |
|---|---|---|
| Mid-21st century (2041–2060) | **+10.4%** | **+0.23 m** |
| End-21st century (2081–2100) | **+13.8%** | **+0.49 m** |

Default: design to **mid-century**; use end-century where marginal benefit exceeds cost. Check latest IPCC / authority updates.

**SD takeaway:** Do not size from historic IDF alone — mid-century uplift is the SD default.

### 6. Overland flood paths and DIA (§3.2.4 / §2.1 / §13.9)

| Issue | Requirement |
|---|---|
| Drain failure / blockage | Risk-manage; fail-safe, redundancy, and/or **safe overland flood paths** |
| High-consequence areas | NT floodplains, urban areas, old hinterland below reclamation, long steep roads, depressed roads, road/rail tunnels, pedestrian underpasses |
| Road flood paths | Channel floodwater back into drains with spare capacity ASAP; review pavement drainage vs HyD **Guidance Notes on Road Pavement Drainage Design** |
| DIA | Required for developments likely to have **significant** impact on existing drainage |
| Decking existing nullahs | **Not preferred**; if proposed → **DIA** to DSD per **ETWB TC(W) 2/2006** + DSD Advice Note No. 1; no unacceptable flood-risk increase |

**SD takeaway:** Preserve continuous overland escape routes in site grading — especially basements, underpasses, and sites behind seawalls.

### 7. Runoff for site drainage (§7.5.2)

| Item | Rule |
|---|---|
| Rational Method | Peak only: \(Q_p = 0.278\, C\, i\, A\) (A in km², i in mm/h → m³/s) |
| Max catchment without subdivide + routing | **1.5 km²** (also if gradients vary greatly) |
| Developed urban HK | Commonly **C = 1.0** |
| Design storm duration | Time of concentration \(t_c\); urban \(t_c = t_o + t_f\) |
| IDF zone (§4.3.2) | **HKO HQ** territory-wide **except** Tai Mo Shan, West Lantau, North District (own tables) |

Less-developed C (check future development will not urbanise the catchment):

| Surface | C |
|---|---|
| Asphalt | 0.70–0.95 |
| Concrete | 0.80–0.95 |
| Brick | 0.70–0.85 |
| Grassland heavy soil — flat / steep | 0.13–0.25 / 0.25–0.35 |
| Grassland sandy — flat / steep | 0.05–0.15 / 0.15–0.20 |
| Steep natural / shallow soil over rock | **0.4–0.9** |

**SD takeaway:** Urban sites default to C = 1.0; large sites need subdivided catchments — lock catchment boundaries with landscape and podium drainage early.

### 8. Buried gravity pipelines — depth and cover (§10)

| Criterion | Value |
|---|---|
| Preferred max depth | **≤ 6 m** (else consider pumping / alternatives — deep O&M is hard) |
| Min cover — carriageway | **900 mm** to top of pipe |
| Min cover — footway | **450 mm** |
| Levels at MH (§10.3) | Prefer **flush soffits** when upsizing downstream; lateral soffit **not below** main; flush inverts only if fall insufficient (e.g. reclamation) |
| Materials (§10.2) | Concrete common up to **2500 mm**; severely polluted flow → consider vitrified clay |
| Slope crest (§10.6) | Avoid pipes near crest; if unavoidable → leakage collection (GCO 1984) |

Sedimentation capacity reduction between desilting cycles (§9.3): gradient **&gt; 1 in 25** → **5%**; otherwise → **10%**.

**SD takeaway:** Keep storm drains shallow enough for O&M; deep basements that force &gt;6 m inverts need an alternative strategy before SD freeze.

### 9. Manholes (§11)

#### 9.1 Location and spacing (§11.2)

Provide at intersections, size changes, direction/gradient changes, and on straight runs:

| Pipe diam. (mm) | Max interval (m) |
|---|---|
| **&lt; 675** | **80** (reduce to **60** if frequent choke risk, busy-road dual cover lifts, or village roads inaccessible to jetting units; note also applies to ≤675 mm for that reduction) |
| **&gt; 675 and &lt; 1050** | **100** |
| **&gt; 1050** | **120** |

Position covers to minimise traffic disruption when opened.

#### 9.2 Access and geometry (§11.3–11.9)

| Element | Minimum / rule |
|---|---|
| Desilting opening | **750 × 900 mm**; on drain centreline |
| Man access | **675 × 675 mm**; with cat ladder → **750 × 900 mm** |
| Access shaft | **750 × 900 mm** |
| Working chamber | Required if MH **&gt; 1.2 m** deep |
| Intermediate platforms | If invert **&gt; 4.25 m** below cover; headroom **2–4 m**; platform ≥ **800 × 1350 mm** |
| Benching fall | **1 in 12** |
| Step-irons / ladders | 300 mm centres staggered; start ≤ **600 mm** below cover; cat ladders if &gt; **4.25 m** or frequent entry |

#### 9.3 Backdrop (§11.10)

| Rule | Detail |
|---|---|
| Trigger | Level difference **&gt; 600 mm** |
| Cascade / ramp | Preferred for drains **&gt; 450 mm** |
| Downpipe | Suitable for drains **&lt; 450 mm** (90° bend + concrete anchor; T-branch + flap) |

**SD takeaway:** MH spacing and backdrop drops drive road / landscape layout — coordinate with HyD cover positions early.

### 10. Box culverts (§12)

| Item | Constraint |
|---|---|
| Preferred cell size (plant access) | Internal **≥ 2.5 m × 2.5 m** (smaller only with maintainer agreement) |
| Access ramp | Width **≥ 3.5 m**; gradient **≤ 1 in 12** |
| Desilting / access intervals | Large / multi-cell: max **160 m**; single cell **&lt; 5 m²**: max **120 m** |
| Desilting openings | Alternate **900 × 750 mm** and multi-part **2 × 3 m** or **3 × 4 m** |
| Access shafts | **900 × 750 mm** each cell (same intervals) |
| Internal openings (multi-cell) | **≥ 2 × 2 m** at **160 m**; flush with invert |
| O&M freeboard | **≥ 500 mm** soffit − highest water under normal maintenance |
| Tidal freeboard | That water level **≥ normal high tide 2.5 mPD**; soffit preferably **≥ 2.5 mPD** |
| Grilles | ≥ **2 m upstream** of entrance |
| Concrete | Min **Grade 40**; cover XC4 **35 mm** / XS3 (Grade ≥45) **60 mm** nominal |
| Movement joints | Spacing ≤ **15 m** avoids seasonal temp crack check |

Tidal culverts: stop-log/gate provisions, seawall maintenance access, silt storage (§12.7.7).

**SD takeaway:** Culvert soffit vs **2.5 mPD** and ramp land take decide formation and waterfront massing.

### 11. Nullahs, engineered channels, decking (§13)

| Item | Constraint |
|---|---|
| Preference | **Open channels** preferred over underground (esp. tidal) |
| Trapezoidal side slopes | Typically **1:1.5 to 1:3.0** |
| Access ramps | ~**600 m** centres; width **3.5 m**; slope **1:12–1:15**; downslope with flow |
| Tidal ramp platform | At **2.5 mPD**, min **5 m × 20 m** |
| Dry-weather flow channel | Confine DWF **~80% of time**; velocity ~**0.75–1 m/s**; divert polluted DWF to sewer if possible |
| Maintenance verge | **1.6 m** clear (grassed cellular concrete) one/both banks |
| Crossing headroom | **≥ 3.5 m** |
| Staircases | ~**400 m** centres |
| Utility under-crossing | Min cover **1 m** under channel |
| Bridge soffit | Above design rainstorm water; supports out of channel if possible |
| Embankment top at estuary | Match seawall top level |
| Decking (§13.9) | **Not preferred** — prefer source control / DWF interception; if proposed → DIA |

Channel lining if velocity **&gt; ~1–2 m/s** (§13.2.1).

**SD takeaway:** Do not assume nullah decking for open space or building over — DSD will push back without a solid DIA case.

### 12. Polder and floodwater pumping (§14)

| Item | Constraint |
|---|---|
| Land (§14.2.1) | Large footprint (embankment + storage + pumps); minimise via deep tanks / underground chambers with dual-use cover |
| Embankment access | Vehicular access on top **≥ 3.5 m** wide |
| Internal drains (§14.4) | Village drainage standard (**10-year**, Table 10); enable DWF bypass of pond/pumps |
| Duty pumps (§14.6.2) | Handle **10-year** runoff inside polder |
| Storage freeboard | Desirable **300 mm** for 10-year storm |
| Standby | ≥ **30%** of duty; auto takeover |
| Duty + standby | Accommodate **50-year** storm |
| Check flood depths | **50-year** and **200-year** with duty pumps + storage |
| Generator fuel | ≥ **36 h** for all duty + standby |
| Dual-use pond | Fence; playground etc. needs evacuation measures + authority agreement |

**SD takeaway:** Low-lying NT village / polder sites need embankment + pond + pump land reserved at SD — dual-use does not remove the flood-storage volume.

### 13. Connections to existing drainage (§15.6)

| Rule | Detail |
|---|---|
| Existing capacity | Check spare capacity before connecting |
| Terminal MH | Private / gov / estate connection → **terminal MH** (DSD std dwg) **inside allocated land**, as near boundary as practicable |
| Junction type | Prefer **MH** connections; **Y-junctions only exceptional** |
| Water seal traps | For short exclusive road drains/gullies into large drains/culverts in **polluted tidal zone** |

**SD takeaway:** Fix connection point and terminal MH inside the lot near the boundary before setting building / landscape edges.

---

### 14. Trenchless works — site layout (§16)

| Item | Implication |
|---|---|
| Scope | Pipes/culverts **&lt; 3 m** diam. without open-cut |
| Man-entry | Access **≥ 1.2 m** diam.; heading typically **≥ 1.5 × 1.5 m** |
| Shafts | Jacking / receiving shafts need substantial working space (+ slurry plant); locate off traffic / major utilities |
| Alignment | Prefer permanent MH positions and maintainable lengths |
| Depth | Not for very shallow pipes; deeper preferred to clear utilities / trees |

**SD takeaway:** If open-cut through a busy road is impossible, budget shaft sites in the SD layout.
