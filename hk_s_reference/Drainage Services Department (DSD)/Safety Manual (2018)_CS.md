# Safety Manual (2018)
**Architect critical summary for schematic design**  
Drainage Services Department | Manual **2018**; Safety Policy **(2020)** incorporated (PDF Dec 2020)

> Scope note: Internal DSD safety manual for planning, design, construction, O&M, labs, tunnels and outdoor work on DSD undertakings. **Not** a substitute for Cap **59** / Cap **509**, CSSM, CoP for Fire Safety in Buildings, or FSD DG licensing. Primary SD gate: **Chapter 4** (Safety in Planning and Design) plus facility geometry in **Ch 6–7** and **Ch 9**. Sister manuals: [Sewerage Manual Pt 1](Sewerage%20Manual%20Part%201%20Key%20Planning%20Issues%20and%20Gravity%20Collection%20System%20(May%202013)_CS.md) / [Pt 2](Sewerage%20Manual%20Part%202%20Pumping%20Stations%20and%20Rising%20Mains%20(May%202013)_CS.md), [Stormwater Drainage Manual](Stormwater%20Drainage%20Manual%20Planning%2C%20Design%20and%20Management%20(January%202018)_CS.md).

## Regulatory Overview

This Manual requires hazards identified at planning/design to be **avoided first**; control measures only if unavoidable (§4.1.2). It binds DSD projects, consultants and contractors to Design for Safety / CSSM contractual regimes and sets dimensional and layout rules for safe construction and lifelong O&M of drains, STWs, pumping stations and tunnels.

## Critical main topics and subtopics

### 1. Hierarchy and consultation at planning / design (§4.1–4.2)

| Rule | Requirement |
|---|---|
| Hazard order | **Avoid** hazards in planning/design; control only if unavoidable |
| Investigation | Sufficient site inspection / GI for constraints and hazards |
| End users | Consult end-users / maintenance authority on O&M safety; **agree** detailed safety features with them |
| Phasing | Phase works to avoid concurrent conflicting activities; phased completion must allow **safe continued construction and occupation** |
| Programme | Realistic programme — rush = accident driver |
| Surroundings | Assess fire / flood / other risks **to and from** adjoining development; traffic, noise, vibration, lighting |
| Services | **Avoid** existing services rather than re-route |
| Access | Plan access/egress for large/heavy plant; review traffic impact for broad options |
| Contaminated ground | Desk study + GI for contaminated / difficult ground; establish existing foundations / previous works |
| Working space | Establish space for excavation / foundation methods; allow C&D temporary storage / sorting |

**SD takeaway:** Freeze end-user O&M safety brief and site logistics before locking massing — avoidance beats retrofit PPE.

### 2. Contractual safety gates — DfS / PFSS / ISAS (§4.4)

| Scheme | Trigger / rule |
|---|---|
| **PFSS** + CSSM Ch 3 & 12 | **All** public works contracts (incl. D&B and term) — use latest CSSM from DEVB |
| **PFSPMS** | Extension of PFSS for all public civil / E&M capital and D&B contracts adopting PFSS |
| **Design for Safety (DfS)** | Mandatory for public works with estimated construction cost **≥ $500M**, **excluding** Design & Build; effective **8 June 2016** (DEVB Guidance Notes / Worked Examples) |
| **ISAS** | Mega capital works **> $1,000M** or capital works with **unconventional** construction method (WBTC No. **32/99**) |

**SD takeaway:** At fee / procurement stage, cost ≥ **$500M** forces DfS process outputs into the design programme; > **$1,000M** / unconventional methods pull ISAS into tender docs.

### 3. Detailed design — access, EVA, excavation, roads, water (§4.3.1–4.3.6)

| Topic | Design requirement |
|---|---|
| Ventilation | Adequate ventilation (+ monitoring) for enclosed workplaces |
| Off-site fab | Prefer off-site fabrication to cut on-site duration / risk |
| Assessments | Carry out **EIA**, **TIA**, **DIA** as needed |
| Site entrance | Avoid concealed / acute-bend entrances; separate vehicle and pedestrian access where practicable |
| Phased access | Maintain unobstructed safe construction routes through phasing |
| EVA / escape | Provide for **EVA**, fire escape routes at detailed design |
| Hazardous ops | Locate away from public (e.g. site welding) |
| Excavation | Contaminated spoil handling; **surface water drainage** to stop excavation flooding; protect adjacent structures / services; specify access and **escape** in excavations |
| Roads | Minimise damage to OH/UG services; TTA to TD / HyD / Police; reduce future lane closures on busy routes; avoid peak traffic |
| Over / near water | Prefer prefabrication + cofferdams; programme for low tide; **permanent** safe access / fall-arrest for future maintenance; durable **non-slip** access; guard rails, toe boards, warning signs |

**SD takeaway:** EVA, separated access, and permanent water-edge maintenance access are schematic layout items — not finishing details.

### 4. E&M and plant rooms (§4.3.7)

| Parameter | Requirement |
|---|---|
| Plant selection | Prefer low-level plant; non-toxic / non-flammable refrigerants; avoid pressurised systems (e.g. low-temp hot water) |
| Main equipment rooms | On **outer walls** for heavy/bulky plant move-in/out |
| Layout | Space for install / operate / maintain; safe access to frequently maintained items |
| Height work | Permanent stairs / ladders / catwalks with guard rails, toe boards, **safety hoop** as appropriate; lifeline anchor points |
| Floors | Slip-resistant; routes clear of pipes/ducts |
| Prefab | Prefer bolted prefab to cut cutting/grinding and time at height |
| Guarding / vibration | Guard dangerous parts; isolate heavy plant on dampers |
| Lighting | Task-standard lighting; **emergency lighting** on escape routes and emergency plant |
| Electrical | Insulated, CB-protected, isolatable, earthed; circuit controls preferably **outside** gas-risk areas (see §7.11) |
| Sprinklers vs electrics | **No** water sprinkling near electrical equipment unless waterproof / auto shut-down before sprinkler activation |
| Cable routes | Prefer ground-level trenches / low wall mounts to cut height work |
| Lifting | Lifting beams / eye-bolts for heavy plant maintenance |
| Materials | Avoid asbestos / special-disposal materials and ignition sources near combustibles |

**SD takeaway:** Outer-wall plant rooms, permanent access hardware, and sprinkler–electrical conflict drive building section early.

### 5. Sewage treatment works and pumping stations — design rules (§4.3.8)

| Parameter | Requirement |
|---|---|
| Screens / intakes | Prefer **automatic** debris/screening removal — avoid man-entry into channels/chambers |
| Walkways | Non-slip with **handrails and toe boards** |
| Chemicals | Easy injection/dosing access; **dyke / drip pan / drainage** for spill containment; spacious **well-ventilated** handling/storage; clear labelling of stores, vessels, pipework, controls |
| Dosing pipework | **No flexible hoses** — permanent piping only |
| Confined entry | Openings sized for personnel in **breathing apparatus** where hazardous gases likely |
| Security | Boundary wall/fencing; **CCTV** and floodlights at strategic points (e.g. entrance) |
| Fire | Adequate firefighting facilities and escape routes |
| Ladders | Landings with fencing and safety hoops for considerable height |
| Manual handling | Mechanical aids for frequent tasks (screenings, polymer bags) |
| Geometry | Avoid nooks that become future **confined spaces**; avoid crevices/voids/depressions (pests / mosquito ponding) |
| Edges | Fixed or removable fencing to all free edges (roof, elevated walkway) |

**SD takeaway:** Process layout must eliminate man-entry and confined-space pockets; chemical bunding and BA-sized openings are SD room-data items.

### 6. STW / PS access, flooring and stairs — hard dimensions (§7.2)

| Parameter | Requirement |
|---|---|
| Surfaces | Even, **non-slip**, obstruction-free accesses and floors |
| Liquid vessels | Secure fencing height **≥ 1100 mm** around scalding / corrosive / poisonous liquids |
| Level changes | Mark rises/falls with yellow/black strips |
| Fall > **2 m** | Guard-rails + toe boards; top rail **900–1150 mm**; intermediate rails so unprotected gap **≤ 470 mm**; toe board **200 mm**; **no** chains/ropes/tapes as fencing |
| Roofs | Permanent access + fixed guard-rails where regular access needed |
| Stairs | Per **BS 5395-1:2010**; ≤ **16** steps per flight; landings ≥ **800 mm** wide; tread ≥ **275 mm**; riser ≤ **175 mm**; avoid ship-type ladders |
| Spiral / helical | Design to **BS 5395-2:1984** |
| Vertical ladders (≥ **2 m** fall) | Safety cage; removable safety chain at top landing |
| FRP flooring | **Forbidden** if FRP on steel beams seated on angle brackets bolted to tank walls; if used, supports must sit on **top of concrete walls / recess** |

**SD takeaway:** Stair geometry, 2 m fall protection, and FRP support detailing are fixed before GA freeze.

### 7. Lighting, ventilation, odour and plant traffic (§7.3, §7.5–7.7)

**Illuminance guide (CIBSE-aligned, §7.3.1):**

| Lux | Locations |
|---|---|
| **50** | Cable tunnels, indoor storage tanks, walkways |
| **100** | Corridors, changing rooms, storerooms, treatment process areas |
| **200** | Loading bays, switchrooms, pump houses, ST plant houses, mech plant rooms, machine halls |
| **300** | Control rooms; rough workshop work |
| **500** | Medium workshop / painting etc. |
| **1000** | Fine electronic / tool-room work |

**Air changes / hour (§7.3.2):**

| ACH | Room type |
|---|---|
| **5–10** | General workshop, plant room, toilet, wet well, dry well |
| **10–15** | Laboratories |
| **15–30** | Boiler / engine rooms, screenings chambers, grit chambers |

| Topic | Requirement |
|---|---|
| Fresh air intake | Away from exhaust / hazardous gases |
| Gas monitoring | Continuous detectors (H₂S, CO, flammable, O₂) in poorly ventilated / confined plant areas (e.g. underground screen chamber, inlet wet well) |
| Deodorisation | Maintain if EIA requires; enclose odour sources; H₂S primary odour constituent (§7.6) |
| Noise | Prefer **silent-type** machinery at design; acoustic lining where needed (§7.5.1) |
| Traffic layout | Separate vehicular / cycle / pedestrian routes; demarcate parking, loading, works areas; gates, signs, speed/height limits, road humps, mirrors, road lighting (§7.7.2–7.7.3) |

**SD takeaway:** Wet-well / grit / screen ACH and odour enclosure drive plant volume and neighbour setbacks; separate plant roads from pedestrians at masterplan.

### 8. Fire, flammables and dangerous goods (§7.8, §7.3.4, §7.25)

| Parameter | Requirement |
|---|---|
| Escape doors | Openable from inside **without key**; routes clear, signed, emergency-lit; escape maps posted; **EVA** unobstructed |
| Smoking / flame | No smoking especially in gas-risk areas; naked flame only with hot-work permit |
| Electrics in flammable areas | No sparking/hot apparatus where flammable gases expected |
| Flammables > **35 L** aggregate | Closed containers in FSD-approved storeroom |
| Flammables ≤ **35 L** | Closed containers in metal cupboard/bin at least-fire-risk position; bilingual “Flammable Substances” marking |
| Use rooms | Efficient mechanical ventilation to open air |
| DG over exempt qty | Licensed FSD DG store of correct category/class (§7.3.4, §7.25) |

**Common DG exempt quantities (examples, §7.25.1):** chlorine **nil**; diesel **2,500 L**; sodium hypochlorite **250 L**; oxygen / acetylene / compressed air **2 cylinders** each; bleaching powder **250 kg**.

**SD takeaway:** Budget FSD-licensed DG stores and flammable rooms early — chlorine has **no** exempt quantity.

### 9. Confined space and gas-risk — design to avoid (§4.3.8, §5.13–5.14, §7.10–7.11)

| Rule | Requirement |
|---|---|
| Definition | Enclosed places with foreseeable specified risk (chamber, tank, pit, well, sewer, tunnel, pipe, etc.) — Cap **59** Confined Spaces Regulation |
| Design priority | **Avoid entry** (CCTV/robots/automation); avoid future confined-space geometry |
| Entry gate | DSD **Designated** CP/CW training + permit-to-work; purge, forced ventilation, standby person, lock-out, blanking |
| Fall protection at openings | Fence entrances; gratings against objects falling into openings |
| Gas-risk areas | e.g. gas holders, digestion tanks, pipe gallery, inlet works — no smoking; Ex / intrinsically safe tools & electrics; continuous gas monitoring; prefer controls **outside** hazardous area; select per **BS EN 60079-10** |
| Height (> **2 m**) | Guard-rails: top **900–1150 mm**, intermediate **450–600 mm**, toe board ≥ **200 mm** (§5.15.2) |

**SD takeaway:** Prefer remote / automatic process access so wet wells and galleries are not routine man-entry spaces.

---

### 10. Drains, nullahs, outfalls — O&M-safe geometry (§6)

| Rule | SD implication |
|---|---|
| Man-entry = high risk | Method statement mandatory; minimise entry via CCTV/robots |
| Channels / nullahs | Safe secure access + **additional emergency egress** if sudden water rise risk; downstream arresting devices (grille / chain / grab-rope); audio-visual alarms; rescue boat / lifebuoys |
| Flow control | Lock-out coordination with upstream/downstream gates, dams, sluices |
| Outfalls | Diving under CoP for Industrial Diving; lock-out of valves/gates; welfare (shower etc.) |
| Manholes | Barriers when open; mechanical aid for covers |

**SD takeaway:** Channel and nullah designs need dual egress and rescue staging — not a single ladder.

---

### 11. Tunnels — clearances and environment (§9.1–9.2)

| Parameter | Requirement |
|---|---|
| Access | Ladders/walkways **independent** of hoists in shafts; layout diagram at each entrance |
| Loco clearance | ≥ **500 mm** between vehicles and fixed side equipment; refuges ≤ **18 m** apart where continuous clearance impossible |
| Ventilation | Alternating supply/extract as minimum; design for breathing, dilution, cooling |
| Atmosphere | O₂ **19.5–23%** by vol.; radon < **900 Bq/m³**; prefer wet-bulb < **27°C** |
| Extinguishers | **No** vaporising-liquid extinguishers in tunnels |
| Standards | Also **BS 6164:2011**; laser work per EMSD laser guidance + Designated Laser Safety Officer |

**SD takeaway:** Tunnel cross-section must include loco sway clearance and personnel refuges — size the bore early.
