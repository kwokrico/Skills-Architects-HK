## Regulatory Overview

Part 1 guides planning, design, construction, operation and maintenance of **public gravity sewerage** in Hong Kong (catchment planning through manholes, siphons, trenchless/tunnel sewers). Pumping stations and rising mains are **out of scope** — use Part 2.

---

## Critical main topics and subtopics

### 1. Land, reserves, and planting (§3.5 / §5.1.9)

| Rule | SD implication |
|---|---|
| Prefer **Government land** | Minimise private resumption; put P/S and STW sites on statutory / town plans early |
| Undeveloped areas | Sewers, rising mains, chambers in **road reserves** or designated **drainage reserves** = **non-building areas** with free O&M access |
| Drainage reserve width | Generally **3 m from both sides** of pipeline / box culvert |
| Pipe / box ≤ **600 mm** | Overall reserve may be reduced **if** future maintenance / replacement space still adequate |
| Trees | **No trees within 3 m** of either side of existing or proposed sewers |
| Softscape over sewers | Turf, plants, minor flowering shrubs OK only if roots are **not** profuse / penetrating |
| Chamber covers | **No planting within 1.5 m** around any chamber cover |
| Access | Free access to all sewerage installations at all times when planting is mature |
| Third-party landscaping | Submit planting, site formation, and structures to **DSD for prior approval** |

**SD takeaway:** Drainage reserve + 3 m tree setback are lot-layout killers — freeze sewer alignments before landscape and building footprints.

### 4. Gravity sewer design criteria (§5.1)

#### 4.1 Velocity and size

| Criterion | Value |
|---|---|
| Min self-cleanse — dia **&lt; 300 mm** (BS EN 752) | Velocity **≥ 0.7 m/s** daily, **or** gradient **≥ 1:DN** (DN in mm), assuming **2 ADWF** at least once daily |
| Min self-cleanse — dia up to **900 mm** | **1.0 m/s** in full-pipe condition |
| Max velocity at peak | **3 m/s** baseline |
| Max velocity relaxed | Up to **6 m/s** only with continuous smooth abrasion-resistant pipe / lining **and** erosion protection at junctions, bends, manholes |
| Steep ground | Prefer flatter pipe + **backdrop manholes** / steps; dedicated energy dissipators rare for sewage |
| Min pipe size | Normally **≥ 200 mm**; smaller only if O&M agents agree |

#### 4.2 Levels and alignment

| Rule | Detail |
|---|---|
| Size increases downstream | Align **soffits** at same level at manhole (avoid backwater surcharge) |
| Lateral to main | Lateral soffit **not lower** than main; equal soffits preferred |
| Depth drivers | Topography, foundations, utilities, trees/roots, min cover, construction method, life-cycle cost |
| Alignment | Check utilities early; trial holes if conflict; consult traffic authority for deep / busy / steep / single-lane roads |

#### 4.3 Septicity (§5.1.7)

Long residence + high temperature + poor air exchange + siltation → H₂S: odour, explosivity, acid corrosion (worse with saline sewage). Mitigate by shorter residence, self-cleansing, corrosion-resistant materials.

#### 4.4 Large deep sewer — avoid trigger (§5.1.8 + PN 3/2010)

| Trigger (both) | Consequence |
|---|---|
| Dia **≥ 675 mm** **and** invert **&gt; 6 m** below ground | Avoid if possible |

If unavoidable: evaluate shallower routes via intermediate pumping / local STW; plan over-pumping for maintenance; consider **twin line** if over-pumping impractical; agree O&M package with DSD per PN 3/2010.

**SD takeaway:** Deep large sewers force manhole spacing, twin corridors, and possibly intermediate P/S land — challenge before freezing basement / road levels.

### 5. Manholes (§7.1)

#### 5.1 Where required (§7.1.1)

- Intersections  
- Change of size / gradient  
- Change of direction  
- On straight runs at max intervals:

| Pipe dia (mm) | Max interval (m) |
|---|---|
| **&lt; 675** | **80** (reduce to **60** if difficult chokages, busy-road dual cover lifts, or village roads inaccessible to large jetting units) |
| **&gt; 675 and &lt; 1050** | **100** |
| **&gt; 1050** | **120** |

Large deep sewers (≥675 mm, invert &gt;6 m): closer spacing may be required — confirm with O&M at design stage. Position covers to minimise traffic disruption when opened.

#### 5.2 Geometry (§7.1.2–7.1.8)

| Element | Minimum / rule |
|---|---|
| Desilting opening | **≥ 750 × 900 mm**; on sewer centreline |
| Man access opening | **≥ 675 × 675 mm**; with ladder → **≥ 750 × 900 mm** |
| Man access position | Off centreline if deep; on centreline if manhole **&lt; 1.2 m** deep |
| Access shaft | **≥ 750 × 900 mm**; step-irons on shorter side; openings confined to **one traffic lane** |
| Working chamber | Required if depth **&gt; 1.2 m** |
| Intermediate platforms | If invert **&gt; 4.25 m** from cover; headroom **2–4 m**; platform **≥ 800 × 1350 mm** + handrail / safety chains; extra opening advised for rescue |
| Benching | ~**1 in 12** slope toward channel |
| Covers | Heavy duty if traffic / heavy load; sewer vs storm grid pattern per DSD Std Drawings |
| Step-irons / ladders | Start within **600 mm** of cover; ladders if depth **&gt; 4.25 m** or frequent entry; corrosion-resistant materials |

#### 5.3 Backdrop manholes (§7.1.9)

| Rule | Detail |
|---|---|
| When | Level difference **&gt; 600 mm** |
| Cascade | Preferred for sewers **&gt; 450 mm** |
| Downpipe | Suitable **&lt; 450 mm**; **not** for **&gt; 675 mm**; duckfoot / 90° bend at base; T-branch + flap at top |

### 6. Structures to avoid unless no alternative (§7.2–7.3)

| Device | Key constraints |
|---|---|
| **Inverted siphon** | Not recommended; min velocity **1.5 m/s**; typically **3** parallel pipes at staggered levels; desilting at inlet/outlet; grit chamber desirable |
| **Multiple pipe crossing** | Prefer diverting the obstacle; if used: total capacity ≥ original; no pipe **&lt; 300 mm**; sewer crossing **≥ 900 mm** above storm invert (or embed / re-route); control structures with desilting access |

### 8. Connections and site coordination (§8.7 / §5.1.10 / Ch. 9–10)

| Item | SD note |
|---|---|
| Connect to existing system | Check **existing capacity**; terminal manholes; provide manholes as required |
| Roadworks | Coordinate sewer works before / with new roads — avoid multi-year road-opening bans |
| Tunnel / trenchless | Land for shafts, protection of deep tunnels, and O&M access — specialist; see Ch. 9–10 + GEO rules if used |

**SD takeaway:** At schematic: confirm discharge point + capacity with DSD, draw drainage reserve / tree setbacks on the site plan, and keep manhole covers out of primary landscape and critical carriageways where possible.
