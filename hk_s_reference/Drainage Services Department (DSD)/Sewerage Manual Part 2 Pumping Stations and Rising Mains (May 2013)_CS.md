## Regulatory Overview

Part 2 covers design of **sewage pumping stations** and **rising mains** for public sewerage in Hong Kong (station types, wet-well sizing, ancillary plant, land take, surge, odour/noise, ventilation). It assumes Part 1 for catchment flow/load and gravity network rules; pumping should be **avoided or minimised** where a deep gravity alternative is practicable.

---

## Critical main topics and subtopics

### 1. When to pump and what to lock early (§1.4–1.5 / §3.1–3.2)

| Rule | SD implication |
|---|---|
| Prefer gravity | Evaluate deep gravity sewer before committing to a P/S site |
| Rising main length | Keep as **short as practicable** |
| Flow build-up | Design for initial + ultimate flow (variable speed, phased pumps, temporary diversion, septicity control) — see Part 1 Ch. 3–4 / GESF |
| Design memorandum | Required: catchment, population, scheme alternatives, criteria, major equipment, septicity/odour, commissioning conditions; consult O&M |
| Near sensitive receivers | Reliability + nuisance control: standby power/storage, standby pumps, overflow/bypass strategy, twin mains, odour/noise |
| Bypass / overflow of raw sewage | Avoid into sensitive waters **even in emergency** where possible |
| Harbourfront (GC 3/2010) | Unpleasant / incompatible facilities not supported; minimise footprint; mitigate; public access / landscape |

**SD takeaway:** P/S is a planning designation + land parcel problem first — not a late M&E add-on.

---

### 2. Station types and building form (§4.1 / §2.5)

| Type | When / form driver |
|---|---|
| **Wet well / dry well** | Large flow & high head; pumps in dry well; **superstructure** for switchgear / motors |
| Preferred dry-well drive | Motors at ground via extended shaft **or** immersible pumps — protect motors from dry-well flood |
| Direct motor in dry well | Only if flooding unlikely |
| **Submersible** | Small–medium; pumps in wet well; **no dry well** → smaller footprint |
| **Screw (Archimedean)** | Bulky civil structure; open screw needs much more land than centrifugal; enclosed screw less land than open |

---

### 3. Wet well levels, volume, retention (§4.2.3 / §10.2.7)

| Level / item | Rule |
|---|---|
| **BWL** | Duty + standby off; as low as practicable but enough submergence / NPSH (no vortex) |
| Stagnant volume | Minimise depth between BWL and wet-well floor |
| **TWL** | Duty on; volume BWL→TWL limits starts — typically **~10 starts/h** (large pumps **4–6/h**; HV motors per manufacturer) |
| Control volume (single pump) | **V = 900 Q / N** (V in litres; Q in L/s; N = starts per hour) |
| **MTWL** | Standby on; set vs upstream surcharge level |
| **Overflow / emergency bypass** | Good practice at or near **all** P/S |
| Raw sewage retention in P/S | Preferably **≤ 2 hours**; else aeration / chemical dosing / other septicity measures |
| Odour from drop into deep wet well | Prefer VFD to hold steadier level; or separate emergency storage from normal operating wet well |

**SD takeaway:** Wet-well plan depth + overflow route + emergency storage drive basement / site levels before architecture freezes.

---

### 4. Pumps, standby, twin mains (§3.4–3.5)

| Item | Rule |
|---|---|
| Duty capacity | Total duty ≥ max incoming flow |
| Standby | e.g. 1 duty → +1 equal standby; 3 duty → +1 similar standby; large stations → **≥ 2** standby |
| Early low flow | Phased install, smaller impeller, VFD, pony pump — avoid oversized early operation (surge, wear, septicity) |
| Twin / multiple rising mains | Case-by-case (risk, environment, O&M while live); prefer **both as duty** (not duty+standby) to avoid standby septicity |

---

### 5. Ancillary facilities to reserve on plan (§5 / §6.1)

Budget land and access for (as applicable):

- Screens (manual vs mechanical rake)  
- Transformer room / power supply (voltages, security of supply)  
- Standby / secure power (generator → **15–30** ACH ventilation zone)  
- Surge suppression devices  
- Flowmeter chambers  
- Lifting equipment + clear removal paths  
- Penstocks / stoplogs  
- Ventilation + **deodorization**  
- Septicity control plant  
- Emergency overflow structures  
- Slope works if required  
- **Vehicular access and parking**  
- Office / control / switchrooms (normally **air-conditioned**)

### 6. Land requirement (§6 / Table 1 / Fig. 11)

Maximum pumping capacity = total of **all** pumps including standby. Prefer a preliminary layout over curve-only estimates.

#### Centrifugal — wet well / dry well (Table 1)

| Pumping capacity (m³/s) | Area (m²) |
|---|---|
| ≤ 0.15 | **400** |
| 0.15 – 0.35 | **400 – 900** |
| 0.35 – 1.00 | **900 – 1400** |
| 1.00 – 4.50 | **1400 – 2500** |
| 4.50 – 7.50 | **2500 – 4000** |

#### Centrifugal — wet well only (Table 1)

| Pumping capacity (m³/s) | Area (m²) |
|---|---|
| ≤ 0.15 | **300** |
| 0.15 – 0.35 | **300 – 800** |
| 0.35 – 1.00 | **800 – 1200** |

#### Screw stations (§6.2)

Use preliminary layout or **Fig. 11**. Curve basis includes only inlet **manual** screens, office, transformer — **add land** for mechanical screens, staff quarters, flow measurement, deodorization, slope works, etc.

**SD takeaway:** Table 1 is a planning reservation tool; site shape, access, and odour plant often enlarge the real footprint.

### 7. Rising mains — layout constraints (§7)

| Topic | Hard / planning rule |
|---|---|
| Desirable velocity | **1–2 m/s** across duty combinations |
| Max velocity | **≤ 3 m/s** (power / economics) |
| Roughness (new) | Part 1 Table 5 rising-main values — use **‘normal’** unless justified |
| Surge | Significant for large / long mains — may need surge tanks, flywheels, valves → **extra chambers / land** |
| Discharge sump | Layout and size at receiving end — space + levels |
| Profile / valves | Air valves, vented non-return, wash-outs, isolation, access hatches |
| Thrust blocks | At bends — coordination with structures / foundations |
| Septicity | Shorten pumped length / retention; chemical / aeration if needed |
| Planting | Same as Part 1: **no trees within 3 m**; **1.5 m** clear of chamber covers |
| Exposed pipes / bridges | Leakage detection; coordinate with bridge structure |
| Along slopes / with roadworks | Access for O&M; coordinate openings with HyD timing |

### 8. Odour and noise (§10)

| Item | Rule / implication |
|---|---|
| EIAO criterion | **5 odour units**, averaging time **5 seconds** (H₂S as alternate compliance criterion acceptable) |
| Principal sources | Septic rising mains, wet wells, inlet works, screens/sludge, vents / air valves |
| Strategy order | Prevent septicity → contain → ventilate under negative pressure → abate (adsorption / absorption / biotrickling / bioscrubber) |
| Bio systems | High removal but **large footprint** for gas–liquid contact |
| Noise | NCO / TM; enclose plant, acoustic screens, separate source from receivers |

#### Table 2 — indicative ACH (UK base; HK summer prefer **×1.5 to ×2**)

| Location | Typical H₂S (ppm) | Rec. ACH |
|---|---|---|
| Pump / lift stations | 0–50 | **5–10** |
| Screening / grit / primary sed. | 50–500 | **15–30** |
| Sludge holding / thickeners | 100–1000 | **5–10** |
| Control / switchgear | 0–5 | **4–6** |

### 9. Ventilation and comfort spaces (§11.2)

| Space | Air changes / h |
|---|---|
| Storage | 1–2 |
| Offices / laboratories | 4–6 |
| Lavatories / bathrooms | 6–8 |
| Pump rooms, motor halls, dry wells, workshops | **6–10** (unmanned selectable down to **3–5**) |
| Pantries | 8–12 |
| Generator rooms | **15–30** |
| Offices / control / switchrooms | Normally **A/C** |

---

### 10. Structure and aesthetics (§8) — architect notes only

| Topic | Note |
|---|---|
| Split | Superstructure (control / office) vs liquid-retaining substructure (wet well / chambers) |
| Aesthetics | Follow DSD *Guidelines on Aesthetics Design of Pumping Station Buildings* |
| Durability | Liquid-retaining design (crack width, cover, sewage exposure) — structural engineer; Table 3 parameters |
| Flotation | Check groundwater uplift per BD foundation guidance |
| Design life (Part 1 Table 1) | Civil/building **50** yr; E&M **25** yr; rising mains **25** yr |

**SD takeaway:** At schematic — reserve P/S land from Table 1+, fix access/crane paths, overflow route, deodorization / generator plant, and 3 m tree setbacks along rising mains before landscape and adjacent buildings lock in.
