# FSD Circular Letters — Technical Design Summaries

**Scope:** Fire Services Department Circular Letters with Critical Summaries (`*_CS.md`) in this library.
**Focus:** Schematic-design constraints, FSI triggers, special risks, Cap. 502 / 572 / 636 retrofit interfaces, submission / inspection gates.
**Coverage:** 72 circular letters (one section each), assembled from individual Critical Summaries.
**Caveat:** Advisory desk reference only — many CLs supersede earlier ones; verify the current FSD Circular Letter list, Codes of Practice for Minimum Fire Service Installations and Equipment, and FS Code before submission reliance. Individual `*_CS.md` files remain the per-instrument source; this file is the scan layer.

---

## How to use

1. Start from the **topic TOC** below (not serial number) for design questions.
2. Check the **supersession map** before relying on an older CL.
3. Open the matching individual `*_CS.md` / source PDF if you need full citation text.

**Architect critical summary for schematic design**

> **Announcement circular only** — no new statutory requirements. The Guide is **general reference** (not exhaustive); consult CoP and individual CLs for compliance. ## Regulatory Overview

This circular announces publication of the FSD Practical Guide, compiling FSD Connects seminar material into a trade reference for APs, RPEs, RFSICs, and property managers on FSI lifecycle compliance. For schematic design, the Guide's value is procedural — GBP workflow, FSAR/FSMP/SCS submission checklists, and common irregularities — rather than numeric code provisions.

---

## Critical main topics and subtopics

### 1. What the Guide covers (four parts — SD-relevant index)

| Part | Chapters | SD use |
|---|---|---|
| **I — Design** | 1.1 GBP workflow (PNAP ADM-2); 1.2 GBP DOs/DON'Ts + common irregularities; 1.3 **FSAR** submission; 1.4 **FSMP** submission; 1.5 **Smoke control system** submission | **Primary SD reference** — plan-stage gates |

| **IV — Maintenance** | AI checklists; FCP/FH/HR/FAS inspection; moving parts; shutdown; FSI/314A; fire safety improvement plans; extinguisher disposal | FM briefing — not SD geometry |

### 2. Part I — design-stage SD takeaways

| Topic | Guide content (for SD) |
|---|---|

| SCS | Useful tips for smoke extraction / pressurization / VAC drawing packages |

## Critical main topics and subtopics

**Architect critical summary for schematic design**  
24 December 2001 | Fire Services Department — Licensing & Certification Command

> Part I VFA extent for DM-BFA **1997** is largely **superseded for new work by CL 2/2012** (DM-BFA 2008). Keep for legacy 1997-regime projects and for Parts II–III (TRS / water mist) still useful at SD.

---

## Regulatory Overview

This three-part circular (i) replaced CLs 10/97 and 5/99 for VFA under DM-BFA 1997, (ii) set local approval criteria for **Time Related Systems** in fire detection, and (iii) accepted **water mist** systems for limited applications subject to prior FSD approval. Part I applied to newly constructed or substantially altered buildings with first plan submission to FSD on/after **20.9.1997**.

---

## Critical main topics and subtopics

### 1. Part I — VFA (1997 Manual) — design standards

| Standard | Notes |
|---|---|
| NFPA 72 §4-4 | Red flashing lights (existing path) |
| BS 5839: Part 1:1988 Clause 9.7 | Also accepted; local criteria below |

Local BS path acceptance:

- Label **FIRE ALARM / 火警** (≥10 mm EN / ≥15 mm CHI)  
- Power: DC+battery **or** AC + emergency generator / supply before main switch  
- Red flashing; minimum **15 cd**; ≥1 VFA near every hose reel & alarm point; ≥1 per compartment; spacing ≤ **60 m** between VFAs  

**GBP:** areas of coverage only; positions on FSI drawings + FSI/314.

**1997-era waivers (overtaken by 2/2012 for new work):** club house / carpark ancillary to domestic, service apartments, student hostels on semi-permanent basis — waived then; **required under 2/2012**.

### 2. Part II — Time Related System (TRS) — management-dependent

Case-by-case FSD approval. Typical delay envelope:

| Stage | Limit |
|---|---|
| Initial delay for “investigation in progress” at panel | **1 minute** |
| Further delay | ≤ **5 minutes**, on merits |

| Design endorsement | RPE (BS / Mech) Cap 409 or manufacturer / DFS-acceptable QP |
| Works | RFSIC only |
| Initial application limit | **Mechanical plant rooms** only (project basis) |

**SD takeaway:** For new public-building VFA extent use **CL 2/2012**; use this letter for TRS/WMS strategy and legacy 1997 VFA projects.
