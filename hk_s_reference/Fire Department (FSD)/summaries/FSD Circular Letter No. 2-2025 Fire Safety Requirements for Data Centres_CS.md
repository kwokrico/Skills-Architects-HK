# FSD Circular Letter No. 2/2025 — Fire Safety Requirements for Data Centres
**Architect critical summary for schematic design**  
26 June 2025 | Fire Services Department — Fire Safety Command  
Effective **1 August 2025** for new submissions and major A&A (≥ half volume rebuild or half main-wall reconstruction / new OP).

---

## Regulatory Overview

This circular inserts a new FSI Code special risk **§4.21 Data Centres** (excluding premises with direct customer-facing retail attracting large public visitation). It defines mandatory FSI systems and extent for data-centre occupancies from 1 August 2025.

---

## Critical main topics and subtopics

### 1. Mandatory FSI schedule (§4.21)

| System | Required |
|---|---|
| Automatic actuating devices | Yes |
| Automatic fixed installation (non-water) | To areas where water undesirable |
| Emergency generator | Independent capacity for FSI + fireman's lift |
| Emergency lighting | **Entire building** + all exit routes to ground |
| Exit signs | All exit routes per staircase configuration |
| Fire alarm system | Actuating point + audio at each hose reel; visual where BFA requires |
| Fire control centre | Minimum one; more per complexity |
| Fire detection | Areas not covered by automatic fixed installations |
| Fire hydrant/hose reel | Sufficient on each floor; FH at approach lobbies; HR reach ≤ **30 m** tubing |
| Fireman's lift | Per Fire Safety in Buildings CoP |
| Portable extinguishers | As required by occupancy |
| Sprinkler | Required where total data-centre floor area **> 230 m²** — all parts including staircases, corridors, toilets |
| V/AC control | Stop mechanically induced air in designated fire compartment |

### 2. Additional lining requirements

| Location | Lining standard |
|---|---|
| Duct/concealed acoustic & thermal insulation | BS 476 Pt 7 Class 1 or 2 (or approved retardant treatment) |
| Protected means of escape linings | BS 476 Pt 7 Class 1 or 2 (acoustic, thermal, decorative) |
| Dangerous goods | Notify FSD if intended storage/use under Cap. 295 |

**SD takeaway:** Treat data halls > 230 m² as fully sprinklered special-risk compartments; coordinate generator, FCC, HR coverage and V/AC shutdown zoning at SD — not a standard office FSI package.
