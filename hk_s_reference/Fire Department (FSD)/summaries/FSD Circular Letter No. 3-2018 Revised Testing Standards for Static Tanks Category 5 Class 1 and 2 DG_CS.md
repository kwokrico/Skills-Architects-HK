# FSD Circular Letter No. 3-2018 Revised Testing Standards for Static Tanks Category 5 Class 1 and 2 DG
**Architect critical summary for schematic design**
21 December 2018 | Fire Services Department

> Scope note: Aligns leakage testing and design submission for static tanks storing Category 5 Class 1 and Class 2 dangerous goods in bulk with the standard already used for Category 5 Class 3. The testing standard does not apply to an oil storage installation under the Buildings Ordinance, or to a Category 5 Class 3 emergency-generator or emergency-power fuel tank of 500 litres or below.

## Regulatory Overview
From 1 April 2019, the revised testing standard applies to all initial licence and approval applications for static tanks storing any class of Category 5 dangerous goods. Class 1 and Class 2 tanks take the same Competent Person leakage test that FSD Circular Letter No. 7/2016 already required for Category 5 Class 3 tanks.

## Critical main topics and subtopics

### 1. Leakage test (revised standard; footnote 1)
| Item | Rule |
|---|---|
| Tanks | Static tanks for Category 5 Class 1 and Class 2 DG, same standard as Category 5 Class 3 |
| Method | Leakage test, hydraulically or pneumatically |
| Pressure | Minimum 70 kPa |
| Duration | Not less than one hour |
| Timing | Before the tank is put into commission |
| Competent Person | Registered Professional Engineer in the Marine and Naval Architecture Discipline or the Mechanical Discipline; or an Authorized Surveyor under the Merchant Shipping (Local Vessels) Ordinance (Cap. 548); or a Boiler Inspector under the Boilers and Pressure Vessels Ordinance (Cap. 56) |
| Class 3 baseline | FSD Circular Letter No. 7/2016, issued 22 December 2016 |

**SD takeaway:** Specify every Category 5 Class 1 and Class 2 bulk static tank for a 70 kPa hydraulic or pneumatic leak test lasting at least one hour, witnessed as a Competent Person test before commissioning.

### 2. Particulars submitted for licence or approval
| Submission | Content the letter requires |
|---|---|
| Full set of designs and specifications to the Director of Fire Services | Wall thickness; dimensions and volume of the tank; material used |

**SD takeaway:** Put wall thickness, internal dimensions, volume and material on the licence drawings for these tanks.

### 3. Exclusions and application date
| Case | Effect |
|---|---|
| Tank classified as an "Oil storage installation" within section 2 of the Buildings Ordinance (Cap. 123) | Testing standard in this letter does not apply |
| Fuel tank of capacity 500 litres or below storing Category 5 Class 3 DG to supply fuel to an emergency generator for any fire service installation or equipment, or for an emergency power backup facility | Testing standard in this letter does not apply |
| Initial applications for licences and/or approvals for static tanks storing all classes of Category 5 DG | Revised standard applies from 1 April 2019 |

**SD takeaway:** Keep emergency-generator and emergency-power fuel tanks that store Category 5 Class 3 at 500 litres or below outside this test; every other initial Category 5 static-tank licence from 1 April 2019 needs the 70 kPa test unless the tank is a Cap. 123 oil storage installation.
