# FSD Circular Letter No. 3/2024 — Requirements on the Use of Flexible Connectors for Connecting Single Sprinklers to Range Pipes in Sprinkler System
**Architect critical summary for schematic design**  
18 April 2024 | Fire Services Department — Licensing and Certification Command

> Amends **CL 5/2020 Technical Guidance** (TB227). Effective **1 May 2024**. Prior approval via **New Projects Division enquiry** still required before adoption.

---

## Regulatory Overview

This circular replaces the previous "not mandatory and for reference only" status of LPC Technical Bulletin **TB227.2.4–TB227.2.7** with **binding local modifications** for flexible connectors linking single sprinklers to range pipes. It supplements **CL 5/2020**, requires **prior FSD approval** via enquiry submission, and takes effect **1 May 2024**.

---

## Critical main topics and subtopics

### 1. Where flexible connectors may be used

| Rule | Detail |
|---|---|
| System type | **Wet pipe installations only** |
| Hazard | Up to **OH Group 3** |
| Movement | Where **relative movement** between pipe ends is expected |
| Prior approval | **Director of Fire Services** approval required (enquiry to **New Projects Division**) |
| Location | **Accessible** locations where inspection is permissible |

### 2. Installation constraints (SD coordination)

| Item | Requirement |
|---|---|
| Support | Every termination supported by **supplier-certified bracket assembly**; RFSIC certifies compliance with manufacturer recommendations |
| Configuration | Must comply with **figure TB227.F1**; other layouts per manufacturer |
| TB227.2.4.1 sentence 2 | **Not applied locally** (product acceptance via FSD accepted-type regime instead) |
| TB227.2.6–2.7 | Remain **reference only** |

**SD takeaway:** Do not assume flexible drops in concealed/soffit zones — **access + prior FSD approval** are mandatory. Coordinate ceiling layout and inspection hatches with sprinkler specialist early.
