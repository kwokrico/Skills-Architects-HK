# FSD Circular Letter No. 4/1996 — Consolidated FSD Circular Letters 1996
**Architect critical summary for schematic design**  
22 October 1996 | Fire Services Department — Fire Safety Command

> **150-page consolidated archive** (Parts I–XI). This summary covers **SD spatial/provision gates** only — plan submission, smoke-control annotation, basement triggers, MTR adjacency, and **historical EVA** (Part X ¶5–6 **deleted** by CL **4/2005**; size EVA from **MoA Code / B(P)R 41D**). Many topics now live in Minimum FSI CoP — use this CL for **submission practice** and **plan-check fault lists**.

---

## Regulatory Overview

This letter consolidates FSD circular guidance issued since 1987 into eleven parts covering plans, sprinklers, product lists, smoke extraction, inspections, electrical supplies, and miscellaneous building fire topics. For schematic design, **Part I (Plans)** and selected **Part X** provisions remain the primary gates for what must appear on GBP/FSI drawings and what triggers enhanced basement or adjacency controls.

---

## Critical main topics and subtopics

### 1. GBP / FSI plan submission chain (Part I ¶1–3)

| Step | Requirement |
|---|---|
| Route | All plans to **Building Authority** under PNAP:30; covering letter **copied to FSD** |
| FSD vetting | Two GBP sets passed to FSD under BO **s.16(1)(b)** |
| FSI/314 | Dual certification: AP (identical to FSD-held GBP) + FSIC/Consultant (CoP-compliant specs) |
| FSD chop | Receipt stamp **≠ approval**; detailed check on sample basis |
| FS 172 gate | No initial inspection without **chopped FSI plans + FSI/501** |

**SD takeaway:** Lock FS Notes to approved GBP before FSI/314; budget messenger collection of vetted plans from FSD HQ.

### 2. Site / block plan annotations (Part I ¶2)

| Item | Show on site plan |
|---|---|
| Surrounding streets/roads | Yes |
| Lot number | Yes |
| Adjacent gov/public/church/school | Yes |
| North arrow | Yes |
| Rural location reference | Milestone or equivalent |

### 3. FSI plan annotation — general (Part I ¶3.6)

| Topic | SD constraint |
|---|---|
| Scale | ≥ **1:100** (1:200 if very extensive) |
| Construction | Partition/party walls distinct from pipework |
| Pipe colours | Standard colour code by diameter (20–200 mm) + legend |
| Sprinkler | Head spacing, pipe sizes, water supply, **sections/elevations** for pipe-ranges |
| Detection | Detector spacing/locations, annunciator positions |
| Gas fixed systems | Compartment volume, concentration, medium qty, actuation, isometric |
| Water fixed systems | Protected area, head positions, discharge rate, sections/elevations |

### 4. Smoke control plan annotation (Part I ¶3.7) — **primary SD gate**

| General (¶3.7.1) | Requirement |
|---|---|
| Units | **SI metric only** (no CGS) |
| Sheet size | Preferred **A0–A4**; avoid > A0 |
| Copies | **Duplicate** submission |
| Compartmentation | Show FRP per approved GBP |
| Microfilm | BS 5536 — matt surface, line weights, min lettering heights |

| Drawing scales (¶3.7.3.5) | Min ratio |
|---|---|
| Block plan | 1:500 |
| Layout plan | 1:100 |
| Sections | 1:100 or 1:50 |
| Plant details | 1:50 or 1:20 |

| VAC control drawing (¶3.7.2) | Show |
|---|---|
| Fans to trip | Location, capacity, trip method |
| Manual stop | Location |
| Schematic | Air-side arrangement; **trip fans coloured** |

| Smoke extraction / SPS extras (¶3.7.3) | Show |
|---|---|
| Authorship | Designer/consultant name, signature per sheet |
| Amendments | Dated, progressive clouding/summary |
| Duct colouring | One copy coloured per DW142 / BS 4800 (supply red, exhaust light blue, **smoke extraction brown**, makeup light green, fire-resisting enclosure yellow/red) |
| Dampers | Distinct symbols: F.D.(T/E/TM/TP), S.D.(M/P/S), S.F.D.; access door + airflow direction |
| Devices | Sail switches, pressure switches, smoke detectors, withdrawal clearances |
| Submitter | **Architect/Consultant** — FSD may refuse contractor-only or split-consultant submissions without owner consent |

**SD takeaway:** Treat smoke-control package as a **separate coloured drawing set** at SD; coordinate damper IDs with FS Code / FRC compartment lines early.

### 5. Basement plans — occupancy & enhanced FSI (Part I ¶5)

| Rule | Trigger / requirement |
|---|---|
| Occupancy | Defined on plan; **no change without FSD consent** |
| Access | Ready, separated access to each level |
| Sprinklers | **Fast-response heads** |
| ≥3 basement levels or industrial basement | Individual consideration — typically: |
| | MoA **firefighting & rescue stairway** |
| | **Dynamic smoke extraction** per basement level except carpark-only areas |
| | Loading/unloading **≠ carpark** — extraction still required |

**SD takeaway:** Three-level basement or industrial use = flag **enhanced FSI + rescue stair + dynamic SES** at massing.

### 6. MTR vent shaft adjacency (Part I ¶6) — layout buffer

| Guideline | Distance |
|---|---|
| Default | MTR vent opening ≥ **5 m** from any building opening (windows, doors, intakes/exhausts) |
| Reduced | **2.5 m** if exhaust directed away and unlikely to affect opening by natural convection |
| Determination | Clearance fixed at **GBP submission** to BD |

### 7. Common GBP faults — architect checklist (Part I ¶7)

| Category | Frequent omissions |
|---|---|
| General | EVA non-compliance (historical Pt X ¶5), missing FS legend/notes, no FCC, no emergency generator, door/shutter FRP not marked, compartment occupancy not stated |
| FH/HR | Coverage gaps, poor siting, inadequate water quantity |
| Sprinkler | Tank capacity, inlet location, annunciator panel |
| Detection | Detector type not specified for sleeping risk |
| Fireman's lift | MoA Part IV zoning, lobby discharge, loading/size per MoA ¶10/12 |

**SD takeaway:** Use ¶7 as a **GBP QA list** before first FSD submission.

### 8. EVA — Part X ¶5–6 (**superseded for new work**)

| Status | Note |
|---|---|
| **Deleted** | CL **4/2005** removes Pt X ¶5 + Appendices A–E for new buildings from **31.12.2004** |
| Still referenced | **EVA plan submission** practice (two copies with FSI/501 if designated EVA ≠ public road) per CL 4/2005 cross-ref |
| Historical content | 6 m carriageway, 30 m hose-run / pumping appliance reach, EVA signage at 50–100 m intervals — **archive only** |

**SD takeaway:** Do **not** design new EVA from this 1996 Part X; use **MoA Code Part VI** + existing CL **4/2005** summary. Retain ¶3.7 smoke-control rules — still current practice for SCS submissions.

### 9. Other Part X SD hooks (still useful at planning)

| Topic | Constraint |
|---|---|
| Transformers | Type-specific room location, ventilation, lobby, basement independent escape |
| Linking buildings | Roller shutter / fire door at connections; smoke-detector actuation preferred |
| Private street hydrants | ≥2 on site, ≥6 m from building; 100 m staggered spacing [verify spacing in CoP if designing now] |
| PFS in industrial/carpark podium | 4 hr separation, buffer floor, remote stairs, full sprinklers, blank wall 3 levels above |
