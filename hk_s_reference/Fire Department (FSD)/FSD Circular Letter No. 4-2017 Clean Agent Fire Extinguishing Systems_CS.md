# FSD Circular Letter No. 4/2017 — Clean Agent Fire Extinguishing Systems
**Architect critical summary for schematic design**  
1 December 2017 | Fire Services Department — Licensing and Certification Command

> Revises **CL 4/96 Part VIII** Pages VIII.5–VIII.9 + Appendices A–E. Supersedes **CL 12/97**. Effective **30 May 2018**. Read with **Ozone Layer Protection Ordinance (Cap. 403)** and **CL 1/2022** (enclosure integrity).

---

## Regulatory Overview

This circular updates clean-agent and related gaseous extinguishing requirements following tighter ozone-depleting agent controls under the **Ozone Layer Protection Ordinance (Cap. 403)**, withdrawing HCFC-based agents from new fixed installations. NFPA 2001-listed agents such as **Novec 1230**, **FM200**, **Inergen**, **FE-13** and **FE-36** are accepted, with revised identification symbols/labels replacing CL 4/96 Part VIII and superseding CL 12/97 from **30 May 2018**.

---

## Critical main topics and subtopics

### 1. Agents — new vs withdrawn (SD specification)

| Status | Agents |
|---|---|
| **Accepted clean agents** (auto total flooding / fixed sprayer) | FK-5-1-12, HFC-227ea, IG-541, HFC-23, HFC-236fa; other NFPA 2001 agents without scheduled substances |
| **Withdrawn from new fixed installations** | HCFC Blend A (NAFS-III), HCFC-123 (FE-232), HCFC-124 (FE-241), PFB (CEA-410) |
| **Existing halon modular** | BTM (Halon 1301) per NFPA 12A; BCF (Halon 1211) per NFPA 12B — existing buildings only |

### 2. System types and submission

| System | Standard / action |
|---|---|
| Auto total flooding | **NFPA 2001** + FPN 15 listed/approved types |
| Fixed sprayer units | FK-5-1-12 or HFC-227ea alternatives to withdrawn HCFC units; volumes per **Government Gazette** |
| Existing buildings (total flooding or sprayer) | **Layout plans to FSD before installation** |
| Portable Class B/electric | HFC-227ea or HFC-236fa replaces BCF extinguishers |

### 3. Identification labels (architectural coordination)

| Requirement | Detail |
|---|---|
| Location | **On or near entrance door** to protected premises |
| Design | Per Appendices **B–E** (agent-specific bilingual labels, e.g. FM200, Inergen, Novec 1230) |
| Existing HCFC/ PFB systems | Retain **Appendix C/D** legacy labels until decommissioned |
| CO₂ symbol replacement | Use **Appendix B** label (not old Appendix A symbol) |

**SD takeaway:** Server rooms, archives and special risks using gas flooding need **door signage zone + agent selection** at SD — banned ozone-depleting agents cannot be specified for new work; confirm **NFPA 2001 listed** product and **CL 1/2022** room integrity testing pathway.
