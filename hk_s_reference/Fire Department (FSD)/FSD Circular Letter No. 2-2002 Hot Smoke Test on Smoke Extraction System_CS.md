# FSD Circular Letter No. 2/2002 — Hot Smoke Test on Smoke Extraction System
**Architect critical summary for schematic design**  
18 November 2002 | Fire Services Department — Licensing and Certification Command

> Acceptance test regime for smoke extraction. Requirement imposed **case-by-case** by FSD New Projects Division when plans involve qualifying compartments. **Immediate effect** from issue date.

---

## Regulatory Overview

This circular allows FSD to require a **hot smoke acceptance test** to verify smoke extraction performance, with standards in the appendix. The requirement is stipulated together with the smoke extraction approval when NPD considers it necessary for compartments meeting the trigger criteria.

---

## Critical main topics and subtopics

### 1. When hot smoke test may be required

| Trigger compartment | Test may be required |
|---|---|
| Headroom **≥ 12 m** | **Yes** |
| **Irregular geometry** or **extraordinarily large** compartment | **Yes** |

**SD takeaway:** Atria, halls and large irregular volumes need **smoke modelling + test budget** in programme — confirm with FSD at GBP whether hot smoke test will be mandated.

### 2. Test parameters (appendix summary)

| Item | Standard |
|---|---|
| Plume temperature | **~10 °C below** ceiling sprinkler temperature rating |
| Fire size | **≥ 1 MW** or as agreed by DFS |
| Fuel/smoke | Methylated spirit and/or non-toxic oil smoke — **DFS agreement** |
| Reference standard | **AS 4391-1999** or equivalent |

### 3. Pass criteria (design must deliver)

| Criterion | Detail |
|---|---|
| Clear height | Designed smoke clear height maintained |
| Air flow pattern | Low-level make-up + high-level extract with **"scouring"** through compartment; make-up must not destabilize smoke layer |
| Actuation | System responds promptly to fire alarm |
| Adjacent spaces | No significant smoke spread to adjoining compartments |
| Smoke curtains | Deflection within design limit |
| Stagnant corners | No significant smoke below layer |
| Re-entry | No smoke re-entry via openings / fresh-air intakes |

**SD takeaway:** Size **make-up air paths, extract positions and curtain geometry** for scouring flow — not just code-minimum exhaust CFM.
