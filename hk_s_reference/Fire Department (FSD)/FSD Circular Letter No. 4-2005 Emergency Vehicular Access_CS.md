# FSD Circular Letter No. 4/2005 — Emergency Vehicular Access
**Architect critical summary for schematic design**  
15 August 2005 | Fire Services Department — Fire Safety Command

> Read with: B(P)R **41D**; Code of Practice for Means of Access for Firefighting and Rescue (**MoA Code**) Part VI; PNAP APP-136. This CL **deletes** Paragraph 5 + Appendices A–E of Part X of FSD CL **4/1996** (old appliance-access rules).

---

## Regulatory Overview

This circular confirms that, from **31.12.2004**, every new building on virgin and redevelopment sites must provide **Emergency Vehicular Access (EVA)** under B(P)R **41D**, with design/construction to **MoA Code Part VI**. FSD no longer sets the EVA geometric standard; the Building Authority owns compliance, and FSD advises as the user of the EVA.

---

## Critical main topics and subtopics

### 1. Who owns EVA — BA vs FSD

| Role | Responsibility |
|---|---|
| **Building Authority** | Statutory EVA provision under B(P)R 41D |
| **MoA Code Part VI** | Design & construction standards; meeting MoA = deemed compliance with 41D(2) |
| **FSD** | User advice only; still receives EVA plans for comment |

**SD takeaway:** Size EVA from **MoA Code / FS Code Part D**, not from obsolete FSD CL 4/96 appliance tables.

### 2. What this CL kills in the archive

- **Delete** for new work: FSD CL **4/1996** Part X ¶5 and Appendices **A–E** (access for fire appliances).
- Those appliance-access rules are **no longer applicable** once B(P)R 41D / MoA Part VI apply.

### 3. Submission still required to FSD

AP must still submit **two copies of each EVA plan** to FSD under ¶1.2, Part VI of FSD CL **4/1996** (that submission practice is **unchanged** by this letter).

**SD takeaway:** Budget EVA geometry + dual plan sets (BD + FSD) at massing; do not wait for GBP day to discover setback / hardstand / turning failures.
