# Town Planning Board Guidelines Index (English)

**Issued by:** Town Planning Board
**Scope:** 31 English guidelines in this library, from PG-No. 5A to PG-No. 43A. Numbers that are not in `source_reference/` are not in this index. This library was not checked against the live Town Planning Board website.
**How to use:** The number links to the critical summary in `summaries/`. Because the PDF filename is not the same as the summary filename, the same cell also links the PDF in `source_reference/`.
**Titles:** The official title is the cover heading, without the words “Town Planning Board Guidelines”.
**Caveat:** Desk reference only. Before a submission, check the current guideline, the outline zoning plan, and the lease.
