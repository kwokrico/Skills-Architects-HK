# BEAM Plus Assessment Tools — Architect Critical Summary
**Schematic design constraints across the BEAM Plus tool family**  
Sources: HKGBC brochures — New Buildings V2.0; Existing Buildings V2.0; Neighbourhood; Interiors Non-Residential v2.0 (27.11.2023); Interiors Residential (27.11.2023); Existing Schools V1.0; Data Centres (NDC/EDC); Existing Buildings Global V1.0 (30.08.2024)

> Scope note: BEAM Plus is a **voluntary third-party green building rating system** (HKGBC = certification body; BEAM Society Limited = assessment body). It is **not** a Buildings Ordinance / BEC / FS Code substitute. At SD, pick the **correct tool for project stage and typology first** — wrong tool = wasted credits and missed early-design decisions (orientation, separation, MEP plant, envelope, water strategy, public realm).

---

## Regulatory Overview

BEAM Plus covers **Hong Kong new construction (including demolition–planning–design–construction–commissioning), major renovation / A&A / wholesale or partial conversion, existing-building management–operation–maintenance–improvement, neighbourhood masterplanning / inception, non-residential and residential fit-outs, existing primary and secondary schools, data centres (≥500 m² with halls + plant as majority area), and (Global Version) overseas existing buildings**. Rating is by weighted performance aspects plus prerequisites (where applicable); most Final certificates last **five years**, after which owners are steered to the next lifecycle tool (Neighbourhood → NB → EB; NDC → EDC; Interiors renew at 5 years).

For architects at schematic design: freeze **target grade + tool + scheme (Comprehensive vs Selective)** before massing, envelope, plant location, and public-realm layout are locked — Energy Use dominates most tools (often ~24–40%), and many credits are **design-irrecoverable** after GA freeze.

## Critical main topics and subtopics

### 0. Tool selector — lock this before SD massing

| Project situation | Use this tool | Do **not** use instead |
|---|---|---|
| New build / major renovation / A&A / wholesale or partial conversion | **New Buildings (NB) V2.0** | EB alone; Interiors alone |
| Masterplan / early inception / space between buildings / public realm | **Neighbourhood (ND)** first → then NB | Jumping to NB without public-realm / socio-economic strategy |
| Operating building of any age/type (commercial, educational, government, industrial, office, residential, hotel, shopping centre…) | **Existing Buildings (EB) V2.0** | NB (unless works qualify as major A&A / conversion) |
| Existing **primary / secondary school** — O&M **plus** education / behavioural change | **Existing Schools (ES) V1.0** | Generic EB if school-specific SLL / HCH credits are the brief |
| Commercial / institutional **fit-out** (office, retail, restaurant, clubhouse, industrial unit, other NR) | **Interiors — Non-Residential v2.0** | Whole-building NB / EB |
| Home / flat **fit-out** | **Interiors — Residential** | BI Non-Residential score table |
| Data centre new build / major A&A | **New Data Centres (NDC)** | Generic NB if DC-specific EU best-practice credits are required |
| Data centre in operation | **Existing Data Centres (EDC)** | Generic EB |
| Existing building **outside Hong Kong** (Macau, Mainland China, SE Asia, Belt & Road, Europe, elsewhere) | **EB Global V1.0** | Local EB V2.0 baselines without climate-adjusted energy baseline |

**Hard gates / SD kill switches**
- Neighbourhood cert ≠ NB cert — must reassess when design moves to building / construction stage
- NB Final → renew via **EB** after 5 years; NDC → **EDC** after 5 years
- Interiors / EB / EDC / ES / NDC certificates typically **expire at 5 years** (EB Comprehensive Scheme B first intermediate certificate: **3 years**)
- Data centre assessed area **≥ 500 m²**; data halls (IT racks) + related plant = **significant majority** of floor area
- Existing Schools: **≥ 1 school calendar year** of operational data before registration
- EB / EDC Selective: **Innovations (IA) not applicable**
- EDC Selective: **Energy Use + Management are mandatory** (unlike conventional EB Selective)
- Credit pool under NB **varies by project type** — confirm with BEAM Pro before SD credit map
- Appoint / consult **BEAM Pro** before registration (explicitly stated for Data Centres; good practice for all tools)

### 1. New Buildings (NB) V2.0 — design-stage whole building

#### 1.1 Scope & lifecycle coverage
- **In:** all new building types — residential, commercial, industrial, community facilities, infrastructure; from small single buildings to large developments
- **Also in:** major refurbishment, alterations & additions, wholesale or partial conversion
- **Lifecycle covered:** demolition, planning, design, construction, commissioning
- **Purpose:** affordable best practices → reduce environmental impact, improve environmental quality, enhance user satisfaction
- **Typology note:** commercial, residential, community, infrastructure and more are all eligible — browse certified stock at BEAM Plus Online Exhibition

#### 1.2 What success buys (design brief drivers)
- Better indoor environment → health, wellbeing, productivity
- Less pollution to the external environment
- Energy-efficient buildings, systems and equipment, including renewables
- Lower unsustainable consumption of scarce resources (**water**, **tropical timber**)
- More cost-effective sustainable design and process

#### 1.3 V2.0 upgrade features (why SD process changes)
| Theme | What changed | Architect action at SD |
|---|---|---|
| **More human-centric** | Aspect rebranded to **Health & Wellbeing**; new healthy-living credits | Programme dual-aspect / daylight / inclusive design early — not as Fit-out late add |
| **More integrated green design** | New aspect **IDCM** added | Run integrated design workshops with AP / RSE / BS / landscape / BEAM Pro from concept |
| **More adaptable, certain, practicable** | Every credit reviewed; manual redesigned for clearer guidance | Use current Assessment Manual credit language — do not rely on old NB v1.x credit maps |

#### 1.4 Seven aspects — full subtopics & weights

| Aspect | Weight | Subtopics (brochure) | SD freeze items |
|---|---|---|---|
| **Energy Use (EU)** | **~29%** | Energy use reduction & control; renewable & alternative energy generation; energy-efficient equipment | Envelope / glazing / roof path; HVAC concept; metering & control; PV / alternative energy area & structure |
| **Integrated Design & Construction Management (IDCM)** | **~22%** | Integrated Design Process; Green Construction Practices; Smart Design and Technologies | Team process plan; C&D waste / site green plan; smart systems architecture |
| **Health & Wellbeing (HWB)** | **~18%** | Design for green living; Inclusive design; Indoor environmental quality | Unit mix / dual aspect; BFA beyond DMBA; daylight, ventilation, acoustics, thermal strategy |
| **Sustainable Sites (SS)** | **~15%** | Neighbourhood integration; Ecological responsive design; Bioclimatic building design; Climate resilience & adaptability | Massing vs neighbours; ecology / tree; bioclimatic form; flood / typhoon / heat resilience |
| **Materials & Waste (MW)** | **~9%** | Materials use; Green products & materials; Waste reduction | Spec: timber policy, recycled content, low-impact products; demolition / C&D diversion targets |
| **Water Use (WU)** | **~7%** | Water conservation; Effluent discharges; Rainwater harvesting & grey water recycling | Fixture flow rates; plant / tank / riser space for rainwater & greywater |
| **Innovations & Additions (IA)** | Bonus (outside base pie) | Innovative technology and techniques | Only claim if performance truly beyond baseline credits |

**Weight reality check:** EU + IDCM + HWB ≈ **69%** — treat BEAM as a core SD driver, not a late green add-on.

#### 1.5 Rating gates (Final Assessment)
Overall rating = weighted % of applicable credits gained under each aspect.

| Rating | Overall score | Min % of applicable credits **in each aspect** |
|---|---|---|
| Platinum | ≥ 75 | ≥ 20% |
| Gold | ≥ 65 | ≥ 20% |
| Silver | ≥ 55 | ≥ 20% |
| Bronze | ≥ 40 | ≥ 20% |

- All **applicable prerequisites in all aspects** must be achieved
- Met all prerequisites but below Bronze threshold → **“Prerequisites Achieved”** (not a grade)
- **FA Certificate valid 5 years** → then pursue **Existing Buildings** for ongoing performance

### 2. Neighbourhood (ND) — masterplan / inception only

#### 2.1 What counts as a “neighbourhood” in HK
Scale can be any of:
- Stand-alone high-rise with several hundred households
- Large multi-tower development
- Couple of low-rise houses

Tool is for **new or planned** developments; designed for that scale/typology variation.

#### 2.2 Why use it at inception (proponent opportunities)
- Demonstrate commitment to **urban sustainability**
- Create sustainable neighbourhood with **vibrant public realm**
- Save resources long-term via **early effective planning**
- Engage community and key stakeholders
- Promote project via third-party verification

**Core philosophy:** assess sustainability at early / inception stage; lay urban-sustainability framework for later stages; design the **space between buildings**; emphasise **socio-economic** elements.

#### 2.3 Three design emphases
| Emphasis | Intent | SD implication |
|---|---|---|
| **Space between buildings** | Start public-realm planning at the beginning of development | POS, streets, voids, podium open space are first-order geometry — not leftover |
| **Socio-economic elements** | New **Community Aspects** aspect forces holistic view | Engagement, lifestyle, placemaking, CSR reporting are credit-bearing |
| **Be a good neighbour** | Positive impact on occupants **and** immediate neighbours | Wind permeability, visual link, deferred POS closure, shared amenities |

#### 2.4 Seven aspects — full subtopics & weights

| Aspect | Weight | Subtopics |
|---|---|---|
| **Site Aspects (SA)** | **25%** | Neighbourhood amenities; Pedestrian-oriented & low-carbon transport; Ecological value & cultural heritage; Quality Open Space |
| **Community Aspects (CA)** | **20%** | Community engagement; Sustainable lifestyle; Placemaking & local character; CSR Reporting |
| **Outdoor Environmental Quality (OEQ)** | **20%** | Outdoor thermal comfort & urban heat island; Daylight access & visual quality; Acoustics & air quality of open space |
| **Energy Aspects (EA)** | **16%** | Sustainable buildings & passive design; Energy-efficient infrastructure |
| **Materials & Waste Aspects (MWA)** | **10%** | Minimised cut & fill; Integrated waste management |
| **Water Aspects (WA)** | **9%** | Water environment & stormwater management; Alternative water sources |
| **Innovations & Additions (IA)** | Credits (not % weight) | Innovative techniques; Performance enhancements |

#### 2.5 Rating gates
| Rating | Overall | CA min | SA / EA / OEQ min | IA credits |
|---|---|---|---|---|
| Platinum | ≥ 75 | ≥ 70% | ≥ 50% | ≥ 3 |
| Gold | ≥ 65 | ≥ 60% | ≥ 40% | ≥ 2 |
| Silver | ≥ 55 | ≥ 50% | ≥ 30% | ≥ 1 |
| Bronze | ≥ 40 | ≥ 40% | ≥ 20% | — |

- All applicable prerequisites in all aspects required
- Certificate valid **up to 5 years**
- After Neighbourhood → register **NB** when project moves from planning to implementation (building design / construction)
- Later lifecycle: NB → EB (post-construction & operation)

#### 2.6 Pilot design moves to copy at SD

**Fat Tseung Street West Subsidised Sale Flats (41-storey, 811 flats)**
- L-shaped block on southern portion of site
- **3-storey-high void** at main entrance → wind permeability + visual link
- Block disposition enables **deferred closure** of existing playground → minimise disruption to public services
- Site abuts public roads on three sides; **vehicular access segregated** from pedestrian route
- Covered walkway → vehicle-free external areas
- Footbridge + lift tower at main entrance → POS, retail, community facilities, covered pedestrian network, transport hubs (NW Kowloon Reclamation Site 6)

**EMSD Headquarters transformation (ex–air cargo terminal)**
- First existing building converted to **district cooling** showcase
- Revamp Education Path → sustainable lifestyle for public
- Piazza / outer area → staff + public recreation; quality landscape + ecological enhancement → ecological value + **UHI reduction**
- Pedestrian-oriented transport planning + renewables for energy-efficiency promotion

**West Kowloon Cultural District (40 ha reclamation)**
- **23 ha** public open space + **2 km** harbourfront promenade
- Phased venue delivery around integrated basement — public realm continuity across phases is a masterplan credit risk if ignored

### 3. Existing Buildings (EB) V2.0 — O&M performance

#### 3.1 Scope
- Measures **actual performance** + facility management practices
- Covers management, operation, maintenance, **improvement**
- Can start **any time** during operational life
- **All types, all ages:** commercial, educational, government, industrial, office, residential, hotels, shopping centres, etc.
- Assessment = areas under **applicant control**
- **Tenant involvement** → additional / bonus credits (tenants are critical to long-term environmental performance)
- Policy driver: support Government **Energy Saving Plan** targets (brochure cites 2025); aim to pull in ~**42,000** existing HK buildings via more flexible V2.0 rules

#### 3.2 Benefits (client / FM brief)
- Implement initiatives that improve energy efficiency & environmental performance
- Enhance performance of buildings of all ages
- Flexibly achieve certification matching building conditions
- Contribute to Energy Saving Plan targets

#### 3.3 Scheme choice (registration decision)

| Scheme | Mechanism | Best for |
|---|---|---|
| **Comprehensive Scheme A** | One-step — assess **all** aspects | NB-certified buildings; full upgrade push |
| **Comprehensive Scheme B** | Step-wise — assess some aspects → **intermediate result** → finish remaining aspects **within 3 years** | Budget / programme constrained |
| **Selective Scheme** | Any one or more aspects; **certificate per aspect**; **no prerequisites**; lower threshold | Partial capability; EU-only funding path |

```
Comp A:  [all aspects] ──────────────────► Comprehensive Certificate
Comp B:  [some aspects] → intermediate → [remaining ≤3 yrs] → Comprehensive Certificate
Selective: [chosen aspect(s)] ───────────► Selective Certificate(s) per aspect
```

**Funding flag:** Registration under **Comprehensive** **or** Selective **Energy Use (EU)** may contribute to higher priority for **CLP Eco Building Fund** or **HK Electric Smart Power Fund**.

#### 3.4 Aspects — full subtopics & weights (Comprehensive)

| Aspect | ~Weight | Subtopics |
|---|---|---|
| **Management (MAN)** | **~24%** | Green procurement; Health, safety & environmental management; ESG disclosure; Cleaning & pest control; **Green lease** |
| **Energy Use (EU)** | **~24%** | Annual CO₂ emissions or energy use; Energy-efficient systems & equipment; Energy management; **Retro-Commissioning** |
| **Site Aspects (SA)** | **~14%** | Location & design of the building; Emissions from the site; Greenery & site amenities; Building amenities |
| **Water Use (WU)** | **~14%** | Water audit; Water conservation; Effluent discharges |
| **Indoor Environmental Quality (IEQ)** | **~14%** | Safety, hygiene, IAQ & ventilation, thermal comfort, lighting, acoustics & noise |
| **Materials & Waste Aspects (MWA)** | **~10%** | Green purchasing; Waste disposal & recycling |
| **Innovations & Additions (IA)** | — | Performance gains from innovative design solutions — **N/A under Selective Scheme** |

- Comprehensive = overall performance by aspect weighting
- Selective = individual aspect assessment only

#### 3.5 Comprehensive rating gates
| Rating | Overall | MAN & EU min | SA / MWA / WU / IEQ min |
|---|---|---|---|
| Platinum | ≥ 75 | ≥ 70% | ≥ 50% |
| Gold | ≥ 65 | ≥ 60% | ≥ 40% |
| Silver | ≥ 55 | ≥ 50% | ≥ 30% |
| Bronze | ≥ 40 | ≥ 40% | ≥ 20% |

All applicable prerequisites in all aspects required (Comprehensive).

#### 3.6 Selective grades (per aspect)
| Grade | % of credits in assessed aspect |
|---|---|
| Excellent 卓越 | ≥ 70% |
| Very Good 優良 | ≥ 60% |
| Good 良好 | ≥ 50% |
| Satisfactory 滿意 | ≥ 40% |

- No prerequisites under Selective
- **Record of Achievement** (all assessed aspect results) available on request after completing **≥ 2 aspects**

#### 3.7 Validity
- Both schemes: **5 years**
- Comprehensive Scheme B first intermediate certificate: **3 years**
- On expiry → renew by new assessment for ongoing operational performance

#### 3.8 Exemplars (ops / retrofit design lessons)
**Pacific Place — Final Platinum (Comprehensive)**
- Shopping mall + Grade-A office
- Proactive management + **monitoring-based HVAC retro-commissioning** → electricity reduction

**City One Shatin Phase 3C — first residential Selective Excellent (Management)**
- Continuous EMS optimisation since 1987
- Stakeholder engagement + ongoing facilities refurbishment → energy saving / carbon reduction
- Landscape greenery improvement + community green activities

#### 3.9 Volume certification (portfolio ≥ 5 properties)

**Why**
- Scale certification at lower cost / effort via **pre-approved credit** + **portfolio assessment** mechanisms
- Synergise corporate sustainability policies across entire portfolio
- Align with market sustainability **disclosure** reporting

**Eligibility for reduced fee**
- EB **V2.0** only (Comprehensive or Selective)
- Must adopt volume-certification assessment mechanism
- Enrol **≥ 5 properties** in portfolio
- Consult **BSL** on assessment feasibility **before** registration

**Process**
1. Get started with ≥ 5 properties
2. Submit portfolio registration (dedicated HKGBC form) — all properties must opt for **same** scheme (Comprehensive, or **same** Selective aspect)
3. Settle registration fee (discount by accumulated registered count under same owner / developer / FM company)
4. Assess portfolio via pre-approved credit **or** portfolio assessment (BSL)
5. Portfolio certified — HKGBC issues portfolio certificate; activates BEAM Plus Project Online Account; optional individual certificates / plaques via HKGBC Secretariat

### 4. Existing Buildings Global V1.0 — overseas O&M export

#### 4.1 Purpose
Export Hong Kong’s mature high-rise mixed-use facility / property management practice (digital tools, smart central plant, retro-commissioning, user & community engagement) to the international market via a dedicated rating tool.

#### 4.2 Target regions
Macau; Mainland China; Southeast Asia; Belt and Road regions; Europe; **any other regions**.

#### 4.3 Key features vs local EB (brief / ops implications)

| Feature | Implication |
|---|---|
| **Flexible participation** | Comprehensive certificate **or** selective certificates in chosen aspects (e.g. management, energy use, health & wellbeing) |
| **Generalised baseline standards** | International **energy baseline adjustable for weather**; water efficiency labelling & IAQ may follow **local** standards of the host region |
| **Carbon neutrality goals** | Encourage GHG emission reduction targets; optional verification via **Science Based Targets initiative (SBTi)**; option to procure **Renewable Energy Certificates (RECs)** |
| **Expanded energy reduction scale** | Scoring range for energy reduction expanded from **8% to 45%** (recognises deep savings via new technology) |
| **Latest technology** | Digital FM practices; **BIM** to model as-built facilities for management efficiency |
| **Induce behavioural change** | IT platforms for users to showcase sustainable living; educational workshops for building users |

#### 4.4 Why participate (brochure)
- HK certification = reliable independent third-party verification, robust QA / accreditation → trustable in international marketplace
- BEAM Plus strength with **high-rise mixed-use** and mega-sized buildings → showcase O&M maturity

#### 4.5 Admin
- Manual: *BEAM Plus Existing Buildings (Global Version) Version 1.0*
- Brochure publication date: **30.08.2024**
- Buildings outside HK may enjoy **special fee concession** — contact Secretariat (Tel 3994 8813 / 3994 8868)

### 5. Interiors — Non-Residential v2.0 (fit-out)

#### 5.1 Scope & roles
- Label for greener **commercial and institutional** fitted-out premises
- Users: premises occupiers, interior designers, fit-out builders / contractors
- Funded by HKGBC; developed by BEAM Society Limited
- Acts as sustainability & healthy-design guide for designers/builders **and** assurance mark for occupiers
- Pub. **27.11.2023**

**Eligible premises:** offices, retail, restaurants, clubhouses, industrial units, other non-residential premises.

#### 5.2 Why certify (four value pillars)
| Pillar | Meaning |
|---|---|
| **Savings** | Save energy; minimise operating expenses |
| **Health & Wellbeing** | Occupant health, wellbeing, productivity |
| **Corporate Social Responsibility** | ESG responsibility |
| **Net Zero Commitment** | Optional path for premises pushing harder on de-carbonisation — **Net Zero certification option** |

#### 5.3 Assessment aspects
1. Management  
2. Integrated Design and Construction Management  
3. Materials and Waste  
4. Energy Use  
5. Water Use  
6. Health and Wellbeing  
7. Innovations and Additions  

#### 5.4 Ratings
| Rating | Overall score |
|---|---|
| Platinum | ≥ 75 |
| Gold | ≥ 65 |
| Silver | ≥ 55 |
| Bronze | ≥ 40 |

#### 5.5 When to join
- Bake standard into fit-out concept on **day one**
- Submit **after** fitting-out works finished
- Interior designer / fit-out contractor / environmental consultant may submit per contract

### 7. Existing Schools (ES) V1.0 — campus O&M + education

#### 7.1 Eligibility & scope
- Existing **primary and secondary** schools only
- Scope: management, operation, maintenance **plus** education, health & wellbeing performance
- **≥ 1 school calendar year** of operational data required before registration
- Tailor-made for HK schools; simpler than mega-building tools
- Emphasises top-management commitment; **Plan–Do–Check–Act** continual improvement; behavioural change through **education**
- Design-relevant environment enhancements cited: lighting, ventilation, material usage, energy efficiency

#### 7.2 Benefits
- Greener / healthier place to learn & inspire + third-party recognition
- Behavioural change & sustainability awareness among teachers, students, **family members**
- Support HK **carbon neutrality by 2050**

#### 7.3 Two-book system (use both)
| Book | Contents |
|---|---|
| **Assessment Manual** | Framework, design intention, assessment criteria, submittal requirements per credit head; extended reading → green building reference book for schools |
| **Technical Guidebook** | Further interpretation per credit; step-by-step calculation examples; calculation & document templates |

**Tool character:** Unique (HK school-specific) · Education-led · Simple vs mega-building tools

#### 7.4 Five performance categories — full subtopics

| Category | Subtopics |
|---|---|
| **Sustainable Leadership & Learning (SLL)** | High-level commitment; Environmental learning; Engagement |
| **Sustainable Campus Environment (SCE)** | Biophilia; Neighbourhood integration; Climate resilience |
| **Efficient Use of Resources (EUR)** | Decarbonisation actions; Benchmarking & disclosure |
| **Health, Comfort & Happiness (HCH)** | Healthy indoor environment; Healthy living; Health protection |
| **Innovations & Additions (IA)** | Innovations |

Framework assesses all-round performance: education, leadership, resource efficiency, indoor environment, wellbeing, innovations.

#### 7.5 Rating notes
- Final grade subject to overall score requirements (brochure table partially graphical)
- Overall score **&lt; 50 points** → **Unclassified**
- Showcase projects awarded **Green** rating (Beta)
- Any category scoring **≥ 70%** → **Outstanding Performance** badge for that category
- Certificate **5 years**; re-assess every 5 years; **substantial registration fee discount** if renew before expiry

### 9. Cross-tool SD credit map (architect checklist)

Freeze before GA / envelope / plant rooms / public realm are locked:

### 10. Certification lifecycle (do not reverse)

```
Neighbourhood ──(masterplanning / inception)──► Certificate ≤5 yrs
        │
        ▼  (planning → implementation)
New Buildings / New Data Centres ──(design–construction–FA)──► FA ≤5 yrs
        │
        ▼  (occupancy / operations)
Existing Buildings / Existing Data Centres / Existing Schools
        │
        └── renew every 5 years
            (EB Comp B first intermediate: 3 years)

Parallel: Interiors NR / Residential — day-one concept → submit post-fit-out → renew at 5 yrs
Overseas O&M: Existing Buildings Global V1.0
```

**Stage labels (Neighbourhood brochure):** Masterplanning → Building Design → Construction → Post-Construction & Operation map to ND → NB → EB.
