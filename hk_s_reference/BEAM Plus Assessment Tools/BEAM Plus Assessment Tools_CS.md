# BEAM Plus Assessment Tools
**Architect critical summary for schematic design**  
Tool selector across the HKGBC brochure set | Certification body: HKGBC · Assessment body: BEAM Society Limited

> Scope note: BEAM Plus is a **voluntary third-party green building rating system**. It is **not** a Buildings Ordinance / BEC / FS Code substitute. Pick the **correct tool for project stage and typology first** — wrong tool = wasted credits and missed early-design decisions. Per-tool gates, weights and SD takeaways live in the sibling `_CS.md` files listed below (do not use this page as a scorecard).

---

## Regulatory Overview

BEAM Plus covers Hong Kong new construction, major renovation / A&A / conversion, existing-building O&M, neighbourhood masterplanning, non-residential and residential fit-outs, existing primary and secondary schools, data centres, and (Global Version) overseas existing buildings. Most certificates last **five years**, after which owners are steered to the next lifecycle tool.

**Hard gates (cross-tool)**

- Neighbourhood cert ≠ NB cert — reassess when design moves to building / construction stage
- NB Final → renew via **EB** after 5 years; NDC → **EDC** after 5 years
- Interiors / EB / EDC / ES / NDC certificates typically **expire at 5 years** (EB Comprehensive Scheme B first intermediate: **3 years**)
- Data centre assessed area **≥ 500 m²**; halls + plant = **significant majority** of floor area
- Existing Schools: **≥ 1 school calendar year** of operational data before registration
- EDC Selective: **Energy Use + Management are mandatory** (unlike conventional EB Selective)
- Credit pool under NB **varies by project type**
- Appoint / consult **BEAM Pro** before registration (explicit for Data Centres; good practice for all)

**SD takeaway:** Freeze **target grade + tool + scheme (Comprehensive vs Selective)** before massing, envelope, plant location and public-realm layout are locked.

### 2. Certification lifecycle (do not reverse)

```
Neighbourhood ──(masterplanning / inception)──► Certificate ≤5 yrs
        │
        ▼  (planning → implementation)
New Buildings / New Data Centres ──(design–construction–FA)──► FA ≤5 yrs
        │
        ▼  (occupancy / operations)
Existing Buildings / Existing Data Centres / Existing Schools
        │
        └── renew every 5 years
            (EB Comp B first intermediate: 3 years)

Parallel: Interiors NR / Residential — day-one concept → submit post-fit-out → renew at 5 yrs
Overseas O&M: Existing Buildings Global V1.0
```

**SD takeaway:** Do not skip ND on a multi-block inception, and do not stay on NB after year-5 FA if the client still wants a live certificate.
